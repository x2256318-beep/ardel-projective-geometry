## §1 問い（幾何の言葉）

素点たちを点とする空間 X があり、各点 v の上に舞台の「ファイバー」が載っているとする。有限素点 p のファイバーは P¹(ℤ_p)（有限レベルは P¹(ℤ/p^k)）で、そこでは 0 ≠ ∞ で、反転 W が 2 点を入れ替える。無限素点のファイバーでは、定義により無限大と無限小が重なり、その重なりは U による貼り合わせと読まれている。

問い 1：この族（素点の上の舞台）を一つの対象として書けるか。書けるなら、U（ねじれた貼り合わせ）は、その対象のどの部分の上の、何という構造か。とくに、無限素点のファイバーでの「重なり」は、点どうしの同一視（空間の貼り合わせ）として書けるか、それとも点の写像から来ない貼り合わせか。

## §2 既存分野への最善の翻訳（写像は義務）

- 点の空間 X：Arakelov のコンパクト化 Spec ℤ̄ = Spec ℤ ∪ {∞}（辞書 §24、照合済みの同定）。
- 素点の上の P¹ の族：算術曲面 P¹_ℤ → Spec ℤ と、Arakelov 理論での無限素点のファイバー P¹(ℂ)（または P¹(ℝ)）。アデールでは P¹(𝔸_ℚ) = ∏'_v P¹(ℚ_v) と、その中の P¹(ℚ)。
- 「射影」の変換：Tate の局所関数等式（フーリエと反転の合成）。GL₂ の言葉では Weyl 元の作用（主系列の絡作用素）、関数の側では Weil 表現の ρ(w)（辞書 §24）。Tate の学位論文の舞台は加法群 𝔸（= P¹ から ∞ を除いたもの）と乗法群 𝔸^×（= P¹ から 0 と ∞ を除いた「赤道」）で、局所関数等式は 0 と ∞ の振る舞いを入れ替える。
- 無限素点での重なり（U による貼り合わせ）：モノグラフ層では、イデール類群 C_ℚ ≅ Ẑ^× × ℝ_{>0} の上の伸縮の生成元 D の自己共役拡張の境界条件で、ℝ_{>0} の両端（0 と ∞）を、Ẑ^× の指標ごとに位相 W(χ*) を付けて結ぶもの（定理 2.6、公準 A1）。既知の言葉では、Connes の切断（Λ）と境界条件、Burnol の作用素、Ibort–Lledó–Pérez-Pardo の境界ユニタリ（索引 2.2・2.3）。

## §3 残余（翻訳しても消えない部分）

構築側の見立て（確信度：中）：

1. **U は点の写像から来ない**（構築側の観察、数値）。U は単数群の平行移動と可換で、指標の基底で対角（固有値 W(χ*)）なので、群の上の畳み込み作用素である。もし U が単数群の点の全単射 φ による引き戻し（f ↦ f∘φ）なら、φ は平行移動と可換になり、φ(u) = cu となって固有値は χ(c)（χ の値）になるはずである。数値で、素数の法 p = 5, 7, 11, 13 では、どの c についても W(χ) = χ(c) はすべての原始指標では成り立たない（`/tmp/q1/chk.py`、最小のずれ 0.55〜1.76）。したがって、少なくともこれらの法の段では、U による貼り合わせは点どうしの同一視（空間の貼り合わせ）ではない。読み：無限素点での「重なり」は、点の空間の言葉では書けず、関数の側（作用素の側）でだけ書ける貼り合わせである。
2. 1 が正しければ、§1 の「一つの対象」は普通の空間ではなく、関数の環（または作用素）の側で定義される対象になる。既知の枠組みでは非可換幾何（Connes）の対象に当たる見込みが高い（確信度：中）。ここで残るのは、(a) 有限素点のファイバー P¹(ℤ_p) では 0 ≠ ∞ で、点の写像 W が両者を入れ替える（空間の構造）のに、無限素点では点の写像から来ない U で結ばれる、という素点ごとの違いを、一つの対象の中でどう書くか、(b) それが既存の対象（算術曲面の Arakelov の無限ファイバー、Connes のアデール類空間、Connes–Consani のサイト）のどれかの言い換えか、の 2 つ。
3. 残余の地位：(a) は定義の読みの側の問い（解釈の層）を含む。数学の文として立てられる部分は、1 の観察（U は点の写像から来ない：有限レベルの各段で、平行移動と可換な単数群の全単射の引き戻しにならない）と、その全段での形（どの N で成り立つか）で、これは計算の細部に近い。
