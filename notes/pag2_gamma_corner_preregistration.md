## §1 4 点

### (1) 幾何の言葉での問い

- 見方を変える段 N ∣ M を考える。段には、新しい素数を加える段と、同じ素数の指数を上げる段の両方を含める。
- 問いの前半：粗い見方の有限レベルの代数 A_N を、細かい見方の代数 A_M の中に、引き戻しと両立する形で置けるか。単位元は保たず、像の単位を「N で周期的な関数への射影」とする。
- 問いの後半：置けるなら、すべての段を通した直極限、すなわちすべての素点を同時に測る側の極限は、完備化を使わずに組み立てられる 1 つの大域の代数になるか。
- 解像度のパラメータを N と同一視しない。ここでの N は「見方の段」の添字である。

### (2) 既存分野の言葉への翻訳

- **作用素の言葉**：ι = π^*/√(M/N) は等長写像で、Q = ιι^† とおく。共役 φ = Ad ι は、行列代数の間の単位元を保たない *準同型（角への埋め込み）である。
- **アソシエーションスキームの言葉**：H = Nℤ/Mℤ による商スキームに当たる。Bose–Mesner 代数については、商スキームの隣接代数が e_H A e_H に同型という古典的事実がある。Q = e_H = Σ_{(M/N) ∣ t} E_t である。問いはその Terwilliger 代数 T(0) 版。
- **フーリエで共役な版**：部分群 (M/N)ℤ/Mℤ への 0 拡張 V（ψ = Ad V、P = VV^† = Σ_{(M/N) ∣ t} D_t）は、閉部分集合への制限（部分スキーム）に当たる。
- **Bost–Connes の言葉**：群環の側（平行移動 τ_x）への φ の制限は、δ_x ↦ (N/M) Σ_{y ≡ x} δ_y となる。これは BC の自己準同型 ρ_{M/N}（ρ_n(e(r)) = (1/n)Σ_{ns = r} e(s)、ρ_n(1) = μ_n μ_n^*）にあたる。ψ の側は σ_n（e(r) ↦ e(nr)）にあたる。
- **極限の言葉**：単位元を保たない *準同型による有限次元代数の直極限である。

## §4 推薦案（1 つ）

- **推薦**：新しいパートは始めない。短期層の小さいノートとして、R-b・R-c・R-d を Lean にする（PAG264）。R-a（像 = 角）と R-e（BC との対応）は Lean にせず、文献と数値・手計算のまま第 5 章・第 6 章の留保に書く。
- **理由**：
  1. 残余は計算の細部と初等的な極限の文だけで、新しい現象はない。R-a は既知の結果（三重正則性）からの短い帰結。確信度は中〜高で、構築側と盲検の手計算が一致し、数値は 111/111 組。§4 の規則では短期層になる。
  2. 対照群（関数体）でも成り立つので、ℚ に固有の算術ではない。第 5 章（設計についての定理）の文面を直す材料であって、新規性の候補にはしない。
  3. 第 5 章の留保「関数のレベルの極限 ℂ[ℚ/ℤ] の代数版にはならない」は、単位元を保つ写像に限れば正しい。ただし、単位元を保たない角の写像（BC の ρ を Ad ι として延ばしたもの）では、整除の順序全体で帰納系が組める。文書の第 5 章は設計の定理をすべて Lean の名前で引いているので、この訂正も Lean の名前で引けるようにする。
  4. γ（6.3）への答えの形がはっきりした。BC の ρ・μ_n は、角への写像として T(0) の片側（L²(Ẑ) の表現では D 側）に届く。T(0) のもう片側は BC の表現の外にある。ただし文献の照合は低〜中のまま（MathSciNet・zbMATH は著者側）。
- **Lean の範囲（案）**：
  - 写像 φ(S) = (1/k)·π^* ∘ S ∘ π_*（π_* は繊維の和、k = M/N）。これが shellAlg N から shellAlg M への単位元を保たない代数準同型になり、gcd によらない（R-b）。

  - (i) と φ(1) = Q からの一意性（R-c）。
  - 合成 φ_{M,L} ∘ φ_{N,M} = φ_{N,L}（R-d）。
  - D 側が殻の span に入らない証人（(2,4)）。
  - 着手前と閉鎖前の内部照合（第 12 の型。言葉の検索を含む）と、閉鎖時の独立照合を行う。
