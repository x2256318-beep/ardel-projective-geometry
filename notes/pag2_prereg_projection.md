## 1. 問い（幾何の言葉）

命名にある「射影」とは、各素点の上の射影直線 P¹ と、0 と ∞ を入れ替える反転 W のことか。無限素点では、乗法の側の正の実数の両端 0・∞ が、対数で加法の直線に移したときの −∞・+∞ になり、加法の射影直線の上でその両端が一点になる（「−∞ と ∞ と 0 が射影によって重なる」）。この重なりを境界ユニタリ U でねじって貼り合わせたものが、有限素点の P¹(ℤ/p^K) の南北の貼り合わせ（赤道の上の F_N(y) = F_S(y⁻¹)）と同じ形の構成として、全素点を通して一つに書けるか。

## 2. 既存分野の言葉への最善の翻訳

- 射影直線 P¹(R)（R = ℤ/N、ℚ_p、ℝ）と、制限積 P¹(𝔸_ℚ) = ∏'_v P¹(ℚ_v)。反転は PGL₂ の元 [[0,1],[1,0]]。［既知］
- 無限素点：ℝ_{>0} の対数座標で −i d/dt を考えると、Λ 切断の区間 [−log Λ, log Λ] の上の自己共役拡張は U(1) で分類され、両端を位相 e^{iθ} で貼り合わせた擬周期境界条件になる（ねじれた円、平坦な U(1) 束）。［既知、教科書的］ 全直線（Λ → ∞）では −i d/dt は本質的に自己共役で、境界条件はない。
- 両端の貼り合わせと反転 W の両立（定理 2.6）：Burnol の定理、Ibort–Lledó–Pérez-Pardo の例 7.1・7.2 に近い先行（CLAUDE.md §3）。Connes のアデール類空間の切断 Λ（Connes 1999 の跡公式の切断）も同じ場所にある（確信度：中、未照合）。

## 3. 翻訳しても消えない部分（残余）

- 現時点の見立て：**残余は「定義の選び方」と「書き方」で、新しい数学の命題としては空に近い。**
  - 有限素点の P¹ と反転・南北の貼り合わせは Part 19〜28 で済んでいる。
  - 無限素点の両端の貼り合わせ（U）と W の両立は、モノグラフ層の定理 2.6 と Part 252・254 で済んでいる。
  - 両者を「射影」の名で一つに書くことは定義の作業で、著者側の基礎文書の起草に属する。
- 残余の候補として 1 つだけ残る：有限素点の南北の貼り合わせ（赤道の上で y ↦ y⁻¹、ねじれなし）と、無限素点の貼り合わせ（U によるねじれ）を、同じ一つの構成の特殊化として書けるか。書けるとすれば、有限素点の側にもねじれ（指標の位相）が隠れているのか、無限素点だけがねじれるのか。これは盲検の問いテストで既知かどうかを確かめる。

## 4. 対照群テスト（§7）

- 関数体 𝔽_q(t)：無限素点は非アルキメデス的で、𝔽_q(t) の無限素点は射影直線 P¹_{𝔽_q} の点 ∞ そのものである。t ↦ 1/t は素点 0 と素点 ∞ を入れ替える。したがって「射影直線の上で 0 と ∞ が反転で入れ替わる」という文は対照群でもそのまま成り立つ（形式の文）。
- ℚ に固有に残るのは、無限素点がアルキメデス的で、ℝ に順序（符号）と二つの端 ±∞ があること、対数が連続であることである。「−∞ と ∞ と 0 の三つの重なり」の「−∞ と ∞」の部分は、𝔽_q(t) の無限素点（付値が離散で端が一つ）では言えない。
- Beurling の一般化素数：無限素点の側（ℝ_{>0} と対数）は同じで、素数の側だけが変わる。無限素点の貼り合わせの文は Beurling でも成り立つと見込む（確信度：中）。
- 結論（見込み）：「0 と ∞ の反転」は形式の文、「±∞ の重なりと U のねじれ」はアルキメデス的な素点に固有。ただし後者も、ℝ_{>0} の上の作用素の境界条件の一般論で、ℚ の算術（素数）は使わない。

## 6. 結論と推薦

- **残余は空。新しいパートは始めない**（CLAUDE.md §4）。
- 構築側の読み（著者の確認待ち）：命名の「射影による融合」は、各素点 v で 0 と ∞ を入れ替える貼り合わせを **反転（乗法、イーデルの側）と加法のフーリエ変換（アデールの側）の合成** として与えることと読める。その指標ごとの位相が Tate の局所因子で、公準 A1 はこの位相を選ぶ公準である。有限レベルでは Part 252 の J∘H_N、無限素点ではモノグラフ層の U と定理 2.6。射影直線 P¹ の 2 チャート（Part 19〜28）は、その舞台となる座標の側。ラベル：［既知］（Tate 1950、Burnol 1998〜2001）。
- この読みは基礎文書の第 1・2 章の材料（著者側の起草）として渡す。定義として採るかは著者の判断。
- 対照群：関数体でも Tate の局所関数等式は同じ形で成り立つので、この読みは ℚ に固有の算術を使わない形式の文である。ℚ に固有に残るのは、無限素点で ±∞ が重なる部分（実数の順序と二つの端）だけ。
