## 結論

### Burnol の定理の適用範囲（数学としては確信度：高。モノグラフの定義との一致は確認待ち）

1. **切断しない C_ℚ ≅ Ẑ^× × ℝ_{>0} の L²：そのまま使えます。**
   - Burnol の定理 2.4 により、平行移動と可換な閉作用素は、双対群（原始ディリクレ指標の群 × ℝ）の上の掛け算作用素です。
   - 素数の平行移動 T_p とだけ可換でも、レゾルベントが可換なら全体と可換になり、同じ結論です（素数の類が生成する部分群の稠密性と、正則表現の強連続性による）。
   - さらに Burnol の定理 2.2 により、可換子が可換なら、対称作用素の自己共役拡張はただ一つです。切断しない群には境界の自由度がありません。
2. **切断した円筒 Ẑ^× × [Λ⁻¹, Λ]：バルクの作用素には使えません。**
   - ℝ 方向の平行移動は空間を保ちません。残る対称性 Ẑ^× の可換子は ⊕_χ B(L²(区間)) で、非可換です。
   - 定理 2.2 の仮定（可換子が可換）が崩れ、自己共役拡張は一つに決まりません。
   - 欠損空間は L²(Ẑ^×) と同型です。自己共役拡張は、境界条件 f(·, Λ) = U f(·, Λ⁻¹)（U は 𝓑 = L²(Ẑ^×) のユニタリ）で番号づけられます。
   - 著者の留保「Λ で切っていること自体が境界条件の存在理由」は、この形で正確に言えます。
3. **境界の空間 𝓑 = L²(Ẑ^×)：有界な場合が使えます。**
   - 各指標は重複度 1 で現れるので、古典的なフーリエ乗子の定理（Burnol の定理 2.4 の有界な場合）が使えます。
   - Ẑ^× と可換な U は指標で対角です：U = ⊕_χ e^{iα_χ}。
   - Part 249 の Lean（PAG253 の `thm26_full`）は、この部分を有限レベル (ℤ/N)^× の上で示したものです。
4. **α_χ を決めるものは、Burnol の定理にも von Neumann の理論にもありません。**

前回の批判的な照合の指摘（「正則表現、つまり重複度 1 でしか使えない」）は、2 と 3 の違いそのものです。

### 反転との両立の半分（数学は確信度：高。先行文献の判定は確信度：中）

- **JUJ = U* の意味。** JUJ = U* は「W が D_U の定義域を保つ」ことと同値です（私の計算。W(dom D_U) = dom D_{J U⁻¹ J}。数値 (7a)〜(7c) で符号を確認）。U が指標で対角なら、α_χ̄ = −α_χ と同値です。
- **先行文献。** この形の分類（指標ごとの境界の位相と、χ と χ̄ の位相の関係）を述べた文献は、今回照合した範囲では見つかりませんでした（§3）。
- **ただし部品はすべて既知で、導出は数行です。** 使うのは次の 3 つです。
  - von Neumann の拡張理論（値が L²(Ẑ^×) にある形）。
  - Ibort–Lledó–Pérez-Pardo の一般論（対称性で不変な拡張 ⇔ 境界のユニタリが境界での表現と可換）。
  - W が両端を入れ替えること。
- **判定（§11 で改訂：既知の結果からの短い帰結、確信度：高。条件は境界ユニタリの実性 KUK = U と同値）。** 既知の部品からの短い帰結です。モノグラフ §1.3 の自己評価「構造的には初等的」、著者の精査報告の「この形の先行文献は検索範囲で見当たらず」と同じ判定です。CLAUDE.md §3 の候補 2 の地位は、こちらでは変えていません。**§12 の盲検の文献照合も同じ判定（既知の結果の短い帰結、folklore）でした。反ユニタリ CW はどの対角の U でも定義域を保つので、W の条件は境界ユニタリの実性と同値です（§12.2）。候補 2 は新規性の根拠になりません（確信度：中〜高。§12.5）。**

### A1（辞書では「解釈の層の公準（内容は Tate の定理）」）

- **A1 の位相は、定理 2.6 が許す境界条件の一つです。** A1 の位相は α_χ = arg W(χ)、W(χ) = τ(χ)/(i^a √N) です（a = 0 は偶指標、a = 1 は奇指標）。
  - **実指標。** 定理 2.6 は α_χ ∈ {0, π} を許し、A1 は α_χ = 0 を選びます。これはガウスの符号決定で、Lean の `gauss_sign_real`（PAG198、第 I 期の項目 15）と同じ内容です。
  - **複素指標。** α_χ̄ = −α_χ は、W(χ)·W(χ̄) = 1 と |W| = 1 から出ます。前者は Lean の `gauss_inv_pair`（PAG173：z(χ)·z(χ⁻¹) = χ(−1)）から 1 行で出ます（χ(−1) = (−1)^a）。後者は Lean の `normSq_gaussSum`（PAG16：原始指標で |τ(χ)|² = N）から出ます（§10 の追補で確認。最初の版では「確かめていない」と書いていました）。
  - **一般の大域体。** 関数等式 Λ(1 − s, χ) = W(χ)Λ(s, χ̄) を 2 回使うと W(χ)W(χ̄) = 1 です。反転との両立の条件は、「関数等式は対合である」ことの作用素の言葉での形です（私の読み。数学としては確信度：高）。**§11 で訂正：この読みは過大でした。両立は定義から自明な W(χ̄) = conj W(χ)（境界条件の実性）から出ます。A1 の算術の内容は、どの α を選ぶかの部分だけです。**
- **したがって。** A1 と定理 2.6 の両立は、Lean にある 3 つの定理（PAG16 の `normSq_gaussSum`、PAG173 の `gauss_inv_pair`、PAG198 の `gauss_sign_real`）から短く出ます。ただし、この組み合わせ自体は Lean の文にしていません。A1 を課すこと（ほかの α を排すること）は公準のままです。「A1 を導いた」とは書きません（CLAUDE.md §6）。
- **著者の回答 (1) との関係。** 「届かないのは局所の材料ではなく、それらを境界条件として束ねる大域の課し方」と合います。局所の値（第 I 期のガウス和）も、その値が定理 2.6 の条件を満たすことも、手の届く範囲にあります。届かないのは選択の原理です。
- **無限素点の寄与。** λ = 0 では無限素点の γ 因子の比は 1 です（数値 (6)）。λ = 0 での無限素点の寄与は、パリティの因子 i^{−a} だけです。（§11 の 4：不分岐の有限素点の比は λ = 0 でも位相をもつので、「貼り合わせ」の範囲（ε 因子の積か、S = {∞} ∪ {p | N} の上の積か）を確かめる必要があります。）

## 1. 設定（Part 249 の記録と novelty-audit.md から。モノグラフ本文との照合待ち）

- **作用素。** T_p = M_{k_p} ∘ S_{−log p}、W(k, u) = (k⁻¹, −u)、D = −i∂_u。

## 2. Burnol の定理の適用範囲

### 2.1 Burnol の定理（arXiv:math/9904044 の本文で確認）

- **定理 2.2。** G は Hilbert 空間 L のユニタリの群（可換でなくてよい）で、A は G と可換な有界作用素の von Neumann 環です。(1) A が可換、(2) (M, D) が対称、(3) (M, D) が G と可換、を仮定します。このとき (M, D) の自己共役拡張はただ一つで、それは A と可換です。
- **「可換」の定義（定義 2.1）。** v ∈ D なら A v ∈ D かつ M A v = A M v。
- **定理 2.4。** G は局所コンパクト・ハウスドルフな可換群で、L²(G) に平行移動で働きます（双対の測度は σ 有限）。平行移動と可換な閉作用素は、ただ一つの乗子 a による掛け算作用素 (M_a, D_a) です。
- **同じ論文のほかの内容。**
  - Γ = F I（I は反転 φ(x) ↦ φ(1/x)/|x|）はユニタリで、群の作用と可換です。その乗子が（四元数の）Tate のガンマ関数です。
  - 切断は射影 P_Λ と F P_Λ F⁻¹ で行い、境界条件は置いていません。
  - ディリクレ指標とイデール類群は出てきません。

### 2.2 三つの場面

| 場面 | 働く群 | 可換子 | Burnol の定理 | 結論 |
|---|---|---|---|---|
| 切断しない L²(C_ℚ) | C_ℚ 全体 | 可換（双対群の上の L^∞） | 定理 2.4・2.2 が使える | 平行移動と可換な閉作用素は掛け算作用素。自己共役拡張は一つ（境界の自由度なし） |
| 切断した円筒 L²(Ẑ^× × [−L, L]) | Ẑ^× だけ | ⊕_χ B(L²[−L, L])（非可換） | 使えない（定理 2.2 の仮定が崩れる） | 自己共役拡張は f(L) = U f(−L) の U で番号づけられる（欠損空間 ≅ L²(Ẑ^×)） |
| 境界の空間 𝓑 = L²(Ẑ^×) | Ẑ^× | 可換（各指標が重複度 1） | 有界な場合が使える | Ẑ^× と可換な U は指標で対角 |

- **T_p の扱い。** 切断した円筒の上で T_p をどう定義しているかは、本文で確かめたい点です（§5 の 1）。
- T_p の Ẑ^× の部分 M_{k_p} と可換であることは、Ẑ^× 全体と可換であることと同値です。理由は、素数の類が生成する部分群が稠密であること（Part 249・251。一意分解で、各類は N を割らない素数の積で代表される。Dirichlet の定理は要らない。§11 の 11 で根拠の書き方を訂正）と、強連続性です。素数は無限個要ります（§11 の 8）。
- 閉作用素については、レゾルベント (M − z)⁻¹ が T_p と可換なら、強連続性で C_ℚ 全体と可換になります。すると Burnol の定義 2.1 の意味で M も可換になります。

### 2.3 計算の要点（標準的な計算。私の確認）

- **欠損空間。** D_min = −i∂_u（芯は L²(K) ⊗ C_c^∞((−L, L))。§12.1 の注）の随伴の核は、ker(D* ∓ i) = {g(k)e^{∓u} : g ∈ L²(Ẑ^×)} です。どちらも L²(Ẑ^×) と同型です。
- **境界条件。** 境界形式は ⟨D*f, g⟩ − ⟨f, D*g⟩ = −i(⟨f(L), g(L)⟩ − ⟨f(−L), g(−L)⟩) です。自己共役拡張は f(L) = U f(−L)（U はユニタリ）と一対一に対応します。スカラーの場合、運動量作用素の拡張は境界の位相 e^{iα} で番号づけられ、これは標準的です（Pérez-Pardo–Barbero-Liñán–Ibort）。
- **Ẑ^× の作用。** Ẑ^× の平行移動は、境界の値に正則表現 ρ で働きます。D_U が Ẑ^× と可換 ⇔ U が ρ と可換、です（Ibort–Lledó–Pérez-Pardo の一般論の、この場合）。
- **反転。** g = Wf とおくと g(·, L) = J f(·, −L)、g(·, −L) = J f(·, L) = J U J g(·, L) です。よって g は g(L) = (J U⁻¹ J) g(−L) を満たします。
  - したがって W(dom D_U) = dom D_{J U⁻¹ J} で、W が定義域を保つ ⇔ U = J U⁻¹ J ⇔ JUJ = U* です。
  - さらに W D W⁻¹ = −D なので、このとき W D_U W⁻¹ = −D_U（スペクトルは λ ↔ −λ、χ ↔ χ̄ で対称）です。
  - （§12.2 で追加）反ユニタリ CW（f ↦ conj f(k⁻¹, −u)）は、どの対角の U でも dom D_U を保ちます。したがって W の条件は、複素共役 C の条件 conj(U) = U（実性）と同値です。
- **指標での形。** U = Σ_χ e^{iα_χ}P_χ なら J P_χ J = P_χ̄ です。よって JUJ = U* ⇔ e^{iα_χ̄} = e^{−iα_χ} ⇔ α_χ̄ ≡ −α_χ です。
- **W が u ↦ −u だけなら。** 条件は U = U⁻¹、つまり α_χ ∈ {0, π} になります。このとき、複素原始指標のルート数（法 300 以下で 16,486 個すべてが ±1 でない、数値 (5)）とは両立しません。
