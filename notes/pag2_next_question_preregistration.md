## 1. Q1：両端の同一視のもとで、無限大と無限小を結ぶ写像は何か

- **出所。** 本来の道の C の続き 3（無限素点での重なり。案の一方「両端の同一視」）。

1. **幾何の言葉。** 切断した円筒 Ẑ^× × [Λ⁻¹, Λ] の両端、つまり無限大の側 Λ と無限小の側 Λ⁻¹ を貼り合わせます。貼り合わせが点どうしの同一視なら、できるのは空間の商です。問い：A1 の貼り合わせは点どうしの同一視か。そうでないなら、どんな写像か。
2. **既存分野の言葉への最善の翻訳。**
   - 点の写像による貼り合わせ：Ẑ^× の平行移動と可換なユニタリで、重みつき合成作用素（f ↦ w·(f∘φ)）であるものは c·ρ(k₀) だけです。理由は、φ(xg) = φ(x)g から φ が平行移動になり、重み w が平行移動で不変なので定数になるからです。定理 2.6 の実性から c = ±1 です。位相は ±χ(k₀) で χ について乗法的になり、群の商（判断材料の読み A-1）に当たります。A1 はこの形ではありません（法 9 の 3 次指標。照合ノートの数値 (8)・(9)）。
   - A1 の貼り合わせ：各レベル N の原始指標の部分で、境界ユニタリは J H_N / √N です。H_N は離散 Hartley 変換（核 cas(2πxy/N) = cos + sin）です。数値 (P1) で 7,517/7,517 です。原始的でない指標では、H_N χ が単数でないところに値をもち、単数の上の固有値の絶対値は 1 未満です（(P1′) 440/440。Part 252 で訂正：単数の上の式そのものは原始性なしで成り立つ）。
   - 文献の言葉：ガウス和はフーリエ係数です（F_N χ = τ(χ)χ̄）。W(χ) は局所ルート数の積で、Tate の局所関数等式（局所フーリエ変換が χ 成分に掛ける因子）です。Hartley の核は実数値なので、実性（照合ノート §12.2）と合います。
3. **残余：空。** 「A1 の貼り合わせは点の同一視でなく、フーリエ型の作用素である」は、ガウス和の定義と Tate の局所理論の言い換えです。各レベルの作用素を組み立てる部分（局所の作用素の制限テンソル積と、無限素点のパリティ因子）も Tate の枠組みです。残るのは計算の細部（主張 (2) の Lean 化）だけで、小さいノートの水準です。
4. **対照群テスト（残余が空なので参考として）。**
   - 「点の同一視なら位相は乗法的」は、コンパクト可換群一般の事実です。F_q(t) でも成り立ちます。
   - F_q(t) のルート数も、多くは乗法的な形になりません。自明な指標で c = 1 に決まるので、群の商の読みでは ε^m = 1 が要ります。(P3d) では、位数 m ≥ 3 の 5,994 個のうち ε^m = 1 は 238 個だけでした。例：p = 7、D = t² + 1、位数 3 の指標で ε = −0.756 + 0.655i は 1 の冪根でもありません。
   - 例外の出方（盲検の注意）：p^s ≡ −1 (mod m) となる半原始的な場合はガウス和が純になり、ε は 1 の冪根です（(P3f) で 198/198）。逆は成り立たず、p = 7、deg D = 3、位数 9・18 では、半原始的でないのに ε が 1 の原始 9 乗根になる指標が 48 個ありました。ℚ の法 9 の 3 次指標（W = e^{2πi/9}）と同じ型です。
   - 一般化素数：Ẑ^× の部分がなく、指標は自明なものだけです。文は空虚に成り立ちます。
   - したがって、ℚ に固有の内容はありません。
- **第 4 の型（障害量の先計算と、逆向きの検討）。** 定理 2.6 の境界条件の自由度は、実の乗子の無限次元トーラスです。そのうち点の写像による貼り合わせは {±1} × Ẑ^× だけです。逆向きの検討：A1 を特徴づける自然な性質として見つかったのは、A1 自身と同値なもの（フーリエ型であること）だけでした。
- **第 2 の型（依存表と除去テスト）。**

  | 結論 | 入力 | 除去テスト |
  |---|---|---|
  | 貼り合わせはフーリエ型 | A1（公準）、ガウス和の定義 | A1 を外すと U は任意の実の乗子になり、フーリエ型の構造は消える |

  したがって、これは A1 の読み替えで、導出ではありません。
- **判定：始めない（残余が空）。** 主張 (2) の確認は小さいノートの候補です。重なりの読みの判断材料としては、「A1 のもとでは、両端の同一視は点の同一視にならない（フーリエ型の重なり）」です。

## 2. Q2：W による商のもとで、固定点は何を数えるか

- **出所。** C の続き 3（案のもう一方「反転 W による商」）。

1. **幾何の言葉。** C_ℚ を W（(k, u) ↦ (k⁻¹, −u)）で割ります。無限大と無限小（u と −u）が同一視され、u = 0 で折り返されます。固定点の集合は {u = 0} × Ẑ^×[2] です（Ẑ^×[2] = ∏_p {±1} はカントール集合）。問い：商の上で自然な作用素は何か。固定点は何を数えるか。
2. **既存分野の言葉への最善の翻訳。**
   - 定理 2.6 の条件のもとで W は D_U と反交換するので、D は商に降りません。降りるのは D_U²、または W を次数とする次数つきの構造です。後者は偶のスペクトル三つ組の型で、Connes–Consani–Moscovici 2025 の Dγ = −γD と同じです。
   - 次数つき指数は Tr(W e^{−tD_U²}) = #{実指標で α_χ ≡ 0} です（McKean–Singer の型の標準的な議論）。0 でない固有値は W で ±λ の対になり、零モードでは、実指標の定数は W = +1、複素指標の対は ±1 に 1 つずつになります。
   - A1 のもとでは、実指標のルート数がすべて 1 なので（Gauss）、指数は反転の固定点の個数 #{k ∈ (ℤ/N)^× : k² = 1} に等しくなります（Lefschetz の不動点の型の等式）。数値 (P2) で 300/300 です。ルート数がちょうど 1 の複素原始指標は、q ≤ 300 では 0 個でした（(P2′)）。
   - 一般の定理 2.6 の境界条件では、指数は固定点の個数以下で、等号は実指標の位相がすべて 0 のときに限ります。
3. **残余：空。** 等式は、Gauss の符号決定（`gauss_sign_real`）を指数の言葉で言い直したものに、有限可換群の |Ĝ[2]| = |G[2]| を足しただけです。
4. **対照群テスト（参考として）。**
   - F_q(t)：2 次の指標のルート数は +1 でした（(P3c) 45/45）。同じ等式が成り立ちます。
   - 一般化素数：指標は自明なもの 1 つで、固定点も 1 つです。空虚に成り立ちます。
   - したがって、大域体に共通の内容です。
- **第 4 の型。** 障害量は、D が降りないこと（WDW⁻¹ = −D）と指数です。商の上の D² の境界条件の自由度は、定理 2.6 の D_U から来る族より大きくなります（指標の対ごとに U(2)、実指標ごとに U(1)。私の推論で、確信度：中）。
- **第 2 の型。**

  | 結論 | 入力 | 除去テスト |
  |---|---|---|
  | 指数 = 固定点の個数 | A1、Gauss の定理（外部） | A1 を外すと指数は 0 から固定点の個数までの任意の値になる |

  等式は Gauss の符号決定の読み替えです。
- **判定：始めない。** 重なりの読みの判断材料としては、「W による商では、A1 は『零モードが固定点をちょうど数える』形で現れる（内容は Gauss）」です。商の上の作用素を D² にするか次数つきにするかは、読みを決めた後の問いです。

## 3. Q3：指標の方向に粗くすると、スペクトルの密度は局所的に一様になるか

- **出所。** 本来の道の C（解像度と有効な姿）、照合ノート §11 の 5（無限重複の注意）。

1. **幾何の言葉。** 各指標の方向のスペクトルは離散の格子 (α_χ + 2πℤ)/(2L) です。指標の方向に粗くする（多くの指標をまとめて見る）と、格子が重なって、スペクトルの数え上げの密度が局所的に一様になるか。
2. **既存分野の言葉への最善の翻訳。**
   - 導手 Q 以下の指標で平均した数え上げが、どの固定区間でも (L/π)×ルベーグ測度に収束する ⇔ 位相が mod 2π で等分布する（周期化した極限の分布が一様であることと同値。短い議論）。
   - A1 のもとでは、ルート数の偏角の、導手順での等分布に帰着します。文献の範囲は §6 の盲検の結果を見てください。照合ノートの数値 (11)：q ≤ 300 で KS 統計量 0.038（0 に実指標 184 個が集中）。
3. **残余：空。**
   - 等分布は、文献の範囲で既知の定理の問題です（§6）。
   - 「局所的に一様な密度」を §1 の命題 3（解像度と有効な姿）と結びつけるのは解釈で、数学の文ではありません。
   - 粗くするパラメータ（導手の上限 Q）は法 N に近いです。CLAUDE.md §1 は解像度を N と同一視することを禁じています。どう扱うかは著者の定義の判断です。
4. **対照群テスト。**
   - F_q(t)：指標は無限個あり、同じ型の等分布の問題になります（Katz・Deligne の型の結果の範囲。私は照合していません）。
   - 一般化素数：指標は自明なもの 1 つなので、格子は 1 つです。粗くしても密度は一様にならず、重複も起きません。
   - したがって「指標の方向の粗視化でスペクトルの密度が局所的に一様になる」は、副有限の単数群をもつ大域体に共通で、一般化素数にはありません。
- **第 4 の型。** 障害量は無限重複です（実指標の位相は {0, π}）。粗くしないと、スペクトルの数え上げが定義できません。逆向きの検討：α ≡ 0 では格子がすべて重なり、密度は一様になりません。
- **第 2 の型（強い警告）。**

  | 結論 | 入力 | 除去テスト |

  | 局所的に一様な密度になる | A1、等分布の定理（外部） | A1 を外すと位相しだい。α ≡ 0 ではならない |

  入れた位相の等分布を、§1 の命題 3 の現れと読み替える、注入→回収の型です。
- **判定：始めない。** 解像度の定義の判断材料としては、「スペクトルを数えるには指標の方向の粗視化がどのみち要る。それを解像度とみなすかは著者の判断。ただし §1 の N との同一視の禁止に触れる可能性がある」です。
