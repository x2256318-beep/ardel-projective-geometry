## 1. 問いを幾何の言葉で書く

- 点（素数たちと無限素点）のうち、どれだけを同時に測るかを変えたとき、大域対象のどの離散構造が見え、どれが均されるか。
- すべての素点を同時に測る側（直極限の側）でだけ現れる離散構造があるか。あるなら、それを「極限でも観測を維持する離散構造」（08:41 の定義）の例として書けるか。
- 測る範囲を粗くしたとき残る連続な姿（ψ(x) の主項 x、零点の個数の主項）は、どの点から来るか。とくに無限素点の寄与は何か。

## 2. 既存分野の言葉への最善の翻訳

- **Weil の明示公式**（Weil 1952。教科書では Iwaniec–Kowalski の定理 5.12 の形）：素数冪の和と零点の和が、極の項と無限素点（ガンマ因子）の項を挟んで 1 つの等式で結ばれる。
  - (1) 試験関数 g の台を [−log X, log X] に限ると、素数の側には n ≤ X の素数冪だけが現れる。零点の側の h = ĝ は指数型 log X の整関数になる（Paley–Wiener）。（盲検の指摘で直した：「零点を約 2π/log X の分解能でしか見分けない」は言い過ぎ。h は細かい尺度でも滑らかに変わり、和は零点の正確な位置に依存し続ける。正確に言えるのは、区間の指示関数を型 log X の関数で上下から挟む誤差が 1/log X の桁より小さくならないこと（Beurling–Selberg の極値関数、Vaaler 1985）。定数 2π は規約で変わり、確かなのは桁だけ。既知。）**注意：** これは「p ≤ X を測る」を対数の台の切断で書くことで、Λ 切断（Λ = log X）と同じ形である。§0 の扱いにより、この翻訳を解像度のパラメータの決定としては採らない。
  - (2) Riemann–von Mangoldt の明示公式：零点を高さ T で打ち切った和は、T が大きい範囲で ψ(x) を幅 x/T 程度の尺度で近似する。ただし鋭い打ち切りの核は符号を変えるので正値の平均ではなく、素数冪の跳びでギブス型の振動が出る（E1 の最大誤差が単調でないことと合う）。厳密な均しは、Mellin 変換が高さ T で切れる重みを使った平滑化された明示公式による。零点（非自明零点）をすべて外すと x − log 2π − ½log(1 − x⁻²) が残り、½log の項は自明零点から来る（既知。盲検の指摘で直した）。
- **有限個の素数のオイラー積**は ℂ 全体で零点を持たない（各因子が零にならない。既知）。（盲検の指摘で直した：「零点は全素点の積に初めて現れる」は誤解を招く。Hurwitz の定理により、零にならない関数の局所一様極限は零を持たないので、ζ の零点は部分積の極限ではなく、部分積は零点を含むどの領域でも ζ に局所一様収束しない。零点はオイラー積の外側、解析接続の側の対象である。定量的な形は Gonek–Hughes–Keating（Duke Math. J. 136, 2007）の ζ(s) ≈ P_X(s)·Z_X(s)：素数 ≤ X の（平滑化した）部分積と、s から約 1/log X 以内の零点の積への分解。）
- **零点の個数の主項** (T/2π)log(T/2πe) + 7/8 のうち、(T/2π)log(T/2πe) と −1/8 は無限素点の因子 π^{−s/2}Γ(s/2) から、+1 は極から来る（N(T) = θ(T)/π + 1 + S(T)。既知）。（盲検の指摘で直した：最初の版は「7/8 を含めて無限素点から」と書いていた。）
- **ルート数：** 原始的な χ について、完備化した L の関数等式 Λ(s, χ) = ε(χ)Λ(1 − s, χ̄) の対数微分では ε(χ) が消えるので、明示公式に ε(χ) は現れない。関数等式から入るデータは導手とパリティ a（ガンマ因子 Γ((s + a)/2) を通して）だけ（構築側の手計算。盲検も「既存の結果からの短い帰結」と判定、確信度：高）。ただし ε は明示公式の外で零点に効く：自己双対な L で ε = −1 なら中心に零点が強制され、族の 1 準位密度では ε で対称性の型（SO(even)・SO(odd)）が分かれる（Iwaniec–Luo–Sarnak 2000。盲検の補足）。実の原始的なディリクレ指標では ε = 1。
