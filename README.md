# アーデル射影幾何学（PAG 2.0）— Lean 4 による形式化

著者：Hirota Hidekazu

このリポジトリには、アーデル射影幾何学の定義層と、それを Lean 4 / Mathlib で形式化した鎖を置いています。幾何の新規性は、個々の定理ではなく設計にあります。設計の柱は次の 4 つです。
- 何を点とするか：素数と無限素点。
- 何を大域対象とするか：制限積の因子として並列に共存する素点たち。
- 貼り合わせのデータ：境界ユニタリと公準 A1。
- 解像度の操作：測る素点の集合。

## 番号の対応

- PAG 2.0 の Part n は、ファイル `PAG(n+4).lean` にあります。名前空間は `PAG.Part(n+4)` で、ファイルの番号を使います。
  - 例：Part 259 は `PAG263.lean` にあり、名前空間は `PAG.Part263` です。
- 早い時期のファイルは「最初の形式化の Part n（PAGn.lean）」として参照しています。

## ビルド

```
lake exe cache get
lake build
```

注意：この環境ではネットワークが使えないため、上の `lake build` は試していません。各ファイルは、同じ Lean と Mathlib の版で、`lean` コマンドと `LEAN_PATH` を使って 1 ファイルずつコンパイルし、`#print axioms` で公理が標準の範囲（`propext`、`Classical.choice`、`Quot.sound`）にあることを確かめました。

## 照合の手順

- **独立照合：** 新しい照合者に、形式文の全文と使う定義を渡します。他の照合者の出力の要約は渡しません。照合の前に予想を書いておき、出力は全文を保存します。
- **内部照合：** パートの着手前と閉じる前に、鎖の全宣言を名前・言葉・`#dupcheck` で検索し、すでにある宣言との重複を確かめます。
- **題と主張文：** Lean の形式文が確定した後に、形式文から起こして書きます。
