アーデル射影幾何学と
Terwilliger 代数の相違

結論は二層です。有限レベルでは、アーデル射影幾何学（PAG）の代数 AN は Terwilliger 代数 T(0) そのものです。定義が一致し、単一レベルの構造（素数冪の Wedderburn 分解と次元、互いに素な法でのテンソル積分解）は既知です（BST 2010、Hanaki–Kim–Maekawa 2011、Bastian–Humphries 2026）。PAG がその上に積むもののうち、レベル間写像は存在の側と角の写像の E 側が既知、帰納系は［再導出（小さい）］で、新規候補として残るのは、単位的な写像の不存在の側と、合成数 N の生成の分類だけです（どちらも確信度は低〜中で、MathSciNet・zbMATH での照合は未実施）。単行書層（Tate の γ 因子、自己共役拡張）は、Terwilliger 理論に対応する問題設定がありません。逆に、一般の Terwilliger 理論が扱う任意のスキームや Leonard 対の世界は、ℤ/N に限る PAG の外に広がっています。

まず押さえるべき3点

同一である部分

AN は、Z/N 上の gcd 殻を基本集合とする軌道 Schur 環（orbit S-ring）の Terwilliger 代数 T(0) に定義照合で一致する。殻代数という PAG の呼び名は、この同一視の別名である。

相違が集中する部分

「異なる N の間の代数をどうつなぐか」と「その代数を何につなぐか」。前者のうち既知でないのは単位的な写像の不存在の側だけ（新規候補、確信度 低〜中）。後者（単行書層）は Terwilliger 理論の外。単一レベルの構造論では、逆に文献の方がはるかに広く、PAG の素数冪・テンソル積の結果はその特別な場合。

⚠ 用語の罠：文献で「cyclotomic scheme（円分スキーム）」と言えば通常は有限体 Fq の剰余類によるスキームを指し、Z/N の gcd 殻スキームとは別物です。両者を混同すると、有限体側の結果（Jacobi 和など）を PAG 側へ誤って移すことになります。PAG の対象の標準的な呼び名は「巡回群上の軌道 Schur 環（cyclotomic S-ring）」から来るスキームです。

01同一視の中身 — AN = T(0)

PAG の有限レベル代数 AN は、End(ℂℤ/N) の中で次の2種類の作用素で生成されます。

Dt ≡ E*t : 殻 { x ∈ ℤ/N : gcd(x, N) = t } （t | N）への対角の射影 ＝ 基点 0 における双対冪等元
Et : 周波数側の殻（フーリエ変換が殻に台を持つ関数）への射影 ＝ Bose–Mesner 代数の原始冪等元

Et は、gcd で関係を分けるアソシエーション・スキームの Bose–Mesner 代数の原始冪等元です。Dt は基点 0 に対する双対冪等元 E*t で、点の側の殻への対角の射影そのものです（改訂前の版は、この射影を Et と書いていた）。この生成元の組は、Terwilliger 代数の定義そのものです。

定義（Terwilliger, 1992）[V]

可換アソシエーション・スキーム Y と頂点 x に対し、非可換・結合的・半単純な ℂ-代数 T = T(x) を導入し、subconstituent algebra と呼ぶ。現代的な定式化では「Bose–Mesner 代数と、点 x に関する双対冪等元で生成される行列代数の部分代数」である（Maleki, arXiv:2310.19609 の要旨で確認）。

出典：Terwilliger, “The subconstituent algebra of an association scheme” I–III, J. Algebraic Combin. 1 (1992), 2 (1993). ／ Herman による概説, Indian J. Pure Appl. Math. 52 (2021) 631–642 [S]

したがって相違は「AN が Terwilliger 代数かどうか」にはありません。相違は、どのスキームの T なのか、そして T の上に何を載せるかにあります。

PAG のスキームは特殊です。自己同型群全体 (ℤ/N)× の軌道で割った軌道 Schur 環であり、基本集合がちょうど gcd 殻になります。類の数は N の約数の個数しかなく、Bose–Mesner 代数は小さい。これが後述する「群スキームでは T が全行列代数になる」という結果が PAG へ移らない理由です。

02Terwilliger 代数とは何か — 標準理論

Terwilliger 代数（subconstituent algebra）は、1992年に Paul Terwilliger が導入した、アソシエーション・スキームの組合せ構造を反映する代数です。生成元は隣接行列 Ai（あるいはその原始冪等元 Ei）と、基点 x で決まる対角行列である双対冪等元 E*i(x) です。

T(x) = ⟨ { Ai } ∪ { E*i(x) } ⟩ ⊆ M|X|(ℂ),   (E*i(x))uu = (Ai)x,u

中心的な主題

  • 既約加群と thin 性：標準加群 V = ℂX を既約 T-加群に分解する。dim E*iW ≤ 1 を thin、dim EiW ≤ 1 を dual thin と呼ぶ。endpoint、diameter などの不変量で加群を分類するのが Part I–III の骨格 [V]。
  • Wedderburn 分解：T は共役転置で閉じ半単純なので T ≅ ⊕ Matni(ℂ)。個々のスキームごとに成分・重複度・次元を決めるのが標準的な「構造問題」。
  • P-多項式／Q-多項式スキーム：Delsarte 理論（1973、符号理論）と結びつき、Bose–Mesner の線形計画 bound を Terwilliger 代数で半正定値 bound へ精密化する（Schrijver、Tanaka）[S]。
  • Leonard 対・Leonard 系：一方の基底で対角、他方で既約三重対角になる作用素の対。thin かつ dual thin な既約 T-加群は Leonard 系と一致し、Askey スキーム／q-Racah 多項式で分類される（Terwilliger, arXiv:math/0306301, 2003）[V]。
  • 三重対角対・q-Onsager・量子群：tridiagonal algebra、(q-)Onsager 代数、Uq(ŝl2) の表現へつながる大きな表現論の層がある [S]。
  • ほぼ可換性（almost commutative）：非 primary な既約加群がすべて1次元である性質。Tanaka (2010, J. Algebraic Combin. 33 (2011) 1–10) は同値条件を与え、その1つが「1類スキームと有限アーベル群スキームの wreath 積であること」[S]。この概念が §3 の Bastian–Humphries へ直結します。

2生成元への帰着が保証されるのは、P-かつ Q-多項式の場合。（それ以外のスキームで T = ⟨A, A*⟩ となる場合を排除するものではありません。）距離正則グラフ／P・Q-多項式スキームでは M は単一の隣接行列 A = A1 で、M* は A* = A*1(x) で生成されるため T = ⟨A, A*⟩ となります [S]。これは §5 の「生成元の部分集合による生成」とは別の話です。

主要参考文献：Bannai–Ito, Algebraic Combinatorics I (1984)／Brouwer–Cohen–Neumaier, Distance-Regular Graphs (1989)／Herman 概説 (2021)。

03円分／gcd スキーム — 文献が実際に扱っている対象

ここが最も混同しやすい箇所です。似た名前の対象が3つあります。

① 有限体円分スキーム Cyc(q, N)

Fq× の部分群の剰余類 Ci を用い、x − y ∈ Ci で関係を分ける。文献で「cyclotomic scheme」と言えば通常こちら。Ishibashi–Ito–Yamada (1999) が Jacobi 和で T の表現を解析し、類数2の場合に既約表現を完全に決定 [S]。

② 群アソシエーション・スキーム

共役類ごとに分けるスキーム。G がアーベルなら類は単元集合になり、dim T0 = |G|2、すなわち T は全行列代数 M|G|(ℂ) に一致する（Bannai–Munemasa, Kyushu J. Math. 49 (1995) 93–102）[V]。gcd 殻への融合とは別物で、この結論は AN へ移らない。

③ 巡回群上の軌道 Schur 環 — PAG の対象

自己同型群の部分群の軌道で割る S-環。部分群が全体 Aut(ℤ/N) = (ℤ/N)× のとき、軌道がちょうど gcd 殻になる。これが PAG の AN の属する族。

④ 1類スキームの輪積と直積 — ③と同じもの

N = pk では、vp(x − y) = j ⇔「下の桁から見て最初に違う p 進の桁が j」なので、③のスキームは Kp の k 重の輪積 Kp ≀ ⋯ ≀ Kp と同型です。一般の N では中国剰余定理により、素数冪の因子の直積 Πp Kp≀vp(N) になります。したがって Bhattacharyya–Song–Tanaka (2010) の結果は AN（N が素数冪）にそのまま当てはまります（改訂前の版の「構成が異なるので読めない」は誤り）。

最も近い2026年の結果 — Bastian–Humphries

Bastian–Humphries, “Schur rings over cyclic groups having Almost Commutative Terwilliger algebras”, arXiv:2606.19095（2026年6月17日投稿）[V] 要旨確認

巡回群上の軌道 Schur 環で、ほぼ可換な Terwilliger 代数を生むものを分類した。要旨によれば、自己同型の部分群は自明なものか、巡回群の位数が素数冪のときに全体の自己同型群である場合に限る。位数 2n ではこの2つだけ。奇素数 p の pn では位数 pn−1 の部分群も許される。素数冪でない位数では、自明な部分群から来る軌道環だけがほぼ可換になる。さらに wedge 積を扱い、巡回群上の Schur 環がほぼ可換な T を生む条件を完全に決定している。

PAG への読み替え（解釈であり引用ではない）：PAG の環は全体の自己同型群による軌道環なので、この定理により AN がほぼ可換であるのは N が素数冪のときに限ることになります。N が相異なる素因数を2つ以上持てば、ほぼ可換ではありません。これは PAG が経験してきた「素数冪と合成数で振る舞いが分かれる」という分岐に、文献側の錨を与える結果です。リポジトリの辞書（records/audit256/dictionary_before_part256.md）には、同論文の本文に素数冪の次元式（p 奇数で (3k²+5k+2)/2、p = 2 で (3k²+3k+2)/2）と、Hanaki–Kim–Maekawa を引用した Thm 5.2（T(A × B) ≅ T(A) ⊗ T(B)）がある、と記録されています（本文の一部の確認。本ページの調査では要旨だけ）。この読み替えは数値でも確かめました：素数冪 11 個（≤ 32）はすべてほぼ可換、素数冪でない 7 個（6 ≤ N ≤ 30）はすべてほぼ可換でない（records/terwilliger-check/。辞書の記録では ≤ 128 で 45/45、6 ≤ N ≤ 60 で 34/34）。

既知 gcd／軌道スキームの T(0) の次元と Wedderburn 分解は、上の同型により既知の結果から出ます。素数冪では BST の T(Kp≀k) ≅ Mk+1(ℂ) ⊕ ℂk(k+1)/2 − b（b は p = 2 で k、ほかで 0）で、dim Apk = (3k²+5k+2)/2（p 奇数）、(3k²+3k+2)/2（p = 2）。一般の N では直積のテンソル積定理（下）により dim AN = Πp dim Apkp。数値：素数冪 11 個で次元式と一致（辞書の記録では ≤ 128 で 44/44）、互いに素な 6 組で次元が積になる（改訂前の版の「見つからず」は誤り）。

04レベル間写像と極限 — 最大の相違

見つからず 異なるスキームの Terwilliger 代数の間の準同型を一般理論として扱う文献は、調査した出典では見つかりませんでした。ただし PAG のレベル間写像の個々の結果は、次のように地位が分かれます（ラベルはリポジトリの判定による）。

  • 単位的な写像の存在の側（gcd(N, M/N) = 1 のとき、Part 258、PAG262）：直積のテンソル積定理（HKM）から出る 既知
  • 単位的な写像の不存在の側（素数 p が N と M/N の両方を割るとき、引き戻しと両立し殻を混ぜない単位的な写像はない）：新規候補（小さい） 確信度 低〜中。盲検の問いテストと構築側の本文照合（Bastian–Humphries・Watanabe・Kim）で見つからず。MathSciNet・zbMATH と HKM 本文での確認が済むまで、外部で新規性として使わない（CLAUDE.md §3）
  • 全 N | M の非単位的な角の写像（Part 260、PAG264）：E 側は商スキームの冪等元による角の作用素版で 既知、ほかは［再導出（小さい）］。近い構造として、輪積の角の代数（単位的でない部分代数）と、別の設定の単位的でない準同型（超立方体の一般化 Terwilliger 代数、arXiv:2301.08366）がある（リポジトリの記録による）
  • 整除順序上の帰納系と極限（Part 261、PAG265）：［再導出（小さい）］。局所的な単位元の文は、各段が単位的で移行写像が乗法を保つ直極限の一般論で、内容を運ぶのは左単位元がないことだけ

したがって、PAG の「単位的 vs 角の写像」の二分法のうち、既知でないと言えるのは不存在の側だけで、それも照合の範囲での判定です。

隣接しているが、同じではない文献

スキームの圏と関手性 — Bose–Mesner まで

Hanaki のアソシエーション・スキームの圏 AS／AS₀（基点つき）では単射・全射が特徴づけられ、核は部分スキーム、余核は商スキームになる [S]。French, “Functors from Association Schemes”, arXiv:1208.1173 は許容射の広い部分圏を与え、そこで「スキームを代数へ送る標準的構成（隣接代数）」が関手的になる。Kuribayashi–Matsuo の要約では、French の系 6.6 は「スキーム ↦ Bose–Mesner 代数」が関手であること [S]。T(x) への拡張は見つからなかった。T は基点と双対冪等元に依存し、スキームの射がそのデータを保つとは限らないため、当然の難所でもある。

積の定理はレベル間写像ではない

§3 の直積／wreath 積の結果は、単一の積スキームの T を因子のデータで記述するもので、T(小さいレベル) → T(大きいレベル) という準同型ではなく、ℂX 上の引き戻しも含まない。

複数基点の変種も、同一スキームの内部

Suzuki の頂点集合に関する T や、Marashdeh の2基点版 T(a,b) = ⟨T(a), T(b)⟩（arXiv:2609.00462、素数位数の circulant／Paley グラフ）[S] は、1つの Mp(ℂ) の中で生成元を増やす構成であり、異なるスキームの間の写像ではない。

05生成の分類 — 生成元の部分集合で全体が生成されるか

見つからず Z/N の円分／gcd スキームについては、{Et} ∪ {E*t} のどの部分集合が T(0) 全体を生成するかを分類した論文は、調査した出典では見つかりませんでした。ただし地位は分かれます：素数冪の場合と ⟨M*, EN⟩ = AN ⇔ N ∈ {1, 4} ∪ 素数 は、構造定理と次元公式から数行で従います 既知の帰結。新規候補として残るのは合成数 N の項目 66（2つの双対な代数の和の条件）と項目 67〜69（完全な分類）だけで、評価は「小さいノートの水準」、確信度は中、MathSciNet・zbMATH での照合は未実施です（CLAUDE.md §3 の候補1）。

文献にある「生成」に関する話題は、性格の異なる2つだけです。

  • 粗い2生成元への帰着（§2）：P・Q-多項式スキームではすべての Ai が A1 の多項式、すべての A*i が A*1 の多項式になるため、生成元集合が ⟨A, A*⟩ へ潰れる。これは M と M* の内部での多項式生成の話であり、冪等元の部分集合の分類ではない。しかも gcd スキームは一般にその意味で P・Q-多項式ではないため、PAG の問いはこれでは解けない。
  • 三重積による生成：三重正則性に関連して、T が三重積 E*i Aj E*k の張る部分空間（Bannai–Munemasa／Bhattacharyya–Song–Tanaka の T₀）で生成される、という主題がある [S]。これも生成元の部分集合の分類ではない。

06外部への接続 — 項目ごとに

PAG の単行書層や指標論的内容が Terwilliger 文献とつながるかを、5項目に分けて調べた結果です。

主題判定内容
Dirichlet 指標の根数／Gauss 和の位相を代数構造として見つからず弱い形の接続はある。有限体円分スキームの固有値（第一固有行列）は Gauss 周期であり、その T-加群の構造は Jacobi 和で支配される（Ishibashi–Ito–Yamada 1999）。Shiratani–Yamada (1997) は Jacobi 和の有理性と、類数2円分スキームの T-部分加群の可約性を結ぶ [S]。Jacobi 和は Gauss 和の商・積なので、Gauss 和の偏角は Fq 円分の T-加群論に入る。しかし、Dirichlet 指標の根数 ε(χ)／Tate の ε 因子を Terwilliger 代数の構造定数・中心冪等元・不変量とする出典は見つからず、mod N の指標についても同様のものは見つからなかった。なお PAG 側でも、根数は公理 A1 で位相として入れたもので、A1 は導かれていない（公準のまま）。
Tate 理論と ε 因子見つからず調査した範囲で、Tate の学位論文、局所／大域 ε 因子、L(s,χ) の関数等式に言及する Terwilliger 代数の論文は見つからなかった。
Bost–Connes 系／ℚ/ℤ の C* 代数見つからずBost–Connes 系自体はよく知られている。C*(ℚ/ℤ) ⋊ ℕ× を e(r)（r ∈ ℚ/ℤ）と等長作用素 μn で生成し、分配関数は ζ(β)、対称性としてイデール類群の連結成分による商が作用する（Shirbisheh, arXiv:0808.1767）[S]。しかし、ある Terwilliger 代数を Bost–Connes 代数と同一視したり、埋め込んだり、写像で結んだりする出典は見つからなかった。ℚ/ℤ や ℤ/N、単位根から作られるという表面的な類似にもかかわらず、である。PAG 側でも、角の写像が群環の側で Bost–Connes の ρ と一致することは数値で確かめただけで、Lean の外（Part 260）。
イデール／アデール／イデール類群見つからずTerwilliger 理論の側では見つからなかった。上記のイデール類群の出現は Bost–Connes 理論の内部のもので、T(x) への橋はない。文献の Terwilliger 代数は ℂ 上（モジュラー版では体／環上）の有限次元行列代数であり、Ẑ = lim← ℤ/N のような射有限／アデール的な構成による T は見つからなかった（§4 の極限の欠如と連動）。
微分作用素の自己共役拡張の境界条件（D = −i d/du、境界ユニタリ）見つからずTerwilliger 文献で「self-adjoint」は、T が共役転置で閉じ半単純であるという意味だけである [V]。差分作用素との接続はある。Askey–Wilson の2階 q-差分作用素が三重対角対を実現する（Terwilliger, arXiv:math/0307016）[S] という双スペクトル／差分作用素の接続だが、円柱上の −i d/du、欠陥指数、拡張を境界ユニタリでパラメトライズする話ではない。そのような拡張理論と T を結ぶ出典は見つからなかった。

含意：PAG の単行書層 — イデール類群の円柱 Ẑ× × ℝ>0 上の D = −i∂u、自己共役拡張の境界ユニタリ U、公理 A1 による Tate の γ 因子との接着 — は、Terwilliger 代数としては記述できません。それは T の理論の内部には対応する問題設定自体がないからです。PAG の中で Terwilliger と重なるのは有限レベルの代数 AN の層までであり、それより上は PAG 独自の構成です。

07逆方向 — 一般理論が持ち、Z/N 限定の理論が持たないもの

相違は一方向ではありません。一般の Terwilliger 理論は、Z/N 上のスキームだけを見る理論では届かない広がりを持ちます。

  • 任意のアソシエーション・スキーム：デザイン、有限幾何、置換群、ラテン方格、正多面体などに由来するスキーム。例：正十二面体の T ≅ M₆(ℂ) ⊕ M₆(ℂ) ⊕ M₂(ℂ)（Levstein–Penazzi、Terwilliger の予想への反例でもある）[S]。任意の有限集合 X と任意の基点 x が対象で、スキームが頂点推移的でない場合 T(x) は実際に x に依存する。ℤ/N の基点 0 のような高対称な状況では見えない現象である。
  • 非可換スキームと任意の係数：Hanaki は任意の（可換とは限らない）スキームに対し、任意の可換単位的環上で T を定義した。モジュラー版（“Modular Terwilliger algebras”, arXiv:2004.09692／Graphs Combin. 37 (2021)）では、正標数で T が半単純でないことがあり（標数が valency を割る場合）、Johnson スキーム J(n,2) の dim T が標数により 16 か 15 になる [S]。
  • 直径が無限に伸びる距離正則グラフの族：Hamming スキーム H(d,q)（T は対称テンソル冪、超立方体 QD では T は U(sl₂(ℂ)) の準同型像、Go, Eur. J. Combin. 23 (2002)）、Johnson スキーム J(v,d)、Grassmann、双対極空間、Doob スキーム（Shrikhande グラフと K₄ の直積、Tanabe, J. Algebraic Combin. 6 (1997) 173–195 [V]）、Odd グラフ、距離二部正則グラフ、一般化四角形、木。いずれも ℤ/N 上のスキームではない。
  • 非アーベル群の群スキーム：任意の有限群 G の共役類スキーム（Bannai–Munemasa の次元の評価、S₅・A₅ に対する Balmaceda–Oura、Cn ⋊ C₂ に対する Maleki、Bastian–Humphries の Camina／Frobenius 分類）。単位元における基点理論は ℤ/N に対応物を持たない [V/S]。
  • スキームを離れた抽象的加群論：Leonard 対／系、三重対角対と tridiagonal algebra、(q-)Onsager 代数、Uq(sl₂) とアフィン量子群、Askey–Wilson 多項式という表現論の建造物全体（§2）。ℤ/N の族が見られるのは、その薄い一片にすぎない。
  • 純粋構造の外の応用：符号とデザインに対する Delsarte の LP／SDP bound、Assmus–Mattson 型定理（Tanaka 2009）、スピン模型と type-II 行列、Hamming／Johnson グラフ上の量子ウォークとエンタングルメント（Vinet ら）[S]。

釣り合い：PAG の単一レベルの構造（素数冪・テンソル積）は一般理論の特別な場合です。一般理論の中に特殊ケースとして見つからなかったのは、単位的なレベル間写像の不存在の側（§4）、合成数 N の生成の分類（§5）、単行書層の主題（§6）です。前の2つは新規候補（確信度 低〜中、照合未完）、最後のものは Terwilliger 理論に問題設定がない、という意味です。両者は包含関係ではなく、1つの代数 AN = T(0) を共有する、異なる方向への拡張です。
