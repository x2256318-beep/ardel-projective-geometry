# アーデル射影幾何学の基本構造と、既存の枠組みとの比較

（2026-11-16。基礎文書の骨格（2026-11-15）と Part 259 までの形式化にもとづく概要。著者の定義・読みの層と、Lean で形式化済みの内容を区別して書く。）

## 1. 一言でいうと

アーデル射影幾何学は、素数と無限素点を「点」とし、それらが制限積の因子として最初から並んで共存する全体を大域対象とする幾何である。新規性は個々の定理ではなく設計にある。設計の要素は次の 4 つ。

- 何を点とするか
- 何を大域対象とするか
- 無限素点をどう貼り合わせるか
- 全体をどう見るか（解像度）

## 2. 基本構造（4 つの層）

### 2.1 点と大域対象（著者の定義）

- 点は素数 2, 3, 5, … と無限素点 ♾️ である。
- 大域対象は、これらの素点が制限積の因子として最初から並列に共存している全体である。
- 有限レベル（法 N による商）と Λ 切断は、その全体への「見方（切り方）」であり、互いに直交する二つの軸である。
- 基礎は離散的であり、直線のような連続対象は基礎に存在しない。

### 2.2 無限素点の貼り合わせ（著者の定義と公準）

- 無限素点では無限大と無限小が重なり合う。著者はこの重なりを「境界ユニタリ U によるねじれた貼り合わせ」と読むと決めた（2026-11-12）。
  - 両端を群の商として同一視する読みは、公準 A1 と両立しないので採らない。
- モノグラフ層では、イデール類群 C_ℚ 上の作用素系（D、T_p、W）を扱う。中心の問い P1 は、自己共役拡張の境界条件 U の両立の分類である（定理 2.6）。
- 公準 A1 の内容は Tate の定理（γ 因子の貼り合わせ）である。A1 は公準として置いており、導出していない。

### 2.3 解像度（著者の定義と読み）

- 解像度の読み L1：解像度は「測る素点の集合」である。解像度を決めるパラメータは未決定であり、N・K・Λ のいずれとも同一視しない。
- 著者の定義（要旨）：完備化（極限）に逃げ込んで連続体に滑り落ちることを、解像度が落ちるという。目標は、極限でも離散構造の観測を保つことである。極限は、すべての素点を同時に測る直極限の側で取る。
- 完備化（L²、ℝ、直積の位相）を使うときは、「解像度が落ちる側の操作」と読む。

### 2.4 設計についての定理（Lean で形式化済み）

- **Part 255（PAG259.lean）**：有限個の素数が生成する部分群の像について。
  - 測らない素数が 2 個以上あるときに限り、閉包に無限素点の座標方向の直線（ℝ × {k}）が現れる。
  - すべてを同時に測れば、像は閉かつ離散になる。
  - 対照群の関数体 F_q(t) では、ノルムの像が q^ℤ なので直線は現れない。
  - 証明の部品（S 単数定理・積公式・弱近似）は既知である。
- **Part 258（PAG262.lean）**：N ∣ M のとき、次の 3 条件を満たす写像 A_N → A_M が存在するのは gcd(N, M/N) = 1 のとき、かつそのときに限る。
  - 単位元を保つ代数準同型である。
  - 引き戻しと両立する。
  - 殻を混ぜない。
- **Part 259（PAG263.lean）**：
  - Part 258 の条件にフーリエとの両立を足すと、写像は一意になる（`shellLift`）。
  - フーリエとの両立を外すと、a = 2 では一意でない。
  - 添字の順序（古典的なユニタリ約数の関係）は有向でない。
  - 無平方数の段は帰納系をなす。

ここで A_N は殻代数で、既知の Terwilliger 代数 T(0) と同じものである。

## 3. 正直な現状

- 形式化した定理・補題は約 3,640 個ある。その大半は既知の事実の再導出である。
- 新規性の候補は、小さいものが 2 つある。生成の分類と、β の不存在である。どちらも文献照合（MathSciNet・zbMATH）が済んでいないので、新規性としては使わない。
- 本理論はリーマン予想へのアプローチではない。
- 開いている問い：
  - 有限レベルの帰納系が T(0) の側に届くか（方向 γ の文献照合）。
  - 解像度の操作に、L1 を超える定式化が要るか。
  - 基礎文書の起草（著者側）。

## 4. アデール幾何（標準理論）との比較

**共通点**
- 素点を並べた制限積を大域対象とする点は、アデールそのものである。
- 公準 A1 の中身は Tate の定理である。
- A_N は既知の Terwilliger 代数である。

**相違点（設計の選択）**
1. **連続体の扱い**：標準理論は各素点での完備化（ℚ_p、ℝ）から出発する。本理論は基礎を離散に置き、完備化を「解像度が落ちる操作」と読む。
2. **無限素点**：標準理論では無限素点は ℝ の 1 因子にすぎない。本理論は、無限大と無限小の重なりを境界ユニタリ U による貼り合わせと読む。
3. **解像度**：「どの素点を測るか」で見え方を切り替える操作を、幾何の中心に置く。ただし、切り替えで起きること自体は既知の部品で説明できる（Part 255）。

## 5. Connes（と Consani）の枠組みとの比較

**Connes の枠組みの概要**
- アデール類空間 A_K/K×（アデールを大域体の乗法群で割った商）を考える。リーマン–ヴェイユの明示公式は、この空間上のスケーリング作用の跡公式として解釈される。
- 近年は算術サイトとスケーリング・サイトがある。スケーリング・サイトの点は、アデール類空間を極大コンパクト部分群で割った商と一致し、熱帯曲線の構造を持つ。標数 1 の代数を使う。

**重なる点**
- モノグラフ層の舞台（C_ℚ 上の作用素系）は、Connes のスペクトル的な描像とほぼ同じ場所にある。
- 定理 2.6 の極限の側は、Burnol の定理の範囲にある。

**違う点**
1. **ねらい**：Connes の企ての中心は、リーマン予想と同値な不等式にある。本理論はその方向を取らない。モノグラフ §5 には、零点に近づく試みが外からの注入や循環論法に行き着いたことが、否定的な結果として記録されている。
2. **商の取り方**：Connes は、ℚ× で割った非可換な商（とトポス）を主役にする。本理論は、素点の並ぶ全体を割らずに置き、切り方（解像度）で見え方を変える。
3. **連続体**：Connes の空間では ℝ₊× のスケーリング作用が本質的である。本理論では、連続体への移行は「解像度が落ちる操作」と読む。

## 6. Arakelov 幾何との比較

**Arakelov 幾何の概要**
- Spec ℤ（素数の集合）に無限素点に当たる点を足して、「コンパクト化」する。
- 無限素点の情報の代わりに、ベクトル束にエルミート計量を載せる。
- これにより、算術曲面の交点理論や算術 Riemann–Roch の定理（Faltings、Gillet–Soulé）が得られる。積公式が重要な役割を果たす。

**重なる点**
- 「点＝素数＋無限素点」という点集合は、ほぼ同じである。
- Part 255 は積公式を部品に使っている。

**違う点**
1. **無限素点に載せるもの**：Arakelov 幾何は計量（解析的データ）を載せる。本理論は、重なりを境界ユニタリ U による貼り合わせと読む。
2. **道具立て**：Arakelov 幾何には、因子・交点数・算術次数がある。本理論には、まだこれらに当たる量がない。
3. **ねらい**：Arakelov 幾何はディオファントス幾何の道具である。本理論の主題は解像度と見え方である。

## 7. 位置づけ（解釈。確信度：中）

- 本理論は、「Arakelov 幾何の点集合を、Connes の作用素の言葉で貼り合わせ、解像度で見る」と位置づけられる。
- 裏返せば、点集合・作用素・貼り合わせのそれぞれに強い先行がある。新しさは、それらの組み合わせ方と、解像度という見方の置き方にある。
- 因子や次数のような量を持たないことは、今後の課題である。
- アデール類空間を Arakelov 幾何の言葉で扱う最近の試みとして、Connes–Consani の *On the Jacobian of Spec ℤ*（2026）がある。要旨によれば、有理数のアデール類空間のリーマン部分を Spec ℤ のピカール群の拡張として解釈し、そこでの付加データは Arakelov 幾何の計量つき直線束を拡張したものになる。両者の橋渡しとして文献照合の候補になる（本文は未読）。
