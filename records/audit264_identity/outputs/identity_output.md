# 照合者の成果物：PAG264 の恒等の法則 3 定理（fsum_self、cornerOp_self、cornerHom_self）— 出力の全文

3 定理とも定義を開けばすぐ出る文で、仮定を満たす具体例はあります。外せる仮定はありませんでした。NeZero N を外すと、文がそもそも型として書けなくなります。ただし恒等の法則が確かめるのは「N = N のとき全部が恒等に潰れる」ことだけで、正規化の因子 N/M の値や pull・fsum の向きは確かめていません。

## 1. 逆翻訳

**使う定義**（記号は説明のためのもの）

- **約分の写像 π**：N が M を割るとき、π は ℤ/M から ℤ/N への「N で割った余りを取る」環準同型（`ZMod.castHom h (ZMod N)`）。
- **pull**：ℤ/N 上の複素数値関数 f を ℤ/M 上の関数 y ↦ f(π(y)) に送る（引き戻し）。
- **fsum**：ℤ/M 上の関数 g を、ℤ/N 上の関数 x ↦ Σ_{y ∈ ℤ/M, π(y) = x} g(y) に送る（ファイバーの和、押し出し）。
- **cornerOp**：ℤ/N 上の関数の空間の任意の ℂ 線形作用素 S に対し、ℤ/M 上の関数の空間の作用素 (N/M)·(pull ∘ S ∘ fsum) を返す。N/M は複素数としての割り算です（(N : ℂ) が先に型づけされ、M は ℂ に持ち上がる）。
- **shellAlg N**：ℤ/N 上の関数の空間の線形作用素全体の中で、次の 2 種類の作用素で生成される ℂ 部分代数。
  - 関数 geps N s（s は自然数）による畳み込み作用素。
  - 関数 dind N s による掛け算作用素。
  - geps と dind の中身は入力では省かれています（「殻の指示関数」と説明されている）。
- **cornerHom**：shellAlg N から shellAlg M への単位元を保つとは限らない（非単位的な）ℂ 代数準同型で、S を cornerOp(S) に送る。像が shellAlg M に入ることは補題 cornerOp_mem によりますが、その文は入力にありません。

**3 定理**（どれも「N は正の整数」という仮定 NeZero N だけを持ちます。節で宣言された M と NeZero M は文に現れないので、現在の Lean 4 の変数の取り込み規則では引数に入りません。確信度：中〜高。仮に入っても、満たせる仮定が 1 つ増えるだけで害はありません。）

- **fsum_self**：任意の正の整数 N と、ℤ/N 上の任意の複素数値関数 g について、g を恒等の約分 π: ℤ/N → ℤ/N に沿ってファイバーごとに足した関数は g 自身に等しい。つまり、すべての x で Σ_{y ≡ x (mod N)} g(y) = g(x)。
- **cornerOp_self**：任意の正の整数 N と、ℤ/N 上の関数の空間の任意の ℂ 線形作用素 S（shellAlg に属するとは限らない）について、(N/N)·(pull ∘ S ∘ fsum) = S。ここで pull と fsum は N ∣ N に対するもの。
- **cornerHom_self**：任意の正の整数 N について、N ∣ N に対する cornerHom は、shellAlg N の恒等写像（非単位的代数準同型としての恒等）に等しい。つまり、shellAlg N のすべての元 S で cornerHom(S) = S。

## 2. 非空虚性の証人

- **fsum_self**：N = 3、g = (a, b, c)（g(0) = a、g(1) = b、g(2) = c）とします。π は恒等なので、x の上のファイバーは {x} だけです。fsum g = (a, b, c) = g。N = 1 なら g は定数 c 1 つで、fsum g = c。**自明**です（定義と「恒等の約分は恒等」から出る）。
- **cornerOp_self**：N = 2、S を行列単位 [[0,1],[0,0]]（(a, b) ↦ (b, 0)）とし、g = (a, b) とします。fsum g = (a, b)、S を当てて (b, 0)、pull しても (b, 0)、係数 2/2 = 1 なので cornerOp(S) g = (b, 0) = S g。この S は shellAlg に入っているかどうかを問わない、作用素全体の中の例です。**自明**です（fsum_self、pull_self、N/N = 1 の 3 つから出る）。
- **cornerHom_self**：N = 2、S = 1（恒等作用素）とします。Algebra.adjoin は部分代数なので 1 を必ず含み、shellAlg 2 は空ではありません。このとき cornerHom(1) = (2/2)·pull ∘ fsum = 1 で、この特別な場合には cornerHom は単位元を保ちます。生成元 mulLeft(dind 2 s) も構成上 shellAlg 2 に入り、それ自身に送られます。**自明**で、内容は cornerOp_self を shellAlg N に制限したものです。

## 3. 除去テスト

**NeZero N を外す**

- **fsum_self**：文が書けません。fsum の中の `univ` には ℤ/N が有限であることが要り、Mathlib ではそれが NeZero に依存します。N = 0 だと ZMod 0 = ℤ で無限集合です。この仮定は「真であるため」ではなく「文が書けるため」に要るので、反例の作りようがありません。
- **cornerOp_self**：同じ理由で文が書けません（cornerOp は内部で fsum を使う）。仮にもし書けたとしても、Lean の規約では (0 : ℂ)/0 = 0 なので cornerOp は 0 になり、S ≠ 0 で恒等の法則は成り立たなくなります。証明の中で N ≠ 0 が真偽に効くのは div_self の 1 か所だけです。
- **cornerHom_self**：shellAlg N の定義自体が [NeZero N] を要求するので、文が書けません。
- **補足（3 定理の外）**：使われている補題 pull_self は、NeZero N を外しても成り立つように見えます。ZMod 0 = ℤ でも、恒等の約分 ℤ → ℤ は恒等の環準同型です。この補題ではその仮定は不要に見えます。

**dvd_refl N を一般の N ∣ M に替える**

3 文とも、両辺の型が違うので書けません。fsum h g は ℤ/N 上の関数で、g は ℤ/M 上の関数です。cornerOp と cornerHom も、両辺が別の空間の作用素・別の代数の写像になります。そこで、意味の通る類似の文で反例を探しました（N = 1、M = 2）。

- **fsum ∘ pull = 恒等**：偽です。f ≡ 1 なら fsum(pull f) ≡ 2 で、一般には fsum ∘ pull = (M/N)·恒等。
- **pull ∘ fsum = 恒等**：偽です。g = (1, 0) なら fsum g = 1、pull で (1, 1) となり (1, 0) と一致しません。
- **cornerOp(1) = 1**：偽です。cornerOp(1) g = ½(g(0) + g(1))·(1, 1) で、g = (1, 0) なら (½, ½) ≠ (1, 0)。cornerOp(1) は「ファイバー上で定数な関数」への平均の射影です。冪等で、階数は N です。
- **cornerHom(1) = 1**：shellAlg 1 も 1 を含むので、上と同じ反例で偽です。

したがって、恒等になるのは対角 N = M の場合に特有です。

**証明の取り方**：Lean では命題の証明は定義上区別されないので、dvd_refl N を N ∣ N の任意の証明に替えても同じ文になります。

## 4. 気づいた点

- **(a) 恒等の法則は正規化の因子を確かめない。** 文が真になるのは、因子 c(N, M) が c(N, N) = 1 を満たすときだけです。そのため c = 1（正規化なし）、c = (N/M)²、c = √(N/M) など、どれでも恒等の法則は成り立ちます。N/M と ℕ の割り算 ⌊N/M⌋ の取り違えもここでは検出できません（形式文では ℂ の割り算になっています）。因子を一つに決めるのは乗法性のほうです。cornerOp(S)·cornerOp(T) = c²·(M/N)·pull ∘ ST ∘ fsum なので、c = N/M が要ります。乗法性を示す cornerOp_mul の文は入力にないので、私は照合していません。
- **(b) 向きの取り違えも確かめない。** N = M では pull も fsum も恒等なので、両者の役割を入れ替えても、π の向きを誤っても、この 3 文は成り立ちます。入力の定義を読む限り向きは整合しています。fsum は ℤ/M の関数から ℤ/N の関数へ、pull は ℤ/N の関数から ℤ/M の関数へ、cornerOp は「押し出す → S を当てる → 引き戻す」の順です。
- **(c) 部分代数上の恒等と作用素全体での恒等。** cornerHom_self が言うのは shellAlg N 上の恒等だけで、作用素全体についての主張は cornerOp_self が別に持っています。cornerOp_self のほうが強い文で、cornerHom_self はその制限です。食い違いはありません。等式は非単位的代数準同型としての等式ですが、恒等写像は自動的に 1 を 1 に送ります。
- **(d) 名前と未使用の変数（体裁の問題）。** 節の名前は uniq（一意性）なのに中身は恒等の法則です。節で M と [NeZero M] を宣言していますが、3 定理では使っていません。
- **(e) fsum の引数（確かめられない点、影響なし）。** fsum_add に `omit [NeZero N] in` が付いているので、fsum の型は [NeZero N] を取らないのだと読めます。ただ、def での変数の取り込み規則をこの入力だけからは確かめられません（確信度：低〜中）。どちらであっても fsum (dvd_refl N) では両方の NeZero が NeZero N で埋まるので、3 定理には影響しません。

文が意図と違う意味に読める箇所（添字の取り違えなど）は見つかりませんでした。上の (a)・(b) は「この法則では確かめられない」という限界の指摘です。
