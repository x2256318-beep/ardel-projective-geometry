## 定義
N を正の整数とし、ℤ/N 上の複素数値関数の空間 V_N = ℂ^{ℤ/N}（標準の内積）を考える。
- 単数群 (ℤ/N)^× が掛け算で ℤ/N に作用する。軌道は「gcd(N, x) = s」（s は N の約数）で決まる集合 S_s である。これは対称なアソシエーションスキーム（円分的なスキーム、ℤ/N の単数の軌道によるシューア環から来るもの）を与える。
- D_s：S_s の指示関数を掛ける作用素（基点 0 に関する双対べき等元 E*_s にあたる）。
- E_s：離散フーリエ変換の側で、周波数 ξ が gcd(N, ξ) = s のところだけを残す射影（スキームの原始べき等元にあたる）。
- A_N：End(V_N) の中で D_s, E_s（s ∣ N）が生成する代数（基点 0 での Terwilliger 代数 T(0)）。
- N ∣ M のとき、π: ℤ/M → ℤ/N を射影、π^*: V_N → V_M を引き戻し（f ↦ f∘π）、ι = π^*/√(M/N)（等長写像）、Q = ι ι^†（N 周期の関数への直交射影）とする。φ(T) = ι T ι^†（T ∈ End(V_N)）。
- また V: V_N → V_M を、部分群への埋め込み x ↦ (M/N)·x に沿った 0 拡張（等長写像）とし、P = V V^†（部分群 (M/N)ℤ/Mℤ の指示関数の掛け算）、ψ(T) = V T V^† とする。
