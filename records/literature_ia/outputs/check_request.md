## 記号

- ξ：法 N の原始 Dirichlet 指標（N ≥ 1）。a = 0（ξ(−1) = 1、偶）または a = 1（ξ(−1) = −1、奇）。
- τ(ξ) = Σ_{x mod N} ξ(x) e^{2πix/N}（ガウス和）。
- W(ξ) = τ(ξ)/(i^a √N)。古典的な関数等式 Λ(s, ξ) = W(ξ) Λ(1 − s, ξ̄)、Λ(s, ξ) = (N/π)^{(s+a)/2} Γ((s+a)/2) L(s, ξ) のルート数。
- 規約 T：ψ_∞(x) = e^{−2πix}、ψ_p(x) = e^{+2πi{x}_p}（{x}_p は p 進の小数部分）。
- 規約 C：ψ_∞(x) = e^{+2πix}、ψ_p(x) = e^{−2πi{x}_p}。
- ξ に対応するイデール類指標 χ = ⊗ χ_v：不分岐の ℓ ∤ N で χ_ℓ(ℓ) = ξ(ℓ)。p ∣ N では χ_p を ℤ_p^× に制限したものが (ξ^{(p)})^{−1}（ξ = ∏_{p∣N} ξ^{(p)} は中国剰余定理による分解、ξ^{(p)} は法 p^{v_p(N)} の指標）。χ_∞ は a = 0 で自明、a = 1 で符号。
- 局所 ε 因子は Tate の局所関数等式の定数。測度は ψ_v に関して自己双対なもの。

## 主張

- **C1**（文献の規約）：Tate の学位論文（1950）の大域加法指標は規約 T である。
- **C2**（無限素点）：規約 T で ε(s, sgn, ψ_∞) = −i（s によらない）、ε(s, 1, ψ_∞) = 1。規約 C では sgn に対して +i。
- **C3**（有限素点の積、規約 T）：p ∣ N で ε(0, χ_p, ψ_p) = ∫_{p^{−k}ℤ_p^×} χ_p^{−1}(x) ψ_p(x) dx（k = v_p(N)）とすると、∏_{p∣N} ε(0, χ_p, ψ_p) = τ(ξ)。ここで χ_p(p) = ∏_{ℓ∣N, ℓ≠p} ξ^{(ℓ)}(p)（χ が ℚ^× の上で自明なことから）。したがって s = 1/2 での有限素点の積は τ(ξ)/√N。
- **C4**（有限素点の積、規約 C）：同じ χ で ψ_p を規約 C に替えると、積は ξ(−1)τ(ξ) になる（s = 1/2 で ξ(−1)τ(ξ)/√N）。
- **C5**（大域）：どちらの規約でも、無限素点の ε と有限素点の積の積は W(ξ) になる。規約 T の ψ_p と規約 C の ε_∞ を組み合わせると、奇の ξ ではすべて合わない。
- **C6**（ある変換との比較）：関数 ε(ξ) = ((1 − i) + (1 + i) ξ(−1))/2 は、偶で 1、奇で −i であり、規約 T の ε(1/2, χ_∞, ψ_∞) と一致する。また離散 Hartley 核 cas(2πt/N) = cos(2πt/N) + sin(2πt/N) について、Σ_x ξ(x) cas(2πxy/N) = ε(ξ) τ(ξ) ξ̄(y)（ξ 原始、y は任意）。
