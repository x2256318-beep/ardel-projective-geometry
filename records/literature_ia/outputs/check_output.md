## C1：加法指標については正しい。ただし注記あり（確信度：高。注記の部分は中）

**文献**：[Tate1950.pdf（Rutgers の走査版）](https://sites.math.rutgers.edu/~ak1230/2023S572/Tate1950.pdf)

- §2.2 Case 1（実数体）：λ(x) = −x (mod 1) とあり、本文に "(Note the minus sign)" と書かれています。
- §2.2 Case 2（p 進）：λ(x) は「λ(x) − x が p 進整数」となる有理数です。
- 指標は e^{2πiΛ(ξ)}、Λ = λ∘Tr です。§4.1 Lemma 4.1.5 に、大域の Λ が k の上で 0 になることが書かれています。
- したがって ψ_∞ = e^{−2πix}、ψ_p = e^{+2πi{x}_p} で、規約 T です。

**二次文献**：[RSY arXiv:2109.07649](https://arxiv.org/pdf/2109.07649) の §4.3 に "Let ψ be the character of Q\A defined in Tate's thesis" とあり、ψ_∞(x) = e^{−2πix} です。

**注記 1（Fourier 変換の符号）**

- Tate の学位論文の Fourier 変換の核は e^{−2πiΛ(ξη)} と読めます。実数体では e^{+2πixy} なので、変換には規約 C の指標を使っていることになります。
- 局所の定数も、ζ(f, c) = ρ(c)ζ(f̂, ĉ) という逆向きの比として書かれています。
- §2.5 の実数体の奇の場合には −i が現れます。これは ε(1−s, χ⁻¹, ψ_T) = −i と整合します。
- ただし式の部分は OCR が崩れていて、ページ番号も読めません。確信度は中です。
- C2〜C5 の ε の定義は、学位論文そのものではなく Corvallis 論文の流儀です。

**注記 2（手がかりの 1502.02633）**

- [arXiv:1502.02633](https://arxiv.org/abs/1502.02633) の無番号の "Notations" 節には、ψ_ℝ = e^{−2πix} と ψ_{ℚ_p} = e^{2πiλ(x)} が書かれています。
- しかし、Tate の学位論文に従うと明記しているのは **Haar 測度の正規化**だけです（"normalized following Tate's Thesis"）。指標は「標準の加法指標」として書かれています。
- 依頼文の「Tate の学位論文の規約として ψ を書いている」は言い過ぎです。

**Burnol**：[ar5iv の math/9811040](https://ar5iv.labs.arxiv.org/html/math/9811040)（"Spectral Analysis of the Local Conductor Operator"）も規約 T です。実数体で exp(−2πit)、有限素点で exp(2πi{Tr t}) です。読んだ範囲には、Tate の規約への言及も、符号の選び方の説明もありません。

**逆の規約の例**：どちらも規約 C であることを確認しました。

- [arXiv:2604.25288](https://arxiv.org/abs/2604.25288)（Holland）の §5.1：ψ_∞ = e^{2πix}、ψ_p = e^{−2πi{x}_p}。
- [arXiv:1511.04265](https://arxiv.org/abs/1511.04265) の (3.72)〜(3.75)：ψ_p = e^{−2πi[u_p x_p]_p}、ψ_∞ = e^{2πiu_∞x_∞}。符号の違いは ℚ 上で自明にするためだと本文に書かれています。

**直した文の案**：「Tate の学位論文の大域加法指標 e^{2πiΛ}（Λ_∞(x) = −x、有限素点は p 進小数部分）は規約 T である。ただし同論文の Fourier 変換は e^{−2πiΛ(ξη)} を核とし、局所の定数は ρ(c) として逆向きに定義されている。」

## C2：正しい（確信度：高）

**導出**

- f = x e^{−πx²} とすると、ψ = e^{−2πix} で f̂ = −i f です。
- Z(s, sgn, f) = L_ℝ(s, sgn) なので、ε = −i です。
- 自明な指標では f = e^{−πx²} が自己双対なので、ε = 1 です。
- 規約 C：ε(s, χ, ψ_a) = χ(a)|a|^{s−1/2} ε(s, χ, ψ) で a = −1 とすると、+i になります。

**数値**（局所関数等式の数値積分、s = 0.3, 0.5, 0.8）

- 規約 T の sgn は −1.000000i、規約 C の sgn は +1.000000i です。
- 自明な指標は両規約とも 1 です。
- s によりません。

**文献**：RSY の式 (155) に、ψ_∞ = e^{−2πix} で ε = 1（自明）、−i（sgn）とあります。

**確かめられなかったこと**：規約 C の +i を直接書いた文献の箇所は見つけていません（Corvallis 論文は開いていません）。

## C3：正しい（確信度：高）

**導出**

- 局所の式：f = 1_{u₀+p^mℤ_p} として局所関数等式を計算すると、ε(s) = ∫_{p^{−k}ℤ_p^×} χ⁻¹(x)|x|^{−s}ψ(x)dx = p^{−ks}·ε(0) です。k より小さい殻では積分は 0 になります。
- x = p^{−k}u と置くと、ε(0) = χ_p(p)^k · τ_{p^k}(ξ^{(p)}) です。
- χ(p) = 1 から、χ_p(p) = ∏_{ℓ∣N, ℓ≠p} ξ^{(ℓ)}(p) が出ます。これは C3 と一致します。
- 積：∏_p χ_p(p)^{k_p} = ∏_ℓ ξ^{(ℓ)}(N/ℓ^{k_ℓ}) です。中国剰余定理によるガウス和の分解 τ(ξ) = ∏_p ξ^{(p)}(N/p^{k_p}) τ(ξ^{(p)}) と合わせると、積は τ(ξ) になります。
- s = 1/2 では各因子に p^{−k/2} が掛かるので、積は τ(ξ)/√N です。

**数値**

- 局所関数等式から求めた値と Tate の式の差：最大 3.1e−13（s = 0, 0.37, 0.5、両規約）。
- 積と τ（s = 0）、積と τ/√N（s = 1/2）の差：最大 1.6e−13。

**文献**：RSY の Lemma 6.1 の (156) と (157) が、C3 の式そのものです（証明は "exercise"）。対応の規約は (150) の ∏_{p∣u} χ_p(a) = ξ(a)⁻¹ で、依頼文と同じです。RSY は p ∣ u での χ_p(p) を書いていません。

## C4：正しい（確信度：高）

- 導出：e^{−2πiu/p^k} にすると、各因子は ξ^{(p)}(−1)τ(ξ^{(p)}) になり、符号の積は ξ(−1) です。ψ_p の導手は ℤ_p のままなので、自己双対測度も変わりません。
- 数値：最大誤差 1.8e−12（s = 0 と 1/2）。
- 文献：直接の箇所は確かめていません。

## C5：s = 1/2 でなら正しい（確信度：高）

**数値**

- 大域積と W の差：規約 T で最大 1.8e−14、規約 C で 1.1e−13。
- 一般の s では、積は N^{1/2−s} W(ξ) です（s = 0, 0.21, 0.5, 0.9 で誤差 4.6e−13）。
- W の別の確認：θ(1/t, ξ) = W t^{a+1/2} θ(t, ξ̄) を数値で確かめました（誤差 3.1e−13）。この関係は、Mellin 変換によって古典的な関数等式 Λ(s, ξ) = WΛ(1−s, ξ̄) と同値です。

**規約を混ぜた場合**（規約 T の ψ_p と規約 C の ε_∞）

- 奇の指標は 1,082 個すべてで −W になり、W と合いません。偶の指標は 1,080 個すべてで一致しました。
- 混ぜた ψ は ℚ 上で自明ではなく（x = 1/3 で e^{4πi/3}）、大域の選び方として許されません。

**直した文**：「s = 1/2 で、どちらの規約でも、無限素点の ε と有限素点の積の積は W(ξ) になる（一般の s では N^{1/2−s} W(ξ)）。」

## C6：正しい（ξ が原始のとき、すべての y で。確信度：高）

**導出**：cas θ = ((1−i)/2) e^{iθ} + ((1+i)/2) e^{−iθ} です。原始指標では Σξ(x)e(±xy/N) = ξ(±1)ξ̄(y)τ(ξ) が y について一般に成り立つので、主張の式が出ます。

**数値**

- ε(ξ) と ε_{T,∞} の差：最大 3.3e−14。
- Hartley 和の誤差：全 y で最大 4.2e−12。
- 対照（原始でない指標）：法 4 では y = 0, 2、法 12 では y = 2, 4, 8, 10 で式が崩れます。「ξ 原始」は必要です。

**注記（確信度：中〜高）**

- 数の一致は正しいのですが、√N·W = ε(ξ)·τ(ξ) という分け方が規約 T の「ε_∞ × 有限素点の積」と一致するのは、規約を T に取ったからです。
- 規約 C では、分け方は i^a × ξ(−1)τ(ξ) になります。
- 引数の符号を逆にした cas(−2πxy/N) では ξ(−1)√N W となり、奇の指標では −W になります（誤差 6.2e−13）。
- 大域の W は規約によりませんが、無限素点と有限素点への分け方は規約によります。したがって、この等式だけから「ε(ξ) は無限素点から来る」とは言えません。
