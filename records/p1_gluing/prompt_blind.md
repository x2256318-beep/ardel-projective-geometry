## 定義

p は素数、K ≥ 1、N = p^K。e(t) = exp(2πi t/N)。法 N の Dirichlet 指標 χ について：
- ガウス和 τ(χ) = Σ_{x mod N} χ(x) e(x)。ヤコビ和 J(χ1, χ2) = Σ_{x mod N} χ1(x) χ2(1 − x)。Ĵ = J/√N。
- 𝔀(χ) = τ(χ)/(i^a √N)（a = 0：χ(−1) = 1、a = 1：χ(−1) = −1）。
- 射影直線 P¹(ℤ/N) の 2 チャートのモデル：P¹ の上の関数を、南のチャートの関数 F_S : ℤ/N → ℂ（点 [x : 1]）と北のチャートの関数 F_N : ℤ/N → ℂ（点 [1 : y]）の組で、単数 y について F_N(y) = F_S(y⁻¹) を満たすものとする（単数の集合を赤道と呼ぶ）。
- 南の畳み込み B_S(F, G) = 南のチャートで F_S と G_S を畳み込み（(F_S * G_S)(x) = Σ_y F_S(y) G_S(x − y)）、上の貼り合わせで北に延ばしたもの（北の非単数の点では 0）。北の畳み込み B_N(F, G) は同じことを北のチャートで行ったもの。
- 赤道のケット k_χ：南のチャートで単数 x に χ(x)、非単数に 0 をとり、貼り合わせで北に延ばした関数。
- 既に示されている事実（前提として使ってよい）：χ1, χ2, χ1χ2 が原始的なとき、B_N(k_{χ1}, k_{χ2}) = conj(Ĵ(χ1, χ2))² · B_S(k_{χ1}, k_{χ2})。

## 問い

Q1. χ1, χ2, χ1χ2 が原始的なとき、conj(Ĵ(χ1, χ2))² を 𝔀(χ1)、𝔀(χ2)、𝔀(χ1χ2) で表せるか。2 乗を外した形でも表せるか。p = 2 ではどうなるか。
Q2. 赤道のケットの上で、指標 χ の成分に 𝔀(χ) を掛ける対角作用素 U を考える。B_N と B_S は U でどう結ばれるか（B_N(k1, k2) = U^m B_S(U^{−m} k1, U^{−m} k2) となる m はあるか）。
Q3. 対角作用素 U'（χ の成分に絶対値 1 の φ(χ) を掛ける）が、Q2 と同じ関係を満たすのはどんな φ のときか。解の集まりの大きさと構造（単数倍の作用、指標ごとの符号との関係）。素朴な値 τ(χ)/√N はその中のどれか。
Q4. 有理数体の代わりに関数体 F_q(t)（ℤ/p^K の代わりに F_q[t]/(P^K)）で、Q1〜Q3 の答えは同じ形か。
Q5. Q1〜Q4 全体として、既存の結果の当てはめで済まない部分（新しい数学の内容）は残るか。どの文献が答えを持っているか。
