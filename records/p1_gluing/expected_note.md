  理由：τ1τ2 = J τ12（原始的な積）と |τ|² = N から、conj J/J = N τ12²/(τ1²τ2²)。τ² = 𝔀² χ(−1) N で、符号 χ(−1) は χ1χ2 の符号と打ち消す。［既知］（ヤコビ和はガウス和の比。古典）。
  1 乗の版（2 乗を外したもの）は一般に成り立たない。p = 2 では原始指標 3 つがそろう組がなく、赤道の定理そのものが空。
- **Q2（読み）**：U を指標 χ の成分に 𝔀(χ) を掛ける作用素とすると、赤道のケットについて B_N(k1, k2) = U² B_S(U⁻²k1, U⁻²k2)。北の畳み込みは、南の畳み込みを U² で移したもの。
