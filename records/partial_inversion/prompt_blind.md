## 定義

- 正の整数 N（2 つ以上の素因数を持つ場合を含む）について、P¹(ℤ/N) を ℤ/N 上の射影直線とする（単模な組 (a, b) を単数倍で割ったもの）。中国剰余定理で P¹(ℤ/N) ≅ ∏_{p∣N} P¹(ℤ/p^{k_p})（k_p = v_p(N)）。
- Q ∥ N（Q ∣ N かつ gcd(Q, N/Q) = 1）について、部分反転 w_Q : P¹(ℤ/N) → P¹(ℤ/N) を、法 Q の成分では [a:b] ↦ [b:a]、法 N/Q の成分では恒等、と定める。w_N は全体の反転 [a:b] ↦ [b:a]。
- X_N ⊂ P¹(ℤ/N) を、点 [x:1]（x ∈ ℤ/N）と点 [1:y]（y ∈ ℤ/N は単数でない）の集合とする。
- 赤道 (ℤ/N)^× を [u:1] として P¹(ℤ/N) に入れる。w_Q は赤道を保ち、u ↦（法 Q で u⁻¹、法 N/Q で u）と働く。
- P_N を法 N の原始ディリクレ指標の集合とする。χ ∈ P_N は χ = ∏_{p∣N} χ_p（χ_p は法 p^{k_p} の原始指標）と分かれる。χ^{(p)} を、χ_p だけを共役 χ̄_p に替えた指標とする（χ ∘ w_{p^{k_p}} = χ^{(p)}）。
- 関数 α : P_N → U(1)（単位円周）を考える（とくに何の公理も課さない）。条件 (L)：各 p ∣ N について、比 α(χ^{(p)}) / α(χ) が χ_p だけで決まる（他の成分 χ_q によらない）。
- Loc を、α(χ) = ∏_p f_p(χ_p) の形の関数全体（f_p : 法 p^{k_p} の原始指標 → U(1)）とする。S を (L) を満たす α 全体とする（どちらも各点ごとの積で群）。

## 問い

Q1（舞台）. X_N は全体の反転 w_N では閉じるが、部分反転 w_Q では一般に閉じない。部分反転で閉じさせると P¹(ℤ/N) 全体になるか。P¹(ℤ/N) の上の部分反転の群（(ℤ/2)^{ω(N)}）の作用は、既存の文献で何と呼ばれ、どこに書かれているか（たとえば Atkin–Lehner 対合、Γ₀(N) のカスプ、モジュラー記号・Manin 記号の P¹(ℤ/N) との関係など）。添字集合 {Q ∥ N}（ユニタリ約数）が現れる既知の文脈を挙げよ。

Q2（解の群）. S / Loc（Loc を法とした S）はどう記述できるか。各成分の共役類 {χ_p, χ̄_p} の組だけで決まる関数の群になるか。

Q3（追加条件）. 次の条件を加えると S / Loc はどこまで小さくなるか。
- (G1) 反転・実性の条件：α(χ̄) = α(χ)⁻¹·c(χ)（c はパリティ χ(−1) だけで決まる既知の因子）の形の条件。
- (G2) 互いに素な分解 N = ab での整合：法 a・法 b の族 α_a, α_b と法 ab の α_{ab} が、χ = χ_a χ_b について α_{ab}(χ) = α_a(χ_a) α_b(χ_b) · κ(χ_a, χ_b) の形（κ は指標の値 χ_a(b)、χ_b(a)、パリティだけで書ける既知の因子）で結ばれる、という条件。
とくに、S / Loc がパリティ (χ_p(−1))_{p∣N} だけの関数まで縮むか、縮まないか。

Q4（既知の例）. α(χ) = τ(χ)/(i^a √N)（τ はガウス和、a ∈ {0, 1} は χ(−1) = (−1)^a で決まる）は (L) を満たすか。満たすなら、その S / Loc の類は何か（パリティの二次形式のようなものになるか）。この類は、χ(−1) の符号を「無限素点」と「有限素点」のどちらの局所定数に入れるかという規約によらないか。根数・局所定数（Tate、Deligne、Langlands）や、ガウス和の積の公式 τ(χ_a χ_b) = χ_a(b) χ_b(a) τ(χ_a) τ(χ_b) との関係で説明せよ。

Q5（関数体）. 同じ問い（Q2〜Q4）を、関数体 F_q(t) のディリクレ指標（F_q[t] の多項式を法とする指標、∞ での局所定数を含む）で考えると、同じ形の答えになるか。違いがあれば何か（とくに、パリティに当たる「F_q^× への制限」が ∞ の局所定数に入るかどうか）。

Q6（文献）. この種の問い（局所的な共変性の条件を満たす指標の関数の群を、局所の積を法として分類する。部分的な共役・部分的な反転での振る舞い）が既存の文献にあるか。あれば具体的に挙げよ。
