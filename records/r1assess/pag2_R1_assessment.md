# R1 の査定：互いに素な段だけの帰納系を第5章の材料として確定できるか（2026-11-15）

**追記（同日、Part 259）**：§2〜§4 と §6 の候補 1〜5 を Lean にした（PAG263.lean、`pag2_part259_unitary_step_maps.md`）。個数の式と奇数での一意性は数値のまま。「互いに素な段」は古典的なユニタリ約数（Cohen 1960）である。

方向ラウンドの項目 (b) のうち、R1 だけを扱う。R2・R3 は扱っていない。パートではなく、Lean と xlsx は変えていない。数値は `out/r1assess/`（uniq.py・aut.py・fourier.py とそのログ）。数値は証明ではない。

## 0. 結論

- **条件つきで確定できる。** 第5章に書けるのは「互いに素な段の写像の系」である。ただし文面を次の 3 点で直す必要がある。
  1. 写像は (i)(ii) だけでは一意に決まらない。N が偶数のとき別の写像がある（§2、数値）。標準の写像は `shellLift`（φ(S) = S ⊗ 1）として名前を挙げるか、フーリエとの両立を条件に足して一意にする（§3）。
  2. 添字は整除の順序ではない。「互いに素な段」の順序（N ∣ M かつ gcd(N, M/N) = 1）は有向集合ではない（§4）。帰納極限がとれるのは有向な部分系（無平方数の系など）の上で、極限は制限テンソル積になる（§5）。
  3. そのどの部分系も整除の順序で共終ではない。関数のレベルの極限 ℂ[ℚ/ℤ] の代数版にはならない（§5）。
- 骨格の第5章の文「大域対象の代数的な組み立ては…互いに素な段のテンソル積の系にある」は、上の 3 点を入れずには書けない。

## 1. 問いの置き方

Part 258（PAG262）の (i)(ii) を満たす単位的な代数準同型 φ : A_a → A_{ab}（gcd(a, b) = 1）について、次の 3 つを確かめた。
- 一意か。
- 合成と両立するか（帰納系になるか）。
- 添字の集合は何か。

## 2. 一意性：奇数の a では一意、偶数の a では一意でない（数値）

**φ(D_s) は (i)(ii) から一意に決まる**（手計算、確信度：高）。
- 理由：(ii) から φ(D_s) = Σ_t c_t D_t^{(ab)} と書け、(i) を δ 関数に当てると Σ_t c_t 1[gcd(x, ab) = t] = 1[gcd(x mod a, a) = s] になる。殻の指示関数は一次独立なので、係数がすべて決まる。
- 数値でも、D の側の解空間の余りは全 11 組で 0 次元だった。

**φ(E_s) は、旧い殻の係数しか (i) で決まらない。**
- 新しい殻（π^* の像と直交する殻）の係数は (i) では決まらない。
- E_s は互いに直交するべき等元で、和は 1 である。そのため、新しい殻をどれか 1 つの s に割り振る仕方だけが候補になる。
- 各割り振りが代数準同型に延びるかを、対 (g, φ(g)) の生成する代数の次元が dim A_a に等しいかで判定した。結果は次のとおり。

| (a, b) | 候補 | 準同型になるもの |
|---|---|---|
| (2,3) | 4 | 2 |
| (3,2) | 4 | 1 |
| (2,5) | 4 | 2 |
| (3,4) | 16 | 1 |
| (4,3) | 27 | 2 |
| (2,9) | 16 | 4 |
| (6,5) | 256 | 2 |
| (5,6) | 64 | 1 |
| (4,9) | 729 | 4 |

- 観察：準同型の個数は、a が奇数なら 1、a が偶数なら 2^{d(b)−1} だった（d は約数の個数）。
- 正体：多重度 2 の分は、A_a の自己同型 ψ(S) = χ S χ^{-1}（χ(x) = (−1)^x を掛ける作用素、a が偶数のとき）で説明できる。ψ はすべての D_s を固定し、E_s を入れ替える。フーリエの側で a/2 だけずらすと、殻の分割が保たれるからである。b の新しい殻 u ごとに、ψ を使うかどうかを独立に選べる。φ = id ⊗ E_{旧} + Σ_u (id または ψ) ⊗ E_u の形である。
- D を固定して E を入れ替える自己同型の個数は、a ≤ 10 で調べると、a が偶数なら 2、奇数なら 1 だった（aut.py）。

確信度：
- 一意でないこと：高。具体的な ψ があり、(i)(ii) と準同型であることは手で確かめられる。
- 個数の式 2^{d(b)−1} と奇数で一意：中。数値の 9 組と a ≤ 10 の観察だけで、証明していない。

## 3. 標準の写像の選び方

**条件 (iii)「フーリエと両立する」を足すと一意になる。** (iii) は φ(𝓕⁻¹ S 𝓕) = 𝓕⁻¹ φ(S) 𝓕 という条件である。
- E_s = 𝓕⁻¹ D_s 𝓕 なので、(iii) から φ(E_s) = 𝓕⁻¹ φ(D_s) 𝓕 となる。§2 で φ(D_s) は決まっているので、生成元の像がすべて決まる（手計算、確信度：高）。
- 数値では、各組の準同型のうち (iii) を満たすのはちょうど 1 つで、`shellLift` の割り振り（新しい殻 t を s = gcd(t, a) に送る）だった。調べたのは (2,3)・(2,5)・(4,3)・(2,9)・(6,5) の 5 組。

**合成との両立。**
- (i)(ii)(iii) はどれも合成で保たれる。また、互いに素な段の合成は互いに素な段になる：N ∣ M ∣ L で gcd(N, M/N) = gcd(M, L/M) = 1 なら gcd(N, L/N) = 1。
- したがって、一意性から φ_{M,L} ∘ φ_{N,M} = φ_{N,L} が出て、帰納系になる（手計算、確信度：高）。
- `shellLift` の生成元の公式（`shellLift_dind`・`shellLift_geps`、φ(D_s) = Σ_{u∣b} D_{su}）からも直接確かめられる。

## 4. 添字：互いに素な段の順序は有向でない

- p と p² の両方の上に来る M はない。v_p(M) = 1 と v_p(M) = 2 を同時に満たせないからである（初等的、確信度：高）。
- 順序の構造は素数ごとに分かれる。各 p について指数 0 が最小で、指数 1, 2, 3, … どうしは比べられない。全体はこれらの直積（有限台）である。

## 5. 極限：有向な部分系ごとの制限テンソル積

- 有向な極大部分系は、指数の関数 k : 素数 → ℕ_{≥1} ごとに 1 つある。N が「どの素数 p でも v_p(N) ∈ {0, k_p}」を満たす N 全体である。
- その上の極限は、制限テンソル積 ⊗'_p A_{p^{k_p}}（ほとんどすべての因子で 1 を取る）になる。有限の段では Part 228 の `shellAlgTensorEquiv` が使える。制限テンソル積の極限は標準の構成である［既知］。
- 例：k ≡ 1 は無平方数の系で、⊗'_p A_p になる。
- どの部分系も整除の順序で共終ではない（p² を超える段がない）。関数のレベルで対応する極限は ⊗'_p ℂ[ℤ/p^{k_p}] の側で、Part 197・202 の極限 ℂ[ℚ/ℤ] とは別物である。
- 部分系全体の上で（有向でないまま）余極限をとると、異なる指数の A_{p^k} どうしの融合積になる。自然な対象とは思えない（確信度：中）。

## 6. ラベルと Lean にする場合の候補

ラベル：
- §2 の一意でないことと、§3 の (iii) による一意性：［再導出（小さい）］。議論は初等的で、文献照合はしていない。
- §5：［既知］。

Lean にする場合の候補（パートとして走らせるかは著者の判断。骨格の「章の不足を埋める場合」に当たる）：
1. 互いに素な段の順序が有向でないこと（p と p²）。
2. (i)(ii) を満たす φ では φ(D_s) が一意に決まること。
3. (i)(ii)(iii) を満たす φ は `shellLift` に等しいこと。
4. a = 2・b = 3 で、(i)(ii) を満たす別の準同型が存在すること（χ による捩れ）。
5. 合成との両立。

これで第5章の主張は Lean の文から書ける。個数の式 2^{d(b)−1} は数値の観察のままにする。
