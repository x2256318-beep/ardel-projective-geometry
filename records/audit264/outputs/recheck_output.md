# PAG264 の散文と形式文の再照合（照合者の報告、通知の本文を写したもの）

## 1. 散文が形式文より広い・強い・違う箇所

**1-1. 「単位元を保たない代数準同型」**
- 散文：見出し（「単位元を保たない代数準同型」）、冒頭 15 行（「`cornerHom h : shellAlg N →ₙₐ[ℂ] shellAlg M`。単位元を保たない代数準同型。」）、冒頭 4.(ii)（「この 2 つを満たす単位元を保たない代数準同型 A_N → A_M は、ちょうど 1 つ」）、ノート §1 の写像（`cornerHom : A_N →ₙₐ A_M`）、ノート §1 の一意性。
- 宣言：`cornerHom`、`existsUnique_corner`。
- 違い：型の `→ₙₐ[ℂ]` は「単位元を保つことを課さない」準同型で、単位的なものもこの型に入る。`existsUnique_corner` の ∃! は `→ₙₐ` 全体の中での一意性で、φ(1) ≠ 1 を条件にしていない。Lean にある「単位元を保たない」は、仮定 `hlt : N < M` のもとでの `cornerOp_one_ne_one`・`cornerHom_one_ne_one` だけ。N = M の場合について、形式文は何も言っていない。
- 直し方：「非単位的な代数準同型（`→ₙₐ`。単位元の保存を課さない）。N < M のとき φ(1) ≠ 1（`cornerHom_one_ne_one`）」。確信度：高。

**1-2. 帰納系（恒等の法則が Lean にない）**
- 散文：ノート §1 合成「φ_{M,L} ∘ φ_{N,M} = φ_{N,L}（`cornerOp_comp`・`cornerHom_comp`）。したがって (A_N, φ) は整除の順序全体の上の帰納系をなす。」、冒頭の範囲「合成の文からは組める」。
- 違い：Lean にあるのは合成の法則だけ。帰納系には恒等の法則 φ_{N,N} = id も要るが、それに当たる宣言（`cornerOp` を `h : N ∣ N` で取ると恒等、という文）は形式文にない。「したがって」で帰納系まで言うのは形式文より強い。
- 直し方：「合成の法則は Lean にある（N ∣ M ∣ L）。恒等の法則 φ_{N,N} = id は Lean の外。帰納系としての組み立てと極限は Lean の外」。確信度：高（入力の 42 宣言の中に該当なし）。

**1-3. φ(1) = `oldP` を一般の N ∣ M の文のように書いている**

- 直し方：「M = N·t と書いたとき、Part 202 の `oldP N t` に等しい（`cornerOp_one_apply`）」。

**1-4. D 側の一般化の根拠の書き方が場所ごとに違う**

- 直し方：「N ∣ M、N < M のとき、ある s で φ(D_s) が D_t の span に入らない。(1,2)・(2,6) は手計算、一般の場合は数値（範囲：…）。Lean にあるのは (2,4)・s = 2 のみ」。
