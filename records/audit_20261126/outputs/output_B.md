## 1. 円環（注入→回収）

**1-1　「射影の変換の位相」と「貼り合わせ U の位相」の一致（2.4、2.9、索引 2.9 最終行）**
- 結論：J̃∘H は原始指標に 𝔀(χ) を掛け、これは U_N の固有値と同じ値。索引はこれを「2.5 のユニタリ性の構造上の理由づけとして読める」と書く。
- 依存する入力：Hartley 核の選択。2.4 によればこの核は「A1 の内容と揃う」ように著者の判断で選ばれており、U_N の位相は A1 そのもの（2.6）、`rootNum` は Hartley 核から定義された量。
- 除去テスト：核を素朴なフーリエ核 e(xy) に替えると奇の指標で値が i 倍ずれ、一致は消える（2.4 に記載）。A1 だけを外す（核は据え置き）と U_N の位相が自由になり、やはり一致は消える。
- 判定：一致は核の選択に入れてある。「理由づけ」ではなく「同じものを 2 か所に置いた」と書くべき。

**1-2　2.9 の「N ∣ 24」**
- 結論：U_N が単数の角に入るのは N ∣ 24 のときだけで、そのとき U_N = I。
- 依存する入力：位相に無限素点の局所定数 (−i)^a を含めること（Hartley 核＝1-1 と同じ選択）と Gauss の符号定理。
- 除去テスト：素朴な位相 τ/√f にすると、角に入るのは {2, 3, 4, 6, 12} になり、8 と 24 が外れる（索引 2.9 の対照群の行）。
- 判定：索引はこの依存を書いているが、下書き 2.9 の題は「位相は N ∣ 24」とだけ書き、依存が落ちている。A_∞ の性質のように読める。

**1-3　「重なり」の読みの選択（2.1）と U の中身（2.3・2.6）**
- 連鎖：重なり＝U と読み（2.1）、群の商の読みは「A1 と両立しない」ことで退けられ、U の位相は A1、A1 の内容は Tate の定理。つまり定義の読みが公準 A1 によって選ばれ、その中身も A1 から来ている。
- 除去テスト：A1 を外すと、法 9 の反例は効力を失い群の商の読みが候補に戻る。U の位相は自由になり、第 2 章に残るのは「指標で対角化される境界ユニタリの族がある」という構造だけ。
- 判定：無限素点の「重なり」が運ぶ算術の情報はすべて注入されたもの。下書きは「A1 は導かれていない」と正しく書いているが、定義の読みの選択そのものが A1 に依存していることの注記が足りない。

**1-4　2.7 の局所定数との一致**
- 2.7 は、𝔀 が素点ごとの Tate の局所定数の積と（規約 T・ω の正規化のもとで）一致することを言う。これは Tate の定理（大域 ε の局所 ε への分解）の有限レベルでの再読で、A1 の内容（Tate の定理）と同じもの。
- 除去テスト：2.7 の Lean の文自体はガウス和の CRT 分解なので A1 を外しても残る。消えるのは「U の位相が素点ごとに分かれる」という読みのほう。
- 判定：2.7 を「貼り合わせがアデール的である証拠」として使うと円環になる。下書き本文は値のレベルにとどめていて、現状は問題ない。

**1-5　2.5 の `TopL_eq_of_A1`、2.6 の `UA1_family_unique`・`Uinf_unique`**
- どれも A1 の位相を定義・仮定に入れたうえでの一意性。下書き自身が 2.5 に「ほぼ同語反復」、2.6 に「A1 は導かれていない」と書いており、適切。
- 除去テスト：A1 を外すと、残るのは「導手ごとの直和分解に沿った延長の一意性」という構造の文だけ。

## 2. 同値性の循環・形の一致の自明な実現

- **2-1　5.5 の角の写像が代数準同型で合成・恒等の法則を満たすこと**：φ(S) = ιSι^†（ι＝引き戻し/√(M/N) は等長写像）なので、ι^†ι = 1 から φ(S)φ(T) = φ(ST) が直ちに出る。合成の法則は引き戻しの関手性から、N < M で φ(1) = ιι^† ≠ 1 は ι が全射でないことから出る。「gcd によらない」のもこのため。等長写像による共役での写像は Bost–Connes の ρ_n(x) = μ_n x μ_n^* と同じ仕組みで、6.3 の「群環の上で ρ と一致する」は構成からほぼ自明。形式的でない中身は、像が A_M に入ること（`cornerOp_mem`）と一意性の 2 つだけで、下書きはこの区別を書いていない。
- **2-2　4.1 の `isClosed_discrete_rhoBox_image`**：空間全体に離散位相を入れれば、どの部分集合も閉かつ離散。名前 `BoxCoord`（`Nat.Primes → ℤ` に箱位相、離散空間の箱積は離散）と推測すると、この定理は ℚ について何も言っていない（Lean は未読で未確認）。逆に各座標離散の直積位相なら有限台の元は稠密で、定理は成り立たない。索引は再照合 A2 の判定「ほぼ同語反復」を記録しているが、下書き第 4 章の冒頭文は「座標の取り方と位相の選び方で…決まります（定理［既知（再導出）］）」と定理の側に寄せている。
- **2-3　2.4 の Part 262（赤道の係数を 𝔀 で書く形）**：係数 conj(Ĵ) は正規化した Jacobi 和で、J(χ₁,χ₂) = τ(χ₁)τ(χ₂)/τ(χ₁χ₂) を 𝔀 に書き換えれば、偶奇因子から符号 s が出るのは定義から自明。索引の読み「北の畳み込みは南を U² で移したもの」の U² は、U を 𝔀 で定義した（A1）ことの言い換え。下書きは「絡み合いの中身はそちら（Part 21・25）にある」と書いていて適切だが、第 2 章冒頭の「Lean にあるのは、値のレベルでは 𝔀 の値と P¹ の赤道の係数を結ぶ文」は、「射影＝貼り合わせの合成」を支える文のようにも読める。
- **2-4　1.1 の積公式**：「∞ の座標は有限素点の座標から決まる」。ℚ_{>0} では無限素点は独立の情報を持たない。定義が無限素点を独立の点とすることとの関係は 5 で触れる。
- 目標と同値な条件で循環している例（N7 型）は、下書きの中には見つけていない。6.5 が N7 を否定的な結果として記録しているのは適切。

## 5. 目的との距離

**幾何の言葉で言えていること**
- 点：素点たち（定義）、付値の組の単射（1.1）。
- 舞台：P¹(ℤ/N) とその還元の塔、帰納極限 LimP（1.4・1.5）。
- 変換：反転 W、有限レベルの写像 JH（P¹ の上の作用素ではない）、U_N・U_∞（赤道の上）。
- 不変量らしきもの：𝔀（注入された値）、導手の区分け。
- 解像度：L1（測る素点の集合）と離散・稠密の二分法（4.1）。

**言えていないこと**：「直線」「有効な姿」を指す数学の対象。素点の空間と舞台 P¹ のつながり。解像度を変える写像（粗くする関手）と、それで保たれる量・変わる量。変換の群とその不変量。射影幾何としての結合構造（点・直線・結合）。無限素点に固有の幾何の内容（注入された部分を除く）。

**最も重要な欠落 3 つ**
1. **§1 の命題 3（解像度と有効な姿）に数学の文がない。** 第 3 章は定義と否定的な結果（3.2）だけで、第 4 章は古典的二分法（離散の側はほぼ自明）。08:41 の定義で「解像度が落ちる」は完備化への滑り落ちと読まれたが、粗くした見方で何が見えるかを述べる文は一つもない。「新しい幾何」を定める核の命題が空のまま章になっている。
2. **「点＝素点」と「舞台＝P¹」が結ばれていない。** P¹(Ẑ) = ∏ P¹(ℤ_p) の点は素点ではない。素点を点とする空間（既知の類似は Spec ℤ ∪ {∞}）は下書きに出てこない。定義では無限素点で無限大と無限小が「重なる」のに、P¹ では 0 ≠ ∞ で反転が 2 点を入れ替える（1.4、`zeroPt_ne_infPt`）。この食い違いを U で埋める読みはあるが、空間のレベルでの対応は書かれていない（1.4 の留保は構築側の候補として置いたまま）。
3. **無限素点に、注入された部分を除いた中身がない。** ℚ_{>0} では ∞ の座標は有限素点から決まり（1.1）、有限素点の側の代数は位相も符号もほぼ見ず（2.9）、U の位相は A1（Tate の定理）。定義が最も強調する点（無限素点での重なり）が、幾何の側では公準として外から入れたものだけで表されている。
