## 定義

N ≥ 2 の整数。V_N = {f : ℤ/N → ℂ}、内積は標準。
- 約数 s | N に対し、D_s = 「gcd(x, N) = s となる x の指示関数」を掛ける作用素。
- F = 離散フーリエ変換 (F f)(k) = N^{-1/2} Σ_x f(x) e^{−2πikx/N}。E_s = F^{-1} D_s F。
- A_N = D_s（s | N）と E_s（s | N）が生成する End(V_N) の単位的部分代数。
- 単数 u ∈ (ℤ/N)^× に対し、(R_u f)(x) = f(ux)。P = R_{−1}。
- 離散 Hartley 変換 (H f)(y) = N^{-1/2} Σ_x f(x)(cos(2πxy/N) + sin(2πxy/N))。
- J：素数冪 q = p^e ごとに、ℤ/q の上の置換 p^k w ↦ p^k w^{-1}（w は法 p^{e−k} の単数、0 ↦ 0）を考え、中国剰余定理で積をとった ℤ/N の置換。(J f)(x) = f(J(x))。
- 単数の上の関数 g : (ℤ/N)^× → ℂ。法 N の Dirichlet 指標 χ について、P_χ は χ の張る直線への直交射影。χ の導手を f(χ)、χ を誘導する法 f(χ) の原始指標を χ* とする。
  W(χ*) = τ(χ*)/(i^a √f(χ*))（τ はガウス和 Σ_x χ*(x) e^{2πix/f}、a = 0（χ*(−1) = 1）または 1（χ*(−1) = −1））。
  U_N = Σ_χ W(χ*) P_χ（単数の上の関数の作用素）。
- N | M のとき、ι : V_N → V_M、(ι f)(y) = (M/N)^{-1/2} f(y mod N)。V : V_N → V_M、(V f)(y) = f(x)（y = (M/N)x のとき）、それ以外 0。
  φ(S) = ι S ι^*、ψ(S) = V S V^*。
