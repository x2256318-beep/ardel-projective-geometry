## 2. 文献・計算についての文で、成り立たない文・根拠より強い文

### 2-1（中）文献照合ノート §1(a)「有限素点の局所定数はガウス和である（i の冪を含まない）」

- 値の文として読むと偽である。法 3 の奇の指標では τ/√3 = i になる（計算では 4.5e−16 + 1.000i）。規約 T では、無限素点が −i、有限素点が i で、積は W = 1。
- CLAUDE.md の「i の冪が無限素点から来ることは規約によらない」も、同じ曖昧さを引き継いでいる。
- 規約によらないのは、明示的な因子 i^{±a} が無限素点の局所定数であることのほうである。
- 照合者の導出：ℚ の上で自明な大域指標は ψ_T(c·)（c ∈ ℚ^×）の形をしている。ε(s,χ,ψ_a) = χ(a)|a|^{s−1/2}ε から、無限素点の局所定数は ±i^a、有限素点の積は ±τ/√N の正の数倍になる。

### 2-2（軽微）「χ_p の ℤ_p^× への制限が (ξ^{(p)})^{−1}（Roy–Schmidt–Yi 式 (150)）」

- 本文を [arXiv:2109.07649](https://arxiv.org/pdf/2109.07649) で確かめた。式 (150)〜(157) は §6.1 にある。§4.3 にあるのは ψ の定義だけ（Tate の学位論文の ψ、ψ_∞ = e^{−2πix}）。
- 式 (150) そのものは積の形で、「∏_{p|u} χ_p(a) = ξ(a)^{−1}（a ∈ ℤ、(a,u) = 1）」である。p ごとの制限は、a を中国剰余定理で選べば導ける（照合者も導出した）。「式 (150) から導かれる」と書くのが正確。
- (155) の値 −i、(156) が演習であること、(157) の積分の形は、本文と一致した。(157) は抽出したテキストが崩れていて、式の細部は確かめていない。

### 2-3（軽微）材料ノート注意 2「符号を逆に取るのが通例で」

「通例」ではない。ℚ の上で自明にするためには、そうするしかない（文献照合ノート §5 の「混ぜた ψ は ℚ の上で自明でない」と同じ理由）。選べるのは、無限素点の側の符号だけである。

### 2-4（軽微）CLAUDE.md と概要の積の文に s がない

τ/√N になるのは s = 1/2 での積である。s = 0 では τ(χ)、一般の s では N^{−s}τ になる。
