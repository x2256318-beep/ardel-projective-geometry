## 定義
- 正の整数 N について V_N = ℂ^{ℤ/N}。A_N ⊂ End(V_N) は、単数群 (ℤ/N)^× の軌道（gcd(N, x) = s の集合）の指示関数を掛ける作用素 D_s と、フーリエ側で周波数の軌道（gcd(N, ξ) = s）に射影する作用素 E_s が生成する代数（円分的なアソシエーションスキームの、基点 0 での Terwilliger 代数 T(0)）。
- N ∣ M のとき π: ℤ/M → ℤ/N、π^* は引き戻し、π_* は繊維の和。φ_{N,M}(S) = (N/M) π^* S π_* は A_N → A_M の単位元を保たない代数準同型（像は角 Q A_M Q、Q = φ(1) は N 周期の関数への射影）で、正の整数の整除の順序の上で帰納系をなす。その代数的な直極限を A_∞ とする（完備化はしない。有限次元の代数の和集合で、局所的な単位元を持つ非単位的な代数）。
- V_∞ を、V_N の引き戻しによる代数的な直極限とする（＝ Ẑ 上の局所定数関数の空間）。
