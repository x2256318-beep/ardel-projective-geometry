### 0.2 Hartley の核と原始指標（§1・§2）

- cas(2π t/N) = ((1 − i)e(t) + (1 + i)e(−t))/2（e = stdAddChar）。
- H_N χ = ε(χ)·τ(χ)·χ⁻¹（χ 原始的）。核を e(xy) と e(−xy) に分け、原始指標のガウス和の性質 τ(χ, e(y·)) = χ⁻¹(y)τ(χ) を 2 回使います。χ⁻¹(−y) = χ(−1)χ⁻¹(y) なので、係数は ((1 − i) + (1 + i)χ(−1))/2 = ε(χ) にまとまります。
- 単数でない y では χ⁻¹(y) = 0 なので H_N χ (y) = 0。原始指標の部分は、単数の上の関数の空間に留まります。

### 0.3 ルート数と主定理（§3・§3b）

- **すべての指標で（§3・§3b）。** W(χ) = τ(χ)/(i^a √N) = ε(χ)·τ(χ)/√N（1/i = −i。`rootNum_eq`）。単数 u で H_N χ (u⁻¹) = χ(u)·H_N χ (1)（x ↦ u·x の置換）、H_N χ (1) = ε(χ)·τ(χ)（x ↦ −x の置換で Σ χ(x)e(−x) = χ(−1)τ(χ)）。よって (J H_N χ)(u)/√N = W(χ)χ(u)。
- **原始指標で（§3）。** (J H_N χ)(u)/√N = H_N χ (u⁻¹)/√N = ε(χ)τ(χ)χ⁻¹(u⁻¹)/√N = W(χ)·χ(u)（同じ式の別の導き方）。|W(χ)|² = |ε(χ)|²·|τ(χ)|²/N = 1（Part 16 の |τ(χ)|² = N）。
