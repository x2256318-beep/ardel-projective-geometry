# 依頼文（内部照合の監査、照合者 R3）

あなたは Lean 4 と Mathlib に通じた独立の照合者です。ある形式化プロジェクトは、ファイル PAG1.lean 〜 PAG260.lean を番号順に積み上げた 1 本の鎖です（番号の大きいファイルは小さいファイルを import できます）。あなたの担当は PAG257（Part 253）の宣言です。

## 問い
担当の各宣言 T について、**T より前のファイル**（T が PAGk にあれば PAG1〜PAG(k−1)）に、次のどれかがあるかを判定してください。
- **A**：同じ文（名前・変数名・書き方の違いを除く）。定義なら、同じ対象（同じ値）を別の名前で定義したもの。
- **B**：前の宣言から直ちに出る（代入、特殊化、定義を展開すれば同じ、など。証明が 1〜2 行）。
- **C**：前の宣言から数行で出る（短い系。前の宣言を 1〜3 個組み合わせ、簡単な計算を足す程度）。
- **D**：前の鎖に見つからない。
- T が前の宣言より強い・一般的な形なら、そう書いてください（判定は D とし、「前の X を一般化」と添える）。

- 使ってよいツールは Read と Grep だけです（上の 3 つの場所の中だけ）。ファイルの書き込み、シェル、ウェブ、エージェントの起動はしないでください（照合が独立でなくなるため）。

- 分からないものは分からないと書き、作り上げないでください。「見つからなかった」は「ない」の証明ではありません。
- 各判定に確信度（高・中・低）を付けてください。
