## 1. M1：貼り合わせ U は素点ごとに分かれるか（推奨）

### 1.1 出所
本来の道の「無限素点を含む大域対象」と「重なり」。Part 254 は U を導手ごとの直和に分けましたが、素点ごとの積に分かれるかは問うていません。Part 255 の L1（測る素点の集合 T）で言うと、「T に素数を 1 つ足したとき、U はどう変わるか」です。

### 1.2 幾何の言葉での問い
2 つの点（素数）p, q の上の局所の貼り合わせから、p と q を同時に見たときの貼り合わせは決まるか。決まらないなら、ずれは何か。無限素点はどこに入るか。

### 1.3 既存分野の言葉への最善の翻訳
- 互いに素な法でのガウス和の乗法性：τ(χ₁χ₂) = χ₁(N₂)χ₂(N₁)τ(χ₁)τ(χ₂)（古典。中国剰余定理）。
- ルート数の局所因子への分解 W(χ) = ∏_v ε_v（Tate の学位論文の局所定数）。交差項は、局所の指標 χ_p を相手の素数で評価した値にあたります。
- 2 次の指標では平方剰余の相互法則（ガウス和による標準の証明）。
- 作用素の形：原始指標の積が張る部分で U_{N₁N₂} = S ∘ R_{(N₂,N₁)} ∘ (U_{N₁} ⊗ U_{N₂})。R は単数 (N₂ mod N₁, N₁ mod N₂) による平行移動、S は偶奇の符号。原始でない部分では、平行移動の元 (d₂, d₁) が指標ごとに変わるので、1 つの平行移動にはなりません（盲検の指摘）。
- 正確な言い方（盲検の指摘で直した）：中国剰余定理による成分 U_{N₁} ⊗ U_{N₂} は、イデール類指標の局所成分による分解と一致しない。交差項はその差。

### 1.4 残余
- 空の見込みです（確信度：中〜高）。新しいのは置き方（U と L1 をつなぐ言い方、作用素の形）だけです。
- 残余になりうる点（見込みは低い）：原始でない指標を含めた全体での作用素の形。3 つの法では、交差項は 2 つずつの組の積で尽きました（数値 (10)：68 組。3 つ組に固有の項はない）。

### 1.5 対照群テスト
- F_q[t]：同じ交差項の法則が成り立ちます（数値 (5)）。交差項は算術に固有ではありません。
- ℚ では、符号 s が無限素点の因子 i^{−a} から出ます（数値 (9)）。関数体でも無限素点のずれはあり、形が違います：奇の指標の根数には F_q^× の上のガウス和が入り、ともに奇のときのずれはヤコビ和型の位相になります（盲検、David–Florea–Lalín arXiv:1901.00817 の Corollary 2.4 と手計算。確信度：中。こちらでは未確認）。「ℚ に固有なのは s だけ」は取り下げます。
- 一般化素数：指標とガウス和がないので、問いが立ちません。

## 2. M2：有限の高さで離散を観測する（比較用、小さい）

- **出所。** 08:41 の定義の「極限に逃げ込まない」を量で言う。Part 250 の観察 H·g(H) ≈ 1 の残り。
- **幾何の言葉での問い。** 極限をとらずに有限の高さ H で見るとき、点はどれだけ離れているか。連続体への滑り落ちはどの速さか。
- **翻訳。** δ(H) = min{|a log p − b log r| > 0 : |a|, |b| ≤ H} について、上界 (log p + log r)/H は鳩の巣（Dirichlet）、下界 exp(−cH) は整数性（p^a ≠ r^b）、下界 H^{−C} は Baker の定理（Mathlib にない）。
- **数値。** (6)：H = 10〜1000 で exp(−cH) ≤ δ(H) ≤ (log p + log r)/H。(8)：Part 250 の観察の中身は、1 の右隣の分数 H/(H−1) の対数。
- **対照群。** 対数の比がリウヴィル数の一般化素数では、δ(H) が H の任意の冪より速く落ちる高さの列があります（数値 (7)）。素数では Baker の定理でこれが起きません。つまり多項式の下界は算術の内容ですが、深い既知の定理で、Lean にできるのは初等的な上界と指数の下界だけです。
- **残余。** 空（確信度：高）。小さいノート。
- **注意。** 高さの記号は H を使い、CLAUDE.md §1 の N・K・Λ と同一視しません。
