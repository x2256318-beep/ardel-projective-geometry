## 確かめること
1. **正しさ**：書き足された各注記が、`evidence.md` の形式文と根拠に合っているか。
   - 「同じ文」と書いたものは、本当に（名前・暗黙引数の違いを除いて）同じ文か。「同じ値」「同じ定義」と書いたものは、定義の式から見てそう言えるか。
   - 「直ちに出る」「数行で出る」の根拠が書かれたとおりか。「Lean で確認」と書いたものに、Lean の根拠（上のファイルか表）があるか。照合者の判定だけのものに「Lean で確認」と書いていないか。
   - Part の番号とファイル名の対応（Part n = PAG(n+4).lean、PAG.lean = Part 1、PAG2・PAG3 = 付録 A の Part 2・3）を間違えていないか。
2. **すべての場所**：A・B の注記（`evidence.md` の判定が A か B のもの）が、Lean の docstring、ノート、表（行がある定理のみ。定義は表に行がないので見出し）のすべてに入っているか。抜けを挙げてください。
3. **格上げ・書きすぎ**：注記や報告が、根拠より強いことを言っていないか（例：「ない」と言い切る、照合者の判定を確定として書く、件数の食い違い）。報告の件数（A・B が 26、C が 20 など）が `evidence.md`・差分と食い違っていないか。
4. **形式文が変わっていないか**：`fixes_lean_diff.txt` で、docstring・コメント以外（定理の文・証明・定義の本体）が変わっていないか。
