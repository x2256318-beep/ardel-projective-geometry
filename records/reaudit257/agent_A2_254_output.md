## 前置き（記号と、定義を展開して確かめたこと）

N ≥ 1（[NeZero N]）は暗黙に固定されているものとして読みます。記号は次のとおりです。

- V_N = {(ℤ/N)ˣ → ℂ}
- ⟨f,g⟩_N = Ψ5 f g = Σ_u conj(f u)·g u（第 1 引数について共役線形、正規化なし）
- χ と Ψ4 χ（単数への制限）は区別しない

定義を手で展開して、次のことを確かめました（確信度：高）。

- **Ψ3 の正体**：単数からのゼロ拡張、√N で割った離散ハートレー変換、u⁻¹ での評価を組み合わせたものです。
  - cas θ = e^{iθ}(1−i)/2 + e^{−iθ}(1+i)/2 と Gauss 和の置換から、すべての χ mod N について Ψ3 χ = Φ4(χ)·χ が成り立ちます。
  - 固有値は、χ が偶なら τ/√N、奇なら τ/(i√N) です。
  - χ が原始的なら Φ4(χ) は根数 W(χ) で、|W| = 1 です。
  - χ が非原始的なら τ(χ) = μ(N/f)χ*(N/f)τ(χ*) なので、Φ4(χ) は 0 にもなりえます（f は導手、χ* は誘導元の原始指標）。
- **Θ2 の正体**：Θ2 = Σ_χ W(χ*)·P_χ です（P_χ は χ への直交射影）。指標基底で対角化されたユニタリ作用素です。
- **Ξ3 と Ξ7**：Ξ3 は Ẑˣ 上の局所定数関数の空間（代数的な直極限）です。Ξ7 は、Haar 確率測度で取った内積に当たります。

## 1. 訳（すべて確信度：高）

- **Ω1 N q**（q ∈ ℕ）：導手がちょうど q である法 N の指標たちが張る、V_N の部分空間です。q ∤ N のときや q = 0 のときは {0} になります。引数の順は（法, 導手）です。
- **Ω2 f**：線形汎関数 g ↦ ⟨f,g⟩_N です。S51〜S57 のどの文にも出てきません。
- **S51**：任意の N, M ≥ 1、N ∣ M の証明 hNM、g ∈ V_N について、次が成り立ちます。g が法 N の原始指標の張る空間 Ψ6 N に属するなら、Θ2^{(M)}(Θ3 g) = Θ3(Ψ3^{(N)} g)。
  - Θ3 は (ℤ/M)ˣ → (ℤ/N)ˣ に沿った引き戻しです。
  - 左辺の Θ2 は法 M、右辺の Ψ3 は法 N で働きます。
- **S52**：N ∣ M（M ≥ 1）なら、「法 M で導手がちょうど N の指標」が張る空間は、Ψ6 N を Θ3 で移した像に等しい。
- **S53**：任意の自然数 q ≠ q' と、f ∈ Ω1 N q、g ∈ Ω1 N q' について ⟨f,g⟩_N = 0。
- **S54**：Σ_{q∈ℕ} Ω1 N q = V_N。
- **S55**：族 (Ω1 N q)_{q∈ℕ} は独立である。つまり、各 q について Ω1 N q ∩ Σ_{j≠q} Ω1 N j = 0。S54 と合わせると、V_N は内部直和 ⊕_q Ω1 N q になります。
- **S56**：任意の q と f ∈ Ω1 N q について、Θ2 f ∈ Ω1 N q。
- **S57**：正整数 q, q'（Ξ0 の元）が q ≠ q' を満たし、f ∈ Ψ6 q、g ∈ Ψ6 q' なら、直極限の中で Ξ7(Ξ4_q f, Ξ4_{q'} g) = 0。
  - S44 を使うと、「両方を共通の法に持ち上げ、φ で割った内積を取ると 0」という意味になります。
  - この文にはセクション変数 N は出てきません。

## 3. 仮定の点検

- **S51**
  - hNM と [NeZero M] は、式に型を付けるために必要です。
  - hg は本質的です。N = M = p、g = 自明指標とすると、unitsMap_self により Θ3 は恒等写像です。S17・S6・S21 から、左辺は g、右辺は −g/√p となり一致しません。
  - N ≡ 2 (mod 4) では原始指標がないので Ψ6 N = 0 です。このときは 0 = 0 に退化します。N = 1, 3, 4, 5 などでは中身のある主張です。
- **S52**
  - hNM は型のために必要です。
  - N ≡ 2 (mod 4) では両辺とも 0 で、「導手が 2 (mod 4) になることはない」という事実と整合します。
  - 満たす例：N = 3, M = 6。
- **S53**
  - hqq を外すと偽です（f = g = χ とすると ⟨χ,χ⟩ = φ(N) ≠ 0）。hf や hg を外しても偽になります。
  - 満たす例：N = 3, q = 1, q' = 3。
- **S56**
  - hf を外すと偽です。導手の違う χ について Θ2 χ = Θ1(χ)χ で、|Θ1| = 1 なので 0 にもならず、Ω1 N q に入りません。
- **S57**
  - hqq を外すと偽です（f = g = 原始指標 ψ とすると Ξ7 = 1）。
  - hg を外しても偽です。q = 1, q' = 3、f = 1、g = 法 3 の定数関数 1 とすると、両者は直極限で同じ元を表すので Ξ7 = 1 です。Ψ6 3 は (1, −1) で張られるので、g ∉ Ψ6 3 です。
  - 満たす例：q = 3, q' = 4, f = χ₋₃, g = χ₋₄。
- **不要な仮定**：見当たりません（高）。なお、q.val ≠ q'.val は q ≠ q' と同値です。

## 4. 定義の点検

- **引数の順**：Ω1 は（法, 導手）の順です。S52 の Ω1 M N は「法 M・導手 N」の意味で、逆に読むと誤読になります。Θ2 がどの法で働くかは、引数の型から決まります。
- **添字の取り方**：Ω1 は ℕ 全体を添字にしていて、q = 0 や q ∤ N のところは {0} です。S54・S55 にとっては無害ですが、実際に 0 でない成分は q ∣ N かつ q ≢ 2 (mod 4) のものだけです。
- **規約**
  - Ψ5 は第 1 引数について共役線形で、Mathlib の inner と同じ向きです。正規化はしていません。
  - 直極限では φ で割った Ξ6 を使い、これは持ち上げで保たれます（S42）。直交性の主張は、どちらの正規化でも同値です。
  - Φ5 が u⁻¹ で評価しているのは、標準的でないひねりです。これがないと Ψ3 χ = Φ4(χ)·χ̄ となり、指標が固有ベクトルになりません。
  - Φ4 の i^κ√N による正規化は根数の標準形で、偶奇どちらの場合も Ψ3 の固有値と一致します（高）。
- **Θ2 の定義の仕方**：固有値を直接指定するスペクトル的な定義です。そのため S56 はほぼ定義から出ます。ハートレー変換との関係を実際に担っているのは S11 と S51 だけです。
- **構造の入れ方**：位相も完備化もありません。Ξ7 は InnerProductSpace のインスタンスではなく、選択を使って定めた関数です（値が選び方によらないことは S43 で保証）。したがって S57 は前ヒルベルト空間での直交性の主張で、L²(Ẑˣ) についての主張ではありません。
- **Ω2**：「S51〜S57 で使う定義」とされていますが、文には出てきません。証明用の補助かもしれません（確信度：低）。いずれにせよ、文の意味には影響しません。
