## 記法
〔 〕内は確信度です。定義の中身は §4 で点検します。
- N は暗黙の引数です。[NeZero N] により N ≥ 1 です（S17 だけは N = 0、つまり ℤ/0 = ℤ も含みます）。
- cas θ = cos θ + sin θ、e(t) = exp(2πit) と書きます。
- H_χ(y) := Φ2 χ y = Σ_{x∈ℤ/N} χ(x)·cas(2πxy/N)。正規化していない離散ハートレー変換（DHT）です。
- τ(χ) := Σ_a χ(a)e(a/N)。c(χ) := Φ3 χ で、偶なら 1、奇なら −i です。
- W(χ) := Φ4 χ = τ(χ)/(i^κ√N)。κ は偶なら 0、偶でない（＝奇）なら 1 です。
- Φ5 χ u = H_χ(u⁻¹)/√N（u は単数）。χ₀ は自明な指標です。

## 1〜3. 各文の訳・判定・仮定

**S16**
- 訳：任意の N ≥ 1、法 N の任意の指標 χ（原始性は仮定しない）、任意の u ∈ (ℤ/N)ˣ について、H_χ(u⁻¹) = χ(u)·H_χ(1)。
- 判定：自明です。x ↦ xu と一度変数を変えるだけで出ます。核 cas の性質は使っておらず、任意の核 K で同じ式が成り立ちます。〔真偽は高、ラベルは中：「実質的（標準）」と読む余地あり〕
- 仮定：NeZero は有限和を作るために構造上必要です。原始性は不要です。
  - 単数に限ることは本質的です。非単数 y で H_χ(y) = χ̄(y)H_χ(1) と広げると、非原始的な χ で偽になります（S15：N = 2, y = 0 で左辺 1、右辺 0）。
  - u ≠ 1 の非自明な例は N ≥ 3 で存在します。〔高〕

**S17**
- 訳：任意の N ∈ ℕ（0 を含む）と任意の χ について、χ(−1)·χ(−1) = 1。
- 判定：自明です（χ の乗法性と (−1)² = 1 だけで出る）。仮定はありません。〔高〕

**S18**
- 訳：任意の N ≥ 1、任意の χ について、Σ_x χ(x)e(−x/N) = χ(−1)τ(χ)。
- 判定：自明です（x ↦ −x の変数変換）。S5 の y = −1 の場合を具体的に評価したものです。仮定は構造上のものだけです。〔高〕

**S19**
- 訳：任意の N ≥ 1、任意の χ について、H_χ(1) = c(χ)τ(χ)。つまり偶なら τ(χ)、奇なら −iτ(χ)。
- 判定：実質的（標準）ですが軽い内容です。S1 で cas を e(±x/N) に分け、S18 を使うだけです。〔真偽は高、ラベルは中〕
- 仮定：原始性は不要です。S6 で y = 1 とした式から原始性を外した一般化になっています。〔高〕

**S20**
- 訳：任意の N ≥ 1、任意の χ（原始性なし）、任意の単数 u について、H_χ(u⁻¹)/√N = W(χ)·χ(u)。
- 判定：実質的（標準）です。骨格は S16 + S19 + S8 の組み合わせで、独自の内容は S19 程度です。「固有値方程式」に見えるのは、Φ5 に u⁻¹ と 1/√N を組み込んだ定義によるところが大きいです。〔真偽は高、ラベルは中〕
- 仮定：S10 と結論が同じで、仮定 hχ（原始性）だけを外しています。したがって S10 は S20 から直ちに出ます。S10 の原始性の仮定は不要です。〔高〕
  - 非原始的な χ では内容が退化することがあります。法 4 の χ₀ では W = 0 です。H_{χ₀} は単数の上では恒等的に 0 で、値を持つのは非単数（0 で 2、2 で −2）だけです。このとき S20 は 0 = 0 しか言っていません。〔高〕

**S21**
- 訳：法 2 の自明な指標 χ₀ について、|W(χ₀)|² = 1/2。
- 検算：τ(χ₀) = e(1/2) = −1、χ₀ は偶、W = −1/√2 で一致します。〔高〕
- 判定：端の場合だけ（具体例・証人）です。
  - S21 だけでは χ₀ が非原始的であることを述べていません。S15 の第 1 成分（χ₀ は非原始的）と合わせて、初めて「S11 から原始性を外せない」反例になります。
  - さらに、法 2 には原始的な指標が一つもありません。つまり S11 が空虚に成り立つ、退化した法での反例です。〔高〕

**S22**
- 訳：次の 5 つがすべて成り立つ。
  1. 法 2² の原始的な指標が存在する。
  2. 法 4 の χ₀ は原始的でない。
  3. 2 は ℤ/4 の単数でない。
  4. 法 4 で H_{χ₀}(2) = −2。
  5. 法 4 で |W(χ₀)|² = 0。
- 検算：
  - (1) χ(3) = −1 の奇指標は導手が 4 です。
  - (4) x ∈ {1, 3} では 2x ≡ 2 で、cas(π) = −1 が 2 回足されて −2 です。
  - (5) τ(χ₀) = i − i = 0 です。
  - いずれも一致します。〔高〕
- 判定：端の場合だけ（具体例・証人）です。原始的な指標が存在する法 4 で、S7 と S11 の原始性が外せないことを示しており、S21 の「退化した法」という弱点を補っています。〔高〕
  - (1) は他の成分とつながっていません（その χ について何も述べない）。S13・S14 と同じ種類の、仮定が空虚でないことの証人です。
  - 2^2 と 4 の書き方が揃っていませんが、見た目だけの違いで、意味は同じです。〔高〕

## 4. 定義の点検
- Φ1：ハートレー核です。t.val を使っていますが、cos と sin の周期性により代表の選び方には依存しません。〔高〕
- Φ2：正規化していない DHT です。核が x と y について対称なので、引数の順序は問題になりません。〔高〕
- Φ3：c(χ) = (−i)^κ です。ℂ 値の指標では χ(−1) = ±1 なので、値は 1 か −i に限られます。〔高〕
- Φ4：加法指標の符号を正にとり、i^κ で割る標準的な規約です。原始的な χ では根数と一致します（文献によっては共役や逆数で書く）。〔高〕
  - 気になる点：この定義はすべての指標に適用されますが、非原始的な χ では L 関数の根数ではありません。古典的な公式 τ(χ) = μ(N/f)χ*(N/f)τ(χ*)（f は導手、χ* は χ を誘導する原始的指標）から |W|² ≤ f/N < 1 で、0 にもなります。S21・S22 はこの例です。〔高〕
- Φ5：気になる点が二つあります。
  - (a) 反転 u ↦ u⁻¹ が定義に組み込まれています。そのため、本来の主張「H_χ/√N = W·χ̄（単数上）」が、固有値方程式のような形に見えます。χ はハートレー変換そのものの固有ベクトルではありません（原始的な場合、固有ベクトルになるのは実指標のときだけ）。また Φ5 は「ℤ/N 上の関数」から「単数上の関数」への写像で、同じ空間への写像でもありません。〔高〕
  - (b) 定義域を単数に限ったため、原始性が効く部分（非単数での値）が型の段階で見えなくなっています。S20 が原始性なしで成り立つのはこのためです。〔高〕
- 位相などの構造：有限和だけなので該当しません。1/√N で割るのはユニタリにする標準的な規約です。

## 5. 全体の所見
- **言えていること**：単数上の関係 H_χ(u⁻¹)/√N = W(χ)χ(u) は、原始性と関係なくすべての指標で成り立ちます（S16, S19, S20）。変数変換と偶奇の分解だけで出る初等的な事実で、入力 (3) に標準を超える内容はありません。〔高〕
  - 原始性が本当に必要なのは、非単数での消滅（S7）と |W| = 1（S11）の部分です。S15・S21・S22 がその必要性の具体的な証人になっています。〔高〕
- **言えていないこと**：
  - 非原始的な χ の、非単数での値の一般式。
  - 誘導する原始的指標との関係（§4 の τ の公式）。
  - 逆向きの「|W| = 1 ⇒ χ は原始的」（数学的には正しいが、形式化されていない）。
  - 実指標で W = 1 となること（ガウスの符号）、関数等式。
- **入力 (2) との関係**：
  - S20 ⇒ S10 です。入力 (2) では原始的な指標の性質に見える S10 が、実は一般の指標の性質だと分かります。否定的な所見として明記する価値があります。〔高〕
  - S19 は S6 の y = 1 の場合の一般化です。
  - S16 は、S6 と S9 から原始的な場合に出る単数部分の関係を、一般の指標に広げたものです。
  - S17 は S4 と同じ種類の自明な補題です。S18 は S5 の y = −1 の場合です。
  - S21 は S15 と対になり、S11 の仮定が必要なことの証人です。S22 は S7 と S11 の仮定が必要なことの証人を法 4 で与えます。
- **手計算による検算**：
  - 法 4 の奇指標（τ = 2i、W = 1、H(1) = 2、H(3) = −2）で、S16 と S18〜S20 を確かめ、一致しました。
  - 法 5 の 2 次指標（H(1) = τ = √5）で、S19 を確かめ、一致しました。
  - いずれも機械による検証ではありません。〔中〜高〕
