# S18・S23 の査読

**記法**：
- τ(ψ) = Σ_{a mod q} ψ(a)e^{2πia/q}
- κ(ψ) は ψ が偶なら 0、それ以外なら 1
- ε(ψ) := Ξ1 ψ = τ(ψ)/(i^κ√q)（q は法）

確信度は【高】【中】【低】で付けます。「コンパイル済み・公理は標準の 3 つ以内」という申告はそのまま受け入れました。私の検証は読解と手計算だけです。

## 1. 訳

**S18**【高】：仮定のない、閉じた存在文です。
「法 3 の ℂ 値ディリクレ指標 χ₁ と法 5 の ℂ 値ディリクレ指標 χ₂ で、次をすべて満たすものが存在する。χ₁・χ₂ はともに原始的で、ともに奇（χ(−1) = −1）。両者を法 15（型は `3 * 5`）に持ち上げた積 χ = χ₁χ₂ について、ε(χ) ≠ ε(χ₁)ε(χ₂)。」
- χ は偶なので、ε(χ) = τ(χ)/√15、ε(χ₁)ε(χ₂) = τ(χ₁)τ(χ₂)/(i·i·√15) になる。
- したがって不等式は **τ(χ₁χ₂) ≠ −τ(χ₁)τ(χ₂)** と同値。

**S23**【高】：これも閉じた存在文です。
「法 3 の指標 χ₁ と法 13 の指標 χ₂ で、次をすべて満たすものが存在する。ともに原始的で、ともに奇。χ₁(13 mod 3)·χ₂(3 mod 13) = 1。法 39（型は `3 * 13`）の積 χ について ε(χ) = −ε(χ₁)ε(χ₂)。さらに ε(χ₁)ε(χ₂) ≠ 0。」
- 同じように展開すると、等式は **τ(χ₁χ₂) = τ(χ₁)τ(χ₂)** と同値。右辺の − は i·i = −1 と打ち消し合う。

## 2. 判定

**S18：端の場合だけ（具体例・証人）。真で、空虚ではない。**【高】
- **証人**：
  - χ₁ = (·/3)。法 3 の唯一の非自明指標で、χ₁(2) = −1。
  - χ₂ = χ₂(2) = ±i となる四次指標。2 は法 5 の原始根で、χ₂(−1) = χ₂(2)² = −1。R6 により原始。
- **検算**：S12 より ε(χ) = Θ1·χ₁(5)χ₂(3)·ε₁ε₂ = (−1)(−1)(∓i)ε₁ε₂ = ∓i·ε₁ε₂。R2 より ε₁ε₂ ≠ 0 なので、不等式が成り立つ。
- 実は、条件を満たす組すべて（1×2 組）で成り立つ。奇な χ₂ は必ず χ₂(2) = ±i になるため。∃ の形は、実際に言えることより弱い。
- **内容**：素朴な乗法性 ε(χ₁χ₂) = ε(χ₁)ε(χ₂) の反例。

**S23：端の場合だけ（具体例・証人）。真で、空虚ではない。**【高】
- **証人**：
  - χ₁ = (·/3)。χ₁(13) = χ₁(1) = 1。
  - χ₂ = 法 13 の四次指標で χ₂(2) = ±i。3 ≡ 2⁴ より χ₂(3) = 1、χ₂(−1) = χ₂(2)⁶ = −1。
- **検算**：S8 より Θ1 = −1、交差項は 1 なので、S12 から ε(χ) = −ε₁ε₂。非零は R2 から従う。
- **内容**：交差項が 1 でも、符号 Θ1 は残る。つまり、S12 から Θ1 を落とした式 ε(χ₁χ₂) = χ₁(N)χ₂(M)ε₁ε₂ の反例になっている（素朴な式の反例も兼ねる）。
- **注意**：1. の展開が示すとおり、この −1 はガウス和の算術から来るものではない。正規化の i^κ（i·i = −1）からだけ来る。この例では、ガウス和そのものは乗法的。【高】

## 3. 仮定の点検

両文とも前提（仮定）はなく、条件はすべて証人への制約（連言）です。∃ の中の連言は外しても弱くなるだけで、偽にはなりません。そこで、各連言の役割と冗長性を点検します。

**S18**【高】
- **原始性 2 つ**：法が素数なので、「奇 ⇒ 非自明 ⇒ 原始」（R6）により冗長。ただし、ε が本来のルート数であることを明示する意味はある。
- **χ₁ が奇**：法 3 の原始指標は (·/3) だけで、これは奇なので冗長。
- **χ₂ が奇**：「原始性＋不等式」から従う。偶の (·/5) では Θ1 = 1、χ₁(5)χ₂(3) = (−1)(−1) = 1 となり、等号が成り立ってしまうため。
- **満たす例**：上の 2 組。

**S23**【高】
- **原始性 2 つと χ₁ が奇**：S18 と同じ理由で冗長。
- **χ₂ が奇**：情報がある。法 13 の非自明指標 11 個のうち、奇は 6 個。
- **交差項 = 1**：情報がある。実質的には χ₂(3) = 1 という条件で、奇と合わせると四次指標 2 個に絞られる。これを外すと、「何らかの補正が要る」と言うだけの、S18 並みの主張に弱まる。
- **等式**：前の連言と S12・S8（あるいは S6・S7 と定義）から従うので、論理的には冗長。
- **非零**：原始性と R2 から従う。それでも、「0 = −0」で空虚に成り立つことを文面上でも排除する番人として妥当。
- **満たす例**：上の 2 組。
- 法の積が 39 未満の互いに素な組 (3,4), (3,5), (3,7), (3,8), (3,11), (4,5), (4,7), (4,9), (5,7) では、「両方奇かつ交差項 1」は実現できない。39 は最小の例。【中：手計算による列挙】

## 4. 定義の点検

S18・S23 に出てくる自前の定義は Φ1 と Ξ1 だけです。Θ1 や Ξ3 を信用しなくても、文は読めます。【高】

- **Φ1**：法 M·N への changeLevel の積。
  - M, N が互いに素なら、中国剰余定理（CRT）による積指標になる。原始×原始は原始（S13）。
  - 互いに素でなくても定義はされるが、その場合は法 lcm(M,N) からの誘導指標になり、原始にならない。S18・S23 は互いに素なので関係ない。
  - 引数の順序（χ₁ が法 M、交差項は χ₁(N)χ₂(M)）は S12 と S23 で一致している。【高】
- **Ξ1**：τ(χ)/(i^κ√n)。ここで n は法であり、導手ではない。
  - 原始指標に対しては、関数等式に現れる標準的なルート数になる（|ε| = 1）。
  - 非原始では 0 になったり、|·| ≠ 1 になったりする（例：法 p の自明指標では |ε| = 1/√p）。
  - S18・S23 では χ₁, χ₂, χ₁χ₂ がすべて原始なので、本来のルート数であり、Ξ3 とも一致する（R3, S13）。
  - 「偶でなければ i」という場合分けは妥当。ℂ 値指標では χ(−1)² = 1 なので、必ず偶か奇になる。【高】
- **加法指標の向き**：e^{+2πia/n}。逆向きにすると τ が χ(−1) 倍になり、奇指標の ε は符号が反転する。ただし S18・S23 では両辺の変化が打ち消し合うので、結論は変わらない。【高】
- **Θ1**（文面には出てこない）：Θ1 = i^{κ₁+κ₂−κ(χ₁χ₂)}。正規化の i^κ の帳尻合わせにすぎず、τ/√q で正規化すれば不要になる。【高】
- **その他**：
  - `χ.Odd` は DirichletCharacter の名前空間の述語。MulChar には加法がないので、一般の `Odd` と取り違える心配はない。
  - 位相などの構造は関わらない。
  - √15 = √3√5 は非負性から正当。【高】

## 5. 全体の所見

**言えていること**【高】
- S18：法 (3,5) の原始で奇な組では、ルート数の素朴な乗法性が破れる。比は χ₂(3) = ∓i。
- S23：交差項が 1 でも、奇×奇なら ε(χ₁χ₂) = −ε(χ₁)ε(χ₂)。つまり S12 の Θ1 は、交差項に吸収されない補正項である。

**言えていないこと**
- 一般定理ではなく、S12 の系の具体例にとどまる。数学的な深さは低い（Lean で具体的な指標を構成する手間は別の話）。【高】
- 交差項が単独で必要であることは示されていない。
  - S18 の文面だけからは、証人で ε(χ) = Θ1ε₁ε₂ = −ε₁ε₂ が成り立っている可能性を排除できない。
  - これを示すには、Θ1 = 1 で交差項 ≠ 1 となる例か、「ε(χ) ≠ Θ1ε₁ε₂」という形の文が必要。
  - 例：χ₁ = (·/3)、χ₂ = 法 7 の三次指標（偶）とすると、交差項 χ₂(3) は 1 の原始 3 乗根になる。【高】
- S23 の −1 を「算術的な符号の破れ」と読むのは過大評価。これは規約から来ている。【高】
- 二次指標だけでは破れは見えない。実原始指標ではガウスの符号決定により ε = 1 なので、S16 から Θ1·交差項 = 1 が出る（これは平方剰余の相互法則）。証人が四次指標になっているのは必然。【高】

**入力 (2) との関係**
- **S18 と S19**：S18 は S19 を含意する（R3・S13 により Ξ1 = Ξ3）。法 (3,5) では、S19 を満たす原始の組も奇×奇に限られ、証人の集合は一致する。したがって S18 は、S19 の Ξ1 版で奇性を明示した言い換えに近い。【高】
- **S23 と S12**：S23 は S12 の特別な場合（S8 で Θ1 = −1、交差項 1）に、R2・R6 と法 13 の四次指標の存在を合わせたもの。符号の起源は S11。S16 とも整合する（Θ1·交差項 = −1 なので、ε₁・ε₂・ε(χ) がすべて 1 になることはない）。【高】
- **証人の部品**：S17・R5 は S18 の証人の部品にあたる。法 13 の奇指標の存在は (2) には含まれておらず、S23 で新たに必要になる。【高】
- **Ξ4 との関係**：R4・S15 を通じて、Ξ4 の固有値にも同じ非乗法性が及ぶ。ただし、文としては述べられていない。【高】
