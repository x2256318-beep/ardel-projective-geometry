## 定義
N を正の整数とし、ℤ/N 上の複素数値関数の空間 V_N = ℂ^{ℤ/N} を考える。
- 単数群 (ℤ/N)^× が掛け算で ℤ/N に作用する。軌道は「gcd(N, x) = s」（s は N の約数）で決まる集合 S_s である。これは対称なアソシエーションスキーム（円分的なスキーム、ℤ/N の単数の軌道によるシューア環から来るもの）を与える。
- D_s：S_s の指示関数を掛ける作用素（空間の側の射影。双対べき等元 E*_s にあたる）。
- E_s：離散フーリエ変換の側で、周波数 ξ が gcd(N, ξ) = s のところだけを残す射影（スキームの原始べき等元にあたる）。
- A_N：End(V_N) の中で D_s, E_s（s ∣ N）が生成する代数。基点 0 での Terwilliger 代数 T(0)。
- N ∣ M のとき、π: ℤ/M → ℤ/N を射影、π^*: V_N → V_M を引き戻し（f ↦ f∘π）とする。

## 問い
Q1. N ∣ M のとき、ℂ 代数の準同型 φ: A_N → A_M で、次を満たすものは存在するか。
  (i) すべての T ∈ A_N で φ(T)∘π^* = π^*∘T（引き戻しと両立）。
  (ii) φ(D_s) は D_t（t ∣ M）の線形結合、φ(E_s) は E_t の線形結合（殻を混ぜない）。
  単位元を保つ場合と保たない場合で答えは違うか。
Q2. 特に gcd(N, M/N) = 1 の場合と、N = p^e, M = p^{e+1}（p は素数）の場合で、答えはどう違うか。小さい例 (N, M) = (2,4), (2,8), (3,9), (2,6), (3,6) で考えてください。
Q3. この問い（Terwilliger 代数の、商群 ℤ/M → ℤ/N に沿った写像・帰納系の存在）は、既存の文献で扱われているか。Terwilliger 代数・アソシエーションスキーム（とくに商スキーム、直積、wreath 積、シューア環）・Bost–Connes 系の有限レベルなどの文献を調べ、答えを持つ文献があれば具体的に（著者・題・年・定理番号・URL）挙げてください。見つからなければ、何を検索したかを書いてください。
Q4. 同じ問いを、有限体 F_q 上の多項式環の F_q[t]/(t^e) → F_q[t]/(t^{e-1})（単数の軌道によるスキーム）で立てたとき、答えは ℤ/p^e の場合と同じ理由で決まるか。
