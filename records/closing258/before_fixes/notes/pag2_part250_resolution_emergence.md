- **定式化の出所。** Claude の案 1・2 を、著者が了承したものです（「推奨の案 1 と案 2 を合わせた形で進めてください」）。著者の定義そのものではありません。
- **問い（幾何・大域・極限の言葉で）。** 離散的な基礎から、どの粗視化のもとで、どの連続対象が極限として現れるか。現れる対象は粗視化の取り方によるか。
- **結論（Lean）。** 基礎を正の有理数の群（素数が生成する可算群）に置くと、次が成り立ちます。
  - log(ℚ_{>0}) は ℝ の部分集合として可算で、区間を含まず、全不連結です（連結な部分集合は 1 点以下）。
  - 無限素点の側の擬距離 d_∞ = |log q − log r| では、どの歩幅 ε > 0 でも任意の 2 点が鎖でつながります（well-chained）。d_∞ は log による ℝ の距離の引き戻しで、像は ℝ で稠密です。
  - 素数 p の側の擬距離 d_p = |v_p(q) − v_p(r)| では、0 < ε ≤ 1 のとき鎖でつながる ⇔ v_p が等しい、ε > 1 のときすべてつながります。「どの ε > 0 でもつながる」は成り立ちません。d_p は v_p による ℝ の距離の引き戻しで、像は ℤ の中にあり、ℝ で稠密ではありません。
  - 無限素点の側でも、1 個の p の冪 {p^k} の中では ε ≤ log p の鎖は動けません。log 2 と log 3 が生成する加法群は ℝ で稠密です。
- **2 つの側を分ける基準（独立照合 B の指摘を受けて明確にした点）。** Lean の文で d_∞ と d_p を分けているのは、次の 2 つです。
  - 「どの ε > 0 でも鎖でつながるか」：d_∞ は成り立ち（`chainIn_dInf`）、d_p は成り立たない（`not_forall_chainIn_dP`）。
  - 「ℝ の中の等長な像が稠密か」：d_∞ は稠密（`dInf_eq_dist` と `dense_logSet`）、d_p は稠密でない（`dP_eq_dist` と `half_le_abs_padicValRat_sub_half`）。
- **「創発」の案の限界（正直な記録）。** 着手時の案は「解像度を落とす = 鎖でつながる点を区別しない」でした。この読みでは、d_∞ の側の商はどの ε > 0 でも 1 点で、ℝ にはなりません。ℝ が現れるのは、稠密な等長像の閉包（完備化）という別の操作によります。つまり、この形式化は「直線が、解像度を落とした商として現れる」ことは示していません。示したのは「連続な対象 ℝ の中に、全不連結だがどの尺度でも鎖でつながる稠密な部分集合として基礎が入っている」ことです。しかも ℝ は logSet と d_∞ の定義に最初から使われています。「離散的な基礎だけから連続対象が出る」ことの形式化にはなっていません（確信度：高）。
- **位置づけ（正直な評価）。** どれも既知の事実で、照合 A の判定では「深い文は一つもない」です。中心の主張は「ℚ は連結でないが well-chained（鎖連結）である」という教科書の例を対数座標で述べたもので、新しい定理はありません（確信度：高）。このパートの中身は、著者の言葉（解像度、創発）を既存の言葉（ε-鎖、一様連結性、素点ごとの付値）に対応づける 1 つの案を、Lean で検証できる形にしたことです。この案が著者の意図に合うかは、著者の判断です。

### 0.2 log(ℚ_{>0}) は ℝ の中で全不連結で稠密（§1）

- **logSet。** 正の有理数の対数の全体です（def `logSet`）。正の有理数では log q = log r なら q = r なので、基礎の点は区別できます（`log_inj`）。
- **可算（`logSet_countable`）、区間を含まない（`not_Icc_subset_logSet`）。** a < b なら [a, b] は logSet に含まれません。証明は、e^a と e^b の間に無理数 r があり、log r は正の有理数の対数でないことによります。
- **連結な部分は 1 点以下（`subsingleton_of_isPreconnected`）。** logSet に含まれる連結な集合は、元が高々 1 個です。
- **稠密（`dense_logSet`）。** logSet は ℝ で稠密です。

### 0.3 歩幅 ε の鎖（§2）

- **定義（`chainIn S d ε x y`）。** ある n と列 c があって、c(0) = x、c(n) = y、i ≤ n で c(i) ∈ S、i < n で d(c(i), c(i+1)) < ε。
  - d は任意の関数です。距離の公理は仮定していません（対称でない d では、鎖の関係も対称とは限りません）。
  - 鎖は S の中だけを通り、端点も S に入ります。
  - 不等号は狭義の < ε です。文献には ≤ ε の流儀もあり、下の閾値（ε ≤ log p、ε ≤ 1）はこの選択によります。
  - d ≥ 0 なら、ε ≤ 0 では長さ 0 の鎖しかなく、S の上の等号になります（Lean の文はありません。d が負の値を取れるなら成り立ちません。前の版はこの条件を書いていませんでした：照合 B の指摘）。
- **基本の性質。** 反射性（`chainIn_refl`）、ε ≤ ε′ での単調性（`chainIn_mono`：解像度を落とすと、つながりは増える）、1 歩の鎖（`chainIn_of_lt`）、鎖の上で不変な量（`chainIn_invariant`）。
- 推移性と対称性は Lean にしていません（使わなかったため）。d_∞ と d_p の 2 例では、`chainIn_dInf` と `chainIn_dP_classification` から、正の有理数の上で同値関係になります。

### 0.4 無限素点の側（§3）

- **擬距離（def `dInf`）。** d_∞(q, r) = |log q − log r|。正の有理数の乗法で不変です（`dInf_mul_left`）。
- **well-chained（`chainIn_dInf`）。** どの ε > 0 でも、正の有理数の任意の 2 点 q, r は、正の有理数の中の d_∞ の歩幅 ε 未満の鎖でつながります。
  - 構成：q と r を結ぶ線分の n + 1 等分点を通ります。n は n > |r − q| / (min(q, r)·ε) と取ります。
  - 歩幅の評価は補題 `abs_log_sub_log_le`（0 < m ≤ x, y なら |log x − log y| ≤ |x − y| / m）によります。
- **{p^k} は ε ≤ log p で動けない（`eq_of_chainIn_primePow`）。** p ≥ 2、ε ≤ log p なら、{p^k : k ∈ ℤ} の中の鎖で x と y がつながるのは x = y のときだけです。異なる冪は log p 以上離れています（`dInf_zpow`）。ε > log p で {p^k} の全体がつながることは Lean にしていません（数値だけ。§2 の (3)）。
- **log 2 と log 3 で稠密（`dense_closure_log_two_three`）。** log 2 と log 3 が生成する ℝ の加法部分群は稠密です。
  - 証明：稠密でなければ最小の正の元 a があり、log 2 = M·a、log 3 = K·a（M, K は正の整数）となって 2^K = 3^M。これは 2 ∣ 3 を導き、矛盾します。
  - 一般の 2 個の素数の組は Lean にしていません（数値だけ。§2 の (4)）。{2^a 3^b} が d_∞ で鎖連結、という形の文もありません（稠密な部分群から初等的に出ますが、示していません）。

### 0.5 素数 p の側（§4）

- **擬距離（def `dP`）。** d_p(q, r) = |v_p(q) − v_p(r)|。0 でない有理数の乗法で不変です（`dP_mul_left`）。
  - これは p 進絶対値の距離 |q − r|_p ではありません。乗法の群 ℚ_{>0} の上の、付値の差です。
  - 整数値なので、d_p < 1 ⇔ v_p が等しい（`dP_lt_one_iff`）。
- **ε ≤ 1 では v_p が鎖の上で不変（`padicValRat_eq_of_chainIn`）。** 0 < ε ≤ 1 なら、鎖でつながる ⇔ v_p が等しい（`chainIn_dP_iff`）。v_p は ℤ の上に全射です（`exists_padicValRat_eq`）。
- **ε > 1 では全体がつながる（`chainIn_dP_of_one_lt`）。** p 倍の 1 歩は d_p = 1 < ε だからです。
- **分類（`chainIn_dP_classification`）。** p が素数で ε > 0 のとき、鎖でつながる ⇔（ε ≤ 1 ならば v_p が等しい）。
  - 帰結（Lean の文ではない）：鎖の成分は、0 < ε ≤ 1 では v_p の値ごと（ℤ で番号づけられる）、ε > 1 では 1 つです。成分の集合と ℤ の全単射は Lean にしていません。
  - 4f・4g は、独立照合 A の指摘（「まとめの対比が ε = 1 に固定されていて、対称な対比でない」）を受けて足しました。
- **既知の事実との関係（Lean ではない）。** 加法の p 進距離で完備化した ℚ_p も全不連結です。乗法の側でも ℚ_p^× = p^ℤ × ℤ_p^× で、単数の因子 ℤ_p^× は全不連結です。d_p が見ているのは p^ℤ の因子だけです。

### 0.6 まとめと有限レベルとの接続（§5）

- **ε = 1 での対比（`emergence_contrast`。名前は内容より強い）。** d_∞ ではどの ε > 0 でもすべての 2 点が鎖でつながります。どの素数 p でも、d_p の歩幅 1 未満の鎖は 1 と p をつなぎません。これは ε = 1 での対比で、p の側の全体像は上の分類です。
- **有限レベル（`dense_logSet_coprime`）。** N ≥ 1 と互いに素な正の整数 m, n だけでも、log n − log m は ℝ で稠密です（Part 249 の `exists_cls_near` から）。「有限個の素数を除いても無限素点の側の姿は変わらない」は解釈で、N と互いに素な有理数の鎖連結の形の文はありません。

### 0.6b 追補：等長な埋め込みと、2 つの側を分ける基準（§6）

- **d_∞ は log による引き戻し（`dInf_eq_dist`）。** d_∞(q, r) = dist(log q, log r)。`dense_logSet` と合わせると、正の有理数は d_∞ で ℝ の稠密な部分集合と等長です。完備化が ℝ であること自体（距離空間の一般論）は Lean にしていません。
- **d_p は v_p による引き戻し（`dP_eq_dist`）。** d_p(q, r) = dist(v_p(q), v_p(r))。
- **v_p の像は稠密でない（`half_le_abs_padicValRat_sub_half`）。** どの q でも |v_p(q) − 1/2| ≥ 1/2。
- **基準（`not_forall_chainIn_dP`）。** 素数 p では、「どの ε > 0 でもすべての 2 点が d_p の鎖でつながる」は成り立ちません。

### 0.7 観察（Lean なし、数値だけ）

- **高さの切り口。** 高さ H 以下の有理数 {m/n : m, n ≤ H} の対数を窓 [−1, 1] で見ると、最大の隙間 g(H) は H·g(H) ≈ 1 を満たしました（H = 10〜400 で 1.18 → 1.004）。最大の隙間は 1 の隣（log(H/(H−1))）に出ます。
  - つまり歩幅 ε で窓が 1 つにつながるのは、高さが 1/ε を超えたところです（ε = 0.01 で H = 101）。
  - これは ε と高さ H という 2 つの量の関係の観察です。どちらも著者の言う解像度のパラメータとは同一視しません。
- **p の側は ε > 1 で 1 点につぶれる。** これは Lean にしました（4f）。

## 4. 残る問い（本来の道）

- **全素点を同時に粗く見ると何が現れるか（極限の問い）。** 有限個の素数の集合 S について、d_∞ と d_p（p ∈ S）を同時に使うと、鎖の成分は ℤ^S で番号づけられ、各成分の有効な姿は ℝ になる見込みです（未検証。Part 249 の「有限個の素数を除いても稠密」を使う形）。S をすべての素数に広げた極限で何が残るかは、積公式 log q = Σ v_p(q)·log p が支配するはずです。
- **商としての粗視化と、完備化（このパートが答えられなかった点）。** 「解像度を落とすと直線が現れる」を商の言葉で言うには、鎖でつながる点の同一視では足りません（d_∞ の商は 1 点）。尺度 ε ごとの成分の系（ε → 0 の極限）や、完備化を「解像度を上げた極限」と読むなど、別の置き方が要ります。どれが著者の意図に近いかは、著者の判断です。

- **確かめたこと。**
  - well-chained space：任意の 2 点が、いくらでも細かい鎖でつながる距離空間。連結なら well-chained で、逆は成り立たず、有理数の集合が例。Cantor が 1883 年に連結性の定義として提案し、Whyburn の 1964 年の本にこの名前で出る（Wikipedia "Well-chained space"）。
  - 一様連結（uniformly connected、Cantor connected）：離散な一様空間への一様連続写像がすべて定数。距離があれば鎖連結と同じ。コンパクトなら連結と同じ（Wikipedia "Uniformly connected space"、Weiss, arXiv:1411.6323）。
