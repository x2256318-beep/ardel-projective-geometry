# アーデル射影幾何 — Part 251（PAG 2.0）：Part 249 の射影極限の側 — 素数の類は lim (ℤ/N)^× × ℝ で稠密な部分群を生成する

- **問いの出所。** 著者の指示です（2026-11-12、「Part 249 の射影極限の側から進めてください」）。
- **問い（極限の言葉で）。** Part 249 は、有限レベル (ℤ/N)^× × ℝ ごとに、素数の類が生成する部分群の稠密性を示しました。射影極限 lim (ℤ/N)^× × ℝ の上でも稠密か。そのために、素数 p の類を、すべてのレベルで両立する 1 つの元として作れるか。
- **結論（Lean）。**
  - 両立する系の群 `unitSys`（レベル N ≥ 1 ごとの単数の、自然な写像で両立する系の全体。各レベルは離散位相、全体は積位相の制限）を置きました。
  - 素数 p の類 κ_p を、すべてのレベルで両立する元として作りました。レベル N の成分は w_p(N) = 1 + p^(N!)·(p − 1) の逆元です。p ∤ N のレベルでは p⁻¹、p の冪のレベルに落とすと 1 です。この 2 つの性質を持つ両立する系は κ_p だけです。
  - L ≥ 1 を割らない素数の類 (κ_p, −log p) が生成する `unitSys × Multiplicative ℝ` の部分群は稠密です（以下 `unitSys × ℝ` と略します）。L = 1 で、すべての素数の類になります。
- **位置づけ（正直な評価）。**
  - 既知の事実です。C_ℚ ≅ Ẑ^× × ℝ_{>0} のもとで、素数イデール π_p の類が生成する部分群が C_ℚ で稠密、という主張に当たります。新規候補はありません（確信度：高）。
  - 稠密性そのものは、Part 249 の有限レベルの稠密性（`exists_cls_near`）と「開集合の各点は、あるレベルの筒（そのレベルの成分が同じ系の全体）を含む」（`exists_level`）からほぼ形式的に出ます。逆翻訳 A も「唯一の定理らしい文だが、入力は初等的」と判定しました。
  - このパートで Lean に新しく入った中身は、κ_p を大域の元として作ること（p^(K!) mod N が K ≥ N で一定であること）と、その一意性です。
  - Part 249 のノートが「既知の事実による推論、Lean ではない」としていた読み替え（独立照合 B の指摘 3・5）のうち、「すべての N で稠密 ⇒ 射影極限で稠密」と「k_p の p 成分を 1 とおく」を Lean にしました。
- **Lean にしていないこと。**
  - `unitSys` が Ẑ^×（Mathlib の Ẑ の単数群）と同型であること。
  - 構造定理 C_ℚ ≅ Ẑ^× × ℝ_{>0}（Mathlib の `IdeleClassGroup` との同一視）。したがって「イデール類群で稠密」は、この同一視のもとでの読みです。
  - `unitSys × ℝ` が位相群であること、`unitSys` がコンパクトであること。稠密性の文は位相だけを使っています。
  - 以下は独立照合 B の指摘で足した項目です。
    - `unitSys` が射影極限であること（普遍性、または Mathlib の極限との同型）。直積の中で閉、ハウスドルフ、完全不連結であること。各レベルへの射影が全射であること。`unitSys` は「両立する系の全体」という射影極限の具体モデルで、「射影極限」はその呼び名です。

    - p^(N!) mod N が冪等であること（e² ≡ e）。数値では確かめました（step274 (1)）。

### 0.1 冪等元 p^(N!) と w_p(N)（§1）

- **p^(K!) の安定性（`pow_factorial_modEq`）。** p が素数、0 < N ≤ K なら p^(K!) ≡ p^(N!) (mod N)。
  - 証明：N = p^a·M′（p ∤ M′）と分けます。法 p^a では、a < p^a ≤ N ≤ K! なので両辺 0（`pow_dvd_pow_factorial`）。法 M′ では、Euler の定理と φ(M′) ∣ K! から両辺 1（`pow_factorial_modEq_one`）。中国剰余定理で合わせます。
  - 補題 2 つを K = N で使うと、e = p^(N!) mod N は法 p^a で 0、法 M′ で 1 です。したがって e は冪等元（e² ≡ e）ですが、冪等性そのものは Lean の文にしていません（数値では確認。B の指摘）。有限半群の ω 乗 s^ω = lim s^(n!) の場合に当たります（§5）。
- **w_p(N) = 1 + p^(N!)·(p − 1)（def `wNat`）。**
  - N と互いに素です（`wNat_coprime`）。法 p^a で w ≡ 1、法 M′ で w ≡ p だからです。
  - 0 < N ≤ K なら w_p(K) ≡ w_p(N) (mod N)（`wNat_cast_eq`）。p ∤ N なら w_p(N) ≡ p (mod N)（`wNat_cast_of_coprime`）。
  - この式そのものは標準的ではありません（盲検の命名 C：「形式化のための工夫と思われる」）。中国剰余定理や ℤ_p への分解を経由せずに、両立する代表を 1 つの式で与えるために使いました。

### 0.2 射影極限と素数の類 κ_p（§2・§4）

- **`unitSys`。** 直積 ∏_{N ≥ 1} (ℤ/N)^× の部分群で、N ∣ M のとき自然な写像 (ℤ/M)^× → (ℤ/N)^× で両立する系の全体です。
  - 位相：各レベルに離散位相を宣言し（`instTopUnitsLevel`）、全体は積位相の制限です。
  - この環境の Mathlib の import の閉包には (ZMod N)ˣ の位相のインスタンスがなかったので、PAG255 の中で宣言しました（宣言の前は、積位相の合成に失敗しました。二重のインスタンスにはなっていません）。
- **κ_p（def `primeCls`・`primeSys`）。** レベル N の成分は k_{w_p(N)} = w_p(N)⁻¹ です（k は Part 249 の `kUnit`）。
  - 両立する系です（`primeCls_mem`）。
  - p ∤ N なら、レベル N の成分は Part 249 の k_p = p⁻¹ です（`primeCls_of_coprime`）。
  - p 成分は 1：p^a ∣ N なら、レベル N の成分を法 p^a に落とすと 1 です（`unitsMap_primeCls_pow`）。
- **一意性（`primeSys_unique`）。** 両立する系 a が、p ∤ N のすべてのレベルで p⁻¹ に等しく、p の冪のレベルに落とすと 1 なら、a = κ_p です。
  - 補題 `units_eq_of_coprime_parts`：N = A·B、A と B が互いに素なら、(ℤ/N)^× の元は法 A と法 B への像で決まります。
  - この項は、独立照合 A の指摘（稠密性は p 成分の取り方によらないので、稠密性の定理は κ_p の作り方を特徴づけていない）を受けて足しました。
- **既知の対象との対応（Lean ではない）。** イデール π_p（p 成分が p、ほかは 1）を p で割ると、Ẑ^× の成分は「p 成分が 1、ℓ ≠ p の成分が p⁻¹」、実数の成分は p⁻¹ になります。(κ_p, −log p) はこれに一致します（盲検の命名 C の計算と同じ）。Part 249 の辞書 §9 の対応（Artin 写像で Frob_p に写る元）とも合います。

### 0.3 射影極限での稠密性（§3）

- **生成元（def `primeGens L`）。** L を割らない素数 p の (κ_p, −log p) の全体です。実数の成分は `Multiplicative ℝ`（加法群 ℝ を乗法の記法で書いたもの）として、積の群 `unitSys × Multiplicative ℝ` に入れました。
- **レベルごとの元（`exists_mem_closure_level`）。** L ∣ N とします。N と互いに素な正の整数 m について、生成する部分群の元で、レベル N の成分が k_m、実数の成分が −log m のものがあります（素因数分解についての帰納法）。
- **開集合の各点はレベルの筒を含む（`exists_level`）。** `unitSys` の開集合 u と a ∈ u に対し、あるレベル N があって、レベル N の成分が a と同じ系はすべて u に入ります。積位相の基に出てくる有限個のレベルを、その積のレベル 1 つで置き換えます。
  - レベル N は点 a ごとに変わります。開集合全体が 1 つのレベルで決まる、という主張ではありません。
  - この文は、各レベルの位相が離散でなくても成り立ちます（積位相と両立性だけを使います）。離散であることが効くのは、逆向き（筒が開集合であること。Lean にしていません）と、稠密性の文の強さの側です（逆翻訳 A・照合 B の指摘）。
- **稠密性（`dense_closure_primeGens`・`dense_closure_allPrimes`）。** L ≥ 1 について、`primeGens L` が生成する部分群は `unitSys × ℝ` で稠密です。
  - 証明：開集合 U と点 x ∈ U を取ります。`exists_level` でレベル N₀ を取り、N = N₀·L に上げます。Part 249 の `exists_cls_near` で、N と互いに素な m, n を、k_m·k_n⁻¹ が x のレベル N の成分に等しく、log n − log m が実数の成分に ε 以内になるように取ります。対応する生成部分群の元の商が U に入ります。
- **稠密性が使っていないもの。** κ_p の p 成分（`unitsMap_primeCls_pow`）は、稠密性の証明に使われていません。p ∤ N のレベルで p⁻¹ に一致する両立する系なら、p 成分をどう選んでも同じ稠密性が成り立ちます（A の指摘。B も手で確認。証明から読み取れる注意で、Lean の文ではありません。確信度：高）。

## 4. 残る問い（本来の道）

- **`unitSys` と既知の対象の同一視。** unitSys ≅ Ẑ^×、unitSys × ℝ ≅ C_ℚ を Lean にすること。Mathlib の `IdeleClassGroup` の依存（145 モジュール）のビルドが要ります。既知の定理の形式化です。
- **稠密な部分群の上の構造を極限に延ばせるか。** 素数の類が生成する群は、正の有理数の群 ℚ_{>0} と同型です（素因数分解。Lean にしていません）。その上で定義された量（付値 v_p、Part 250 の擬距離）のうち、どれが unitSys × ℝ に連続に延びるか。Part 250 の d_∞ は実数の成分の距離として延び、d_p は延びない見込みです（v_p は稠密な部分群の上で連続でない。未検証）。Part 250 の「2 つの側を分ける基準」の、極限の側での言い換えになります。
- **より強い既知の事実。** Ẑ^× の成分だけなら、集合 {κ_p} 自体が稠密です（Dirichlet の算術級数定理）。Mathlib に Dirichlet の定理はありますが、この環境では未ビルドです。
- **Part 249 の定理 2.6 の極限の側。** 素数の平行移動と可換な作用素、という有限レベルの主張を unitSys の上（連続関数や L² の上）で述べること。平行移動の連続性による極限の議論が要ります（Part 249 の独立照合 B の指摘 6）。
- 以前からの候補：Part 250 の続き（商と極限の置き直し、全素点を同時に見る、無限素点での重なり）、有限レベルの Bost–Connes、Ẑ 上の定理 A。
