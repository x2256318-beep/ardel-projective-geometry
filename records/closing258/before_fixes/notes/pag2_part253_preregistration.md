## 1. K1：原始部分での、貼り合わせ U の作用素としての文

- **出所。** 本来の道の「無限素点を含む大域対象」の有限レベルの部分（重なり＝ねじれた貼り合わせ U の記述）。Part 252 の照合 B の指摘。

1. **幾何の言葉。** 切断した円筒の両端を U で貼ります（著者の決定）。問い：A1 のもとで、U は原始指標の部分で、明示的な実の核を持つ作用素として書けるか。その部分の外では何が起こるか。
2. **既存分野の言葉への最善の翻訳。**
   - 有限アーベル群のフーリエ解析です。原始指標はフーリエ変換の固有ベクトルで、固有値はガウス和です（F_N χ = τ(χ)χ̄、標準）。
   - Hartley の核は cas(θ) = ((1−i)e^{iθ} + (1+i)e^{−iθ})/2 なので、固有値にパリティの重み ε(χ) = i^{−a} が付きます。
   - 指標の直交性により、作用素の文は固有ベクトルの式（Part 252）から直ちに出ます。V_prim は T で不変、T|V_prim はユニタリで、T|V_prim = U_N|V_prim です。
   - 原始的でない指標では、固有値は W(χ) = μ(N/f)χ*(N/f)√(f/N)W(χ*)（ガウス和の標準の式）で、|W| ≤ 1/√2 です（等号は N ≡ 2 (mod 4)）。V_imprim の上では T ≠ U_N です。
   - 文献（盲検のエージェント）：使う式は Montgomery–Vaughan, Multiplicative Number Theory I の Thm 9.5・9.10。近い形として、「フーリエ変換∘全単射」が乗法的指標の基底で 2×2 と 1×1 のブロックに分かれることが Diaz-Vargas–Glebsky–Rubio-Barrios（arXiv:1803.09239、実在を確認）の Example 4.2 にあります。逆元 u⁻¹ を入れると χ と χ̄ の入れ替えが消えて対角になる、という読みです（盲検、確信度：中）。「Hartley 変換＋逆元」の作用素そのものの文献は見つかりませんでした。
3. **残余：計算だけ。** 作用素としての書き直しで、数学として新しい内容はありません（確信度：高）。Lean にすると、モノグラフの主張 (2)「U = JH_N」が「V_prim の上の作用素の等式」として閉じます。
4. **対照群テスト（数値 (Ca)・(Cb)・(Cc)）。**
   - F_p(t)（D は既約）では、Hartley の形の類似（ψ を ±1 だけで重み (1 ∓ i)/2 をつけて平均した実の核）の固有値がルート数と一致するのは、p = 3 ですべて（333/333）、p = 5 で 216/438、p = 7 で 384/1164、p = 11 で 69/357 です。
   - 不変な形は成り立ちます：η を χ の定数 F_p^× への制限として、η ≠ 1 ならルート数 ＝ (τ_ψ(χ)/p^{d/2})·(g(η̄)/√p)、η = 1 ならルート数 ＝ τ_ψ(χ)/p^{d/2}（24/24、定数 1。ψ(a) = e(a_{d−1}/p)、g は F_p 上のガウス和）。
   - 一致は η² = 1 のときちょうどです（(Cc) 2,292/2,292）。η が 2 次なら、2 次のガウス和の符号で一致します。位数 3 以上では、素体上のガウス和が「1 の冪根 × √p」にならない（Chowla。盲検の引用で、原論文は未確認）ので一致しません。
   - したがって、K1 の文の Hartley の形は「無限素点の単数が ±1」に依存します（ℚ では ℝ^×/ℝ_{>0} = {±1}、F_3(t) では F_3^× = {±1}）。不変な形は Tate の局所ルート数の積で［既知］、F_q(t) の明示の式は David–Florea–Lalín（arXiv:1901.00817、実在を確認）の Lemma 2.3・Cor. 2.4 にあります（盲検。偶指標の符号は関数等式の書き方で変わる）。
   - 一般化素数：指標とガウス和がないので、文が定義できません。
- **費用。** 1 パート。Mathlib の新しいビルドは要りません（直交性・ガウス和のモジュールはビルド済み）。V_imprim でのノルムの評価まで入れると、原始的でない指標のガウス和の式（Mathlib にない）が要るので、中心は V_prim の部分にします。
- **ラベル。** ［再導出］。

## 2. K2：法 N の貼り合わせ U_N 全体の、明示の核

## 4. K4：Ẑ の上の定理 A（本来の道 (A)）

- **出所。** 本来の道 (A)（CLAUDE.md §0 の 2）。

1. **幾何の言葉。** 有限素点の全体 Ẑ の上で、殻の指標の関数（ケット）のハール測度での畳み込みは、ガウス和の定数をかけたケットになるか。
