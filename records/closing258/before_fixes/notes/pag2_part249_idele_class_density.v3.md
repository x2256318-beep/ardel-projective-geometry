## 0. 結論

### 0.1 設定［既知］

- **イデール類群。** C_ℚ = 𝔸_ℚ^×/ℚ^× ≅ Ẑ^× × ℝ_{>0} です（ℚ の類数が 1 で、単数が ±1 のため）。対数座標を u = log ノルム とします（モノグラフの命題 2.1）。
- **素数イデールの類。** π_p は p 進の成分だけが p のイデールです。その類は [π_p] = (k_p, −log p) で、k_p = (p⁻¹)_{ℓ ≠ p} ∈ Ẑ^× です。
- **有限レベル。** U_N = ker(Ẑ^× → (ℤ/N)^×) とすると、C_ℚ/U_N ≅ (ℤ/N)^× × ℝ です。p ∤ N なら k_p ≡ p⁻¹ (mod N) です。
- **作用素（モノグラフ）。**
  - 素数シフト T_p = M_p ∘ S_{−log p}
  - 反転 W(k, u) = (k⁻¹, −u)
  - スケーリングの生成子 D = −i∂_u
  - Lean では境界（カットオフ Λ と境界ユニタリ）を入れず、(ℤ/N)^× × ℝ 上の関数への作用として定義しました。
- **注意。** ここでの N は合同部分群 U_N のレベルです。著者の言う解像度のパラメータとは同一視しません（CLAUDE.md §1）。

### 0.2 素数の類の生成と定理 2.6（Lean：§1〜2）

- **k_n の定義。** N と互いに素な n に対し、k_n = n⁻¹ ∈ (ℤ/N)^× とします（def `kUnit`）。
  - k_1 = 1、k_{ab} = k_a·k_b です。
  - N ∣ M なら、(ℤ/M)^× → (ℤ/N)^× は k_n を k_n に写します（`unitsMap_kUnit`）。よって k_p は Ẑ^× = lim (ℤ/N)^× の元を定めます。
- **生成（`kUnit_mem_of_prime`・`eq_top_of_prime`）。** (ℤ/N)^× の部分モノイドが、N と互いに素なすべての素数の k_p を含めば、全体になります。
  - 証明：単数 a は a⁻¹ の代表 n の k_n です。n を素因数に分けると k_n = ∏ k_{p_i} です。
- **定理 2.6 の前提（`commute_transl_of_prime`）。** U が N と互いに素なすべての素数 p の T_{k_p} と可換なら、すべての T_g と可換です。
  - T_g が U と可換になる g の全体は部分モノイドです（`commSubmonoid`）。
- **定理 2.6 (a)⇒(b) の一部（`eigen_of_commute_prime`・`thm26_prime`）。**
  - U は各指標 χ にスカラー c(χ) で働きます。
  - |c| = 1 と反転条件の固有値の形 c(χ⁻¹) = conj c(χ) を仮定すれば、実指標では c = ±1 です。
  - モノグラフの (a) は JUJ = U* という作用素の条件です。そこから固有値の形を導く部分（U のユニタリ性と、J が χ を χ⁻¹ に写すこと）は、追補 §0.8 で Lean にしました。
  - Part 1 の `eigen_of_commute`・`real_sector_sign` と組み合わせました。
- **A_N の側（`mem_dilCommute_of_prime`）。** 素数の単数倍 U_{k_p} と可換な作用素は、すべての単数倍と可換です（Part 220 の `dilCommute`）。
- **Dirichlet の定理が不要な理由。**
  - モノグラフの証明は「Dirichlet の算術級数定理［既知］により {k_p} は Ẑ^× で稠密」と述べていました。
  - 可換性は積と極限で保たれます。だから、{k_p} が生成する部分群が稠密であれば足ります。各レベル N で生成するのは素因数分解だけで示せます。
  - Dirichlet の定理が言うのは「各類に素数がある」ことです。これは集合 {k_p} 自体の稠密性で、ここで要る主張より強いです。

### 0.3 稠密性（Lean：§3）

- **主張（`exists_cls_near`）。** (ℤ/N)^× × ℝ の任意の点 (a, t) と ε > 0 に対し、正の整数 m, n（N と互いに素）で、次を満たすものがあります。
  - k_m·k_n⁻¹ = a
  - |log n − log m − t| < ε
  - (k_m·k_n⁻¹, log n − log m) は、正の有理数 m/n の素数イデールの積 ∏ π_p^{v_p(m/n)} の類です。
- **構成。**
  - m = 1 + Nj、n = a₀ + N⌊e^t·m/N⌋ と取ります（a₀ は a の代表 + N）。
  - すると |n/m − e^t| < 2N/m です。j を大きくして、log の e^t での連続性を使います。
- **有限個の素数を除いた版（`exists_cls_near_of_dvd`）。**
  - N ∣ M なら、m, n を M と互いに素に取れます。
  - (ℤ/M)^× で同じことをして、`ZMod.unitsMap` で落とします。
- **大域的な意味。**
  - C_ℚ ≅ Ẑ^× × ℝ の位相では、(aU_N) × (区間) の形の集合が開集合の基になります。
  - よって「すべての N で稠密」は「素数イデールの類（p ∉ S）が生成する部分群は C_ℚ で稠密」と同じです。
  - 構造定理は既知として使いました。Lean は各 N の主張です。

### 0.4 帰結（Lean：§4）

- **不変な関数は定数（`eq_of_prime_invariant`・`eq_of_prime_invariant'`）。**
  - F : (ℤ/N)^× × ℝ → ℂ が次を満たすとします：対数座標について連続で、M（N ∣ M）と互いに素なすべての素数で F(k·k_p, u − log p) = F(k, u)。このとき F は定数です。
  - 証明の流れ：素数での不変性を積と商に広げます（`invariant_kUnit`・`invariant_cls`）。それから稠密性と連続性を使います。
  - 意味：素数シフトで不変な（連続な）関数は、単数の作用 M_a とスケーリング S_s（D の生成する平行移動）でも不変です。群の側の主張（素数の類が生成する部分群の閉包が全体になること）は、§0.3 の稠密性です。
- **Euler データは指標を決める（`eq_of_euler`）。**
  - C_ℚ/U_N の指標 ψ(k, u) = χ(k)·e^{iλu} を考えます。M と互いに素なすべての素数で χ₁(k_p)·p^{−iλ₁} = χ₂(k_p)·p^{−iλ₂} なら、χ₁ = χ₂ かつ λ₁ = λ₂ です。
  - 証明：ψ₁/ψ₂ は素数シフトで不変なので、定数 1 です。λ₁ ≠ λ₂ なら u = π/(λ₁ − λ₂) で e^{iπ} = −1 となり、矛盾します。
  - モノグラフの Step 7 で、D_U と T_p の同時固有値が「Euler 因子型の位相 χ̄(p)p^{−iλ}」になると述べていた部分の、有限レベルでの単射性です。
  - これは GL₁ の強重複度 1 の素朴な場合です［既知］。Hecke はもっと強く、密度が 1/2 を超える素数の集合で足りることを示しています（Rajan の論文の紹介による。原典は未確認）。

### 0.6 有限レベルの代数 A_N との関係（観察、数値だけ：step272 の (7)）

- **観察。** A_N（Terwilliger 代数 T(0)）を単数の殻 (ℤ/N)^× に制限した角 D_1 A_N D_1 は、span{K_t : t ∣ N} と一致しました（N ≤ 40、法 p の掃き出しで 39/39）。
  - K_t(x, y) = [x ≡ y (mod t)] です。
  - 次元は #{t ∣ N : t ≢ 2 (mod 4)} でした。これは、法 N の指標に現れる導手の数です。
- **指標の基底での読み。** K_t は単数の乗法的な合同部分群 {r ≡ 1 (mod t)} の指示関数による畳み込みです。指標の基底では、導手が t を割る指標の上の射影の定数倍です。よって角の元は、指標の基底で「導手だけの関数」として対角に働きます。
- **推論（Lean なし、確度：中〜高）。**
  - 定理 2.6 の境界ユニタリ U（Uχ = e^{iα_χ}χ、α_χ̄ = −α_χ）が角に入るとします。χ と χ̄ は導手が同じなので、α_χ = α_χ̄ = −α_χ、つまり α_χ ∈ {0, π} です。
  - よって角に入るのは、導手ごとの符号 ±1 だけです。
  - 公理 A1 のユニタリ（固有値はルート数 W(χ)。複素指標では一般に実数でない）は角に入りません。
  - 言い換えると、境界の貼り合わせ A1 は、有限レベルの代数 A_N の外にある構造です。

### 0.8 追補（2026-11-08）：定理 2.6 (a)⇒(b) の有限レベル版を完全な形で（Lean：§6）

午前の照合（§7）で、`thm26_prime` が反転条件を固有値の形で仮定していて、モノグラフの (a) の JUJ = U* からその形を導く部分がないことがわかりました。その部分を足しました。

- **内積。** 有限群 G 上の関数に、標準のエルミート形 ⟪f, g⟫ = Σ_x conj(f x)·g x を入れます（def `ipG`）。モノグラフの 𝓑 = L²(Ẑ^×) の内積の有限レベル版で、正規化の定数は省きました（等長と随伴の条件には影響しません）。
  - 「U がユニタリ」は ⟪Uf, Ug⟫ = ⟪f, g⟫、「JUJ = U*」は ⟪JUJ f, g⟫ = ⟪f, Ug⟫ と書きました。Mathlib の随伴（`LinearMap.adjoint`）は使っていません。
- **主張（`thm26_full`）。** U が N と互いに素なすべての素数の平行移動 T_{k_p} と可換で、等長で、JUJ = U* なら、各指標 χ に次が成り立ちます。
  - Uχ = c(χ)·χ（午前までの 2e）
  - |c(χ)| = 1（`norm_eq_one_of_isometry`）
  - c(χ⁻¹) = conj c(χ)（`conj_eigen_of_adjoint`）。(ℤ/N)^× の上では χ̄ = χ⁻¹ なので、モノグラフの α_χ̄ = −α_χ にあたります。
  - 実指標では c(χ) = ±1
  - すべての平行移動と可換な一般の有限可換群でも同じです（`thm26_full_of_commute`）。
- **証明の要点。**
  - ⟪χ, χ⟫ = Σ |χ(x)|² は x = 1 の項だけで正なので、0 ではありません（`ipG_charFun_self_ne_zero`）。
  - 等長性から |c|²⟪χ, χ⟫ = ⟪χ, χ⟫、よって |c| = 1 です。
  - Jχ = χ⁻¹ なので JUJχ = c(χ⁻¹)·χ です。随伴の式に χ, χ を入れると conj c(χ⁻¹)⟪χ, χ⟫ = c(χ)⟪χ, χ⟫、よって c(χ⁻¹) = conj c(χ) です。
- **非空虚性の証人（Lean、`thm26_full_hyp_transl`・`transl_charFun`）。** 任意の h ∈ (ℤ/N)^× について、U = T_h は仮定をすべて満たし、固有値は c(χ) = χ(h) です。複素指標では実数でない位相が実際に現れるので、仮定が恒等写像のような自明な場合しか許さない、ということはありません。
- **仮定の除去（Lean）。**
  - 随伴の条件を外すと結論が崩れます（`thm26_needs_adjoint`）。U = i·id は素数の平行移動と可換で等長ですが、c(χ⁻¹) = conj c(χ) を満たす c は取れません（自明な指標で c = i、i ≠ conj i）。
  - 等長の条件を外すと結論が崩れます（`thm26_needs_isometry`）。U = 2·id は可換で JUJ = U* を満たしますが、|c| = 1 を満たす c は取れません。
- **扱っていないこと。**
  - 逆向き (b)⇒(a) は Lean にしていません。数値では、(b) を満たす c から作った U が (a) を満たすことを確かめました（step272 の (9a)、3 ≤ N ≤ 30）。
  - 境界つきの円筒（Λ、自己共役拡張）の上の主張ではなく、有限レベルの繊維 (ℤ/N)^× の上の主張です。
- **ラベル：** 再導出（定理 2.6 は著者の主張。この有限レベルの証明は、可換群の正則表現についての標準的な議論）。
