## 0. 結論

### 0.1 B_s と Terwilliger 代数

- B_s = ⟨D_u（すべての u ∣ N）, E_N, E_s⟩ ⊆ A_N = T(0) です。
- P = Σ_t P_{t,t}（主べき等元 ε_0）は ⟨D_u, E_N⟩ に入り、T(0) の中心にあります（Part 240）。よって B_s = B_s·P ⊕ B_s·(1 − P) と分かれます。
  - B_s·P は主加群の上の全行列環 M_{d(N)}(ℂ) です（Part 241）。
  - 素冪では T(0)(1 − P) は可換で、1 次元の既約加群ごとの値の組 ℂ^r です（BST、辞書の数値 (6d)）。
- ℂ^r の部分代数で 1 を含み、いくつかの元で生成されるものは、「生成元の値の組が同じ点を同じとみなした関数の全体」です。
- よって **dim B_s = d(N)² + （主でない型を生成元の値の組で分けたときの組の数）** です。生成元は D_t と E_s です（E_N は主でない部分で 0）。

### 0.2 素冪での数え上げ：足りない 1 次元

N = p^k の主でない型は (c, d) = (p^γ, p^δ) です。範囲は γ ≥ g（g = 1（p 奇数）・2（p = 2））、δ ≥ 0、γ + δ ≤ k です（Part 238）。

- 型 (p^γ, p^δ) の加群は、殻 D_{p^δ} に載り、双対殻 D_{p^u}（u = k − γ − δ）に載ります（Part 216〜219 の層 W(d) と、かなめ G_d）。
- D_t はこの加群の上で [t = p^δ]、E_t は [t = p^u] として働きます。

N = p³（p は奇素数）、s = p（j = 1）の場合：

| 殻 δ | 型 γ | 双対殻 u | E_p の値 | B_p の値の組 |
|---|---|---|---|---|
| 0 | 1 | 2 | 0 | (δ = 0, 0) |
| 0 | 2 | 1 | 1 | (δ = 0, 1) |
| 0 | 3 | 0 | 0 | (δ = 0, 0) |
| 1 | 1 | 1 | 1 | (δ = 1, 1) |
| 1 | 2 | 0 | 0 | (δ = 1, 0) |
| 2 | 1 | 0 | 0 | (δ = 2, 0) |

- 値の組は 5 種類です。1 行目と 3 行目（u = 2 と u = 0）が同じ組になります。
- よって dim B_p = 16 + 5 = 21 = F − 1 です（F = 22）。
- E_1（u = 0 で 1）と E_{p²}（u = 2 で 1）はこの 2 行を区別するので、B_p に入りません。
- E_1 + E_{p²} は 2 行とも 1 なので入ります。
- N = 16、s = 2 も同じ形です（γ ≥ 2 で、δ = 0 に u = 2, 1, 0 が並ぶ）。

**閉じた式（数値だけ）。**
- 殻 δ の型の双対殻は u ∈ {0, 1, …, k − δ − g} です。
- 組の数は、各 δ で 1、さらに「型が 2 つ以上あり j がその中にある」なら +1 です。
- 数えると、dim B_{p^j} = (k+1)² + (k − g + 1) + c_j になります。c_0 = k − g、j ≥ 1 で c_j = max(0, k − g − j + 1) です。
- 例：N = p³ で dim B_1, B_p, B_{p²}, B_{p³} = 21, 21, 20, 19。N = 16 で dim B_1, B_2, B_4, B_8, B_16 = 30, 30, 29, 28, 28。

### 0.3 証拠と主補題

**証拠の関数。**
- q = δ_1 − (1/p)·1_{1+(N/p)ℤ} = (1/p)·Σ_{c < p}(δ_1 − δ_{1+c(N/p)}) です（def `levelWit`）。
- p² ∣ N なら、1 + c(N/p) は単数です。よって q は単数の殻に載り、P q = 0 です（Part 246 の 2 点の関数 `twoPt` の和）。
- フーリエ変換は次のとおりです。
  - (N/p)k ≠ 0（法 N）なら 𝓕q(k) = e(−k)。
  - (N/p)k = 0 なら 𝓕q(k) = 0。
  - したがって p ∣ s なら E_s q = 0 です（D_s の点 k は p ∣ k.val）。

**主補題**（`convL_geps_one_not_mem_addEAlg_of_level`）：p 素数、p^{m+1} ∣ N、p ∣ s、p^m ∤ s、N ∤ 2p^m なら E_1 ∉ B_s。
- f = q + h とおきます（h = `unitWit N p m` = Σ_{c < p^m}(δ_{1+cM} − δ_{−(1+cM)})、M = N/p^m）。
  - P f = 0 で、f は単数の殻に載ります。
  - E_s f = 0 です。q は p ∣ s から、h は p^m ∤ s から（Part 247 の `convL_geps_unitWit`）。
  - よって f ∈ U_s^⊥ です。
- Part 246 の判定法（`exists_apply_eq_smul_of_mem_addEAlg`）により、E_1 ∈ B_s なら E_1 f = c·f です。両辺を 𝓕 で写すと 1_{D_1}·𝓕f = c·𝓕f です。
- k = 1 では、𝓕q(1) = e(−1)、𝓕h(1) = 0（M ≢ 0）、1_{D_1}(1) = 1 なので c = 1 です。
- k = p^m では、𝓕q(p^m) = 0、𝓕h(p^m) = p^m(e(−p^m) − e(p^m))、1_{D_1}(p^m) = 0 です。
  - 0 = p^m(e(−p^m) − e(p^m)) となりますが、N ∤ 2p^m なので右辺 ≠ 0 です。これで矛盾します。
- 仮定 N ∤ 2p^m は外せません。p = 2、N = 2^{m+1} では h = 0 になり、f = q は E_1 の固有ベクトルです（数値 (3)）。
- p ∣ s と p^m ∤ s から m ≥ 2 です。

### 0.4 分類の完成と素冪の系

- **除いた組。** N = p³（p は奇素数）、s = p：m = 2 で p³ ∣ N、p ∣ p、p² ∤ p、p³ ∤ 2p² です。N = 16、s = 2：m = 2 で 8 ∣ 16、2 ∣ 2、4 ∤ 2、16 ∤ 8 です。よって B_p ≠ A_{p³}、B_2 ≠ A_16 です。
- どちらも |S′| = 3 です（Part 241 の |S′| + 1 + [2 ∣ N] = d(N)：p³ では 3 + 1 + 0 = 4、16 では 3 + 1 + 1 = 5）。さらに平方因子をもつので、主定理の右辺も偽です。
- **主定理**（`addEAlg_eq_shellAlg_iff_all`）：s ∈ S′ なら、B_s = A_N ⇔ |S′| ≤ 2 ∨（N が平方因子なし ∧ s ∈ {1, 2}）です。証明では、除いた組をここの結果で、それ以外を Part 247 の `addEAlg_eq_shellAlg_iff` で扱います。
- **素冪**（`addEAlg_eq_shellAlg_iff_primePow`）：N = p^k、s ∈ S′ なら、B_s = A_N ⇔ k ≤ 2 ∨ N = 8 です。
  - |S′(p^k)| = k − [p = 2] で、p^k が平方因子なしなら k ≤ 1 です。
- **E_1 の判定**（`convL_geps_one_mem_addEAlg_iff_primePow`）：s = p^j ∈ S′ なら、E_1 ∈ B_s ⇔ j = 0 ∨ k ≤ 2 ∨ N = 8 です。
  - ⇒ は、j ≥ 2 なら Part 247 の `convL_geps_one_not_mem_addEAlg_primePow`、j = 1 なら主補題（m = 2）です。

### 0.5 フーリエ双対

- 𝓕 による共役は E_1 ↔ D_1、B_s ↔ ⟨E_u, D_N, D_s⟩ と移します（Part 246 の `dualAddEAlg`）。
- よって主補題と同じ仮定で D_1 ∉ ⟨E_u, D_N, D_s⟩ です（`mulLeft_dind_one_not_mem_dualAddEAlg_of_level`）。
- ⟨E_u, D_N, D_s⟩ = A_N の条件も主定理と同じです（`dualAddEAlg_eq_shellAlg_iff_all`）。
