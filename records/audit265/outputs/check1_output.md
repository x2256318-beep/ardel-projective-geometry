## 1. 逆翻訳

記号：a, b, c は正の整数で順序は整除（a ≤ b ⇔ a ∣ b）。A_N は ℂ^{ℤ/N} の上の作用素のうち D_s（gcd(N,x) = s の指示関数を掛ける）と E_s（geps N s との畳み込み）が生成する部分代数。π: ℤ/M → ℤ/N は剰余写像、π^* は引き戻し、π_* は繊維の和。

- cornerSys：a ∣ b のとき A_a → A_b の ℂ 線形写像 φ_{a,b}(S) = (a/b) π^* S π_*。非単位的な代数準同型 cornerHom から線形写像の部分だけを取り出したもの。
- cornerSys_apply：φ_{a,b}(S) は cornerHom の値そのもの（定義による）。
- cornerSys_self：任意の a と S ∈ A_a で φ_{a,a}(S) = S。
- cornerSys_comp：a ∣ b ∣ c と S ∈ A_a で φ_{b,c}(φ_{a,b}(S)) = φ_{a,c}(S)。
- instance：族 (A_a, φ_{a,b}) は整除の順序の上で帰納系の 2 法則（恒等と合成）を満たす。添字の有向性はこの文に入っておらず、PAG258 の別の instance にある。
- CornerLim：この系の ℂ ベクトル空間としての直極限。積の構造は持たない。
- cornerLim_of_injective：任意の a で標準の写像 A_a → CornerLim は単射。

## 2. 非空虚性の証人

- cornerSys_self：a = 4、S = D_2。π = id で係数は 1 なので、文は D_2 = D_2 を言うだけ。空虚ではないが内容は自明で、End のどの作用素でも成り立つ。
- cornerSys_comp：(2,4,8)、S = D_2 ∈ A_2（gcd(N,M/N) ≠ 1 の段の例）。φ_{2,4}(D_2)f = ½[x 偶](f(0)+f(2))。それに φ_{4,8} を続けた結果も φ_{2,8}(D_2) を直接計算した結果も ¼[x 偶]Σ_{y 偶} f(y)。文の中身は、引き戻しと繊維の和がそれぞれ合成と両立することと、係数の積 (2/4)(4/8) = 2/8 だけ。これも End 全体で成り立つ。
- cornerLim_of_injective：a = 1 では A_1 ≅ ℂ なので「CornerLim ≠ 0」を含む。a = 2 では of_2(D_2) ≠ 0。自明ではない。ただし有向な添字の上では ker of_a = ⋃_{b≥a} ker φ_{a,b} なので、「すべての of_a が単射」と「すべての遷移写像が単射」は同値で、中身は PAG264 の cornerHom_injective の言い換え。

## 3. 除去テスト

- cornerLim_of_injective が依存しているもの：IsDirectedOrder Lvl、DirectedSystem の instance、cornerHom_injective、Mathlib の exists_eq_of_of_eq。
- 遷移写像の単射性を外すと反例がある：φ'_{a,b} = 0（a ≠ b）と φ'_{a,a} = id は 2 法則を満たし、添字に最大元がないので極限は 0 になり、どの of_a も単射でない。
- 有向性を外した場合（一般論）：王冠型の半順序（a, b < c, d）で写像を id, id, id, ×2 にとると極限は 0。
- 整除の部分順序（ユニタリ約数の順序、無平方数どうしの整除）に替えた場合：2 法則は制限なので成り立つ。ユニタリ約数の順序は有向でない（2 と 4 に共通の上界がない）ので Lean の証明は通らない。それでも文は真のまま（全体の CornerLim が部分の図式の余錐になるので、部分の極限への標準の写像も単射）。
- 整除でない順序（通常の ≤、逆の整除）：cornerOp が定義できず文が立たない。x ↦ x.val mod a で無理に定義すると合成の法則が破れる（6 → 4 → 3 と 6 → 3 が x = 4 で食い違う）。
- pos を外す：shellAlg は NeZero を要するので型が付かない。無理に入れると Lean では (a:ℂ)/0 = 0 なので恒等の法則が破れる。
- 使っていない仮定：gcd(a, b/a) = 1 はどの文も使っていない。正規化 a/b を外しても、A_a を End 全体に替えても、3 つの文はすべて成り立つ。係数が効くのは乗法性だけ。
