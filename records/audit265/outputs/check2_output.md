## 成果物 1：逆翻訳

記号：正の整数 a について、A_a は ℤ/a 上の複素数値関数の空間に働く線形作用素の部分代数で、D_s（gcd(a,x) = s の指示関数を掛ける）と E_s（その逆フーリエ変換との畳み込み）が生成するもの（s は自然数全体を走る）。a ∣ b のとき π: ℤ/b → ℤ/a は還元写像、π^* は引き戻し、π_* は繊維の和。レベルは正の整数で、整除で順序をつける（有向、積 ab が共通の上界）。

- cornerSys：a ∣ b のとき φ_{a,b}(S) = (a/b) π^* ∘ S ∘ π_* で A_a → A_b を定める。ℂ 線形で積を保つが、単位元を保つことは要求しない。値が A_b に入ることは前の鎖の cornerHom が保証する。
- cornerSys_self：φ_{a,a}(S) = S。
- cornerSys_comp：a ∣ b ∣ c のとき φ_{b,c} ∘ φ_{a,b} = φ_{a,c}。
- instance DirectedSystem：この族と写像は恒等と合成の法則を満たす。添字の有向性はこのクラスの内容ではなく、別のインスタンス（PAG258）が与える。
- CornerLim：直極限。組 (a, S) 全体を「ある共通の上界 c で φ_{a,c}(S) = φ_{b,c}(T)」で割った集合。Mathlib のインスタンスにより非単位的な環の構造と ℂ のスカラー倍が付き、演算は共通の上界へ送ってから行う。abbrev が定めるのは型だけ。
- ofCorner：標準写像 ι_a: A_a → CornerLim、S ↦ [(a, S)]。非単位的な ℂ 代数準同型。
- ofCorner_apply：ι_a(S) は (a, S) の類（定義からそのまま）。
- ofCorner_cornerSys：a ∣ b のとき ι_b(φ_{a,b}(S)) = ι_a(S)。
- ofCorner_injective：どの a でも ι_a は単射。
- exists_local_unit：極限のどの元 x にも、ある正の整数 a があって e_a = ι_a(1) が e_a x = x = x e_a を満たす。
- not_exists_left_one：すべての x について ux = x となる元 u は極限にない（左単位元がなく、とくに両側の単位元もない）。

## 成果物 2：非空虚性の証人

手計算の前提（実行による確認はしていない）：A_1 ≅ ℂ。A_2 = M_2(ℂ)（D_2E_2D_1 が行列単位の定数倍になるため）。φ_{1,2}(1) = ½J = E_2 ≠ 1。

- ofCorner_injective：a = 1 で e_1 ≠ 0、したがって極限は零環ではない。a = 2 で 4 次元の M_2(ℂ) が極限に埋め込まれる。自明ではなく、遷移写像の単射性に依存する。
- exists_local_unit：x = ι_2(D_1) なら a = 2 で成り立つ。a = 1 では成り立たない（½J D_1 = ½[[0,1],[0,1]] ≠ D_1）。x = 0 ならどの a でもよく、文は空に近い。一般の x でも代表のレベルをとるだけで出る。直極限の構成からほぼ自動的に成り立つ文。
- not_exists_left_one：仮定のない否定文。候補 u = ι_c(U) にはそれぞれ反例 x = e_{2c} が対応する。u = e_1 には x = e_2 が反例（u e_2 = ι_2(½J) ≠ e_2）。u = e_2 には x = e_4 が反例（φ_{2,4}(1) は階数 2 の射影）。極限が零環でないことも含意するので空虚ではない。
- ofCorner_cornerSys：(a, b, S) = (1, 2, 1) で ι_2(½J) = ι_1(1)。(2, 4, D_1) で φ_{2,4}(D_1) は g ↦ [x 奇数]·½(g(1) + g(3))。a = b では自明。どの直極限でも成り立つ一般論の文。

## 成果物 3：除去テスト

**not_exists_left_one の依存**
1. 狭義の段で φ_{c,d}(1) ≠ 1 であること（本質）。遷移写像が単位的なら文は偽（反例：同じ添字で F_a = ℂ、遷移写像が恒等の系）。φ(1) ≠ 1 自体は正規化によらない（0 でないどの定数を掛けても階数は a < b のまま）。
2. どのレベルの上にも狭義に大きいレベルがあること（証明では d = 2c）。反例：12 の約数だけの系（有向で最大元 12、極限は A_{12} と全単射で e_{12} が単位元）。
3. 単射性：極限での等式をレベル d に引き戻すのに使う。より弱い条件「上のレベル e で φ_{c,e}(1) ≠ φ_{d,e}(1)」で置き換えられる。ただし非退化性は要る（反例：狭義の段で零写像、a = a で恒等写像の系。2 法則を満たし極限は零環）。
4. 正規化 a/b：これがないと積を保たないので、極限の環構造も cornerOp_one_mul も立たず、文が書けない（φ_c(S)φ_c(T) = c(b/a)φ_c(ST)）。合成の法則だけなら c_{a,b}c_{b,c} = c_{a,c} を満たす正規化で足りる。
5. 添字の有向性：極限の環構造に要る。証明そのものは c ∣ 2c しか使わない。通常の大小に替えると遷移写像が定義されない。ユニタリ約数の順序のような有向でない順序に替えると文が書けない。最大元のない有向な部分順序（無平方数、2^k の鎖、k! の鎖）では同じ証明で文が残る。したがってこの文は素数冪の段にも gcd(N, M/N) にもよらない。効いているのは cornerOp がすべての狭義の段で非単位的であること。
6. A にないこと：右単位元がないこと。

**exists_local_unit の依存**：使うのは (a) 元がどれもあるレベルの像であること、(b) 各レベルが単位的であること、(c) ι_a が積を保つことだけ。単射性・φ(1) ≠ 1・正規化の値・最大元がないことは使わない（零写像の系、定数の系、12 の約数の系のどれでも成り立つ）。文が書ける範囲の変種では反例が作れず、cornerOp に固有の内容はない。真だが A にない事実：e_a が冪等であること、有限個の元に共通の局所単位元があること、a ∣ b のとき e_a e_b = e_a であること。not_exists_left_one と合わせると、a は x に依存せざるをえない。

**そのほか**：ofCorner_injective は cornerHom_injective に依存（零写像の系が反例）、直極限の同値関係のために有向性も要る。ofCorner_cornerSys はどの直極限でも自動的に成り立つ。cornerSys_self／comp は cornerOp_self／comp に依存。
