# 査読所見：構成は「ディリクレ指標の根数（root number）」、新規の内容は見当たらない

以下はすべて記憶に基づく判断で、定理番号は照合していません。

## 2. P1〜P6 は標準か

- **P1**：標準です（確信度：高）。中国剰余定理で a = a₁N + a₂M と置く一行の計算で、原始性は要りません。Montgomery–Vaughan『Multiplicative Number Theory I』9 章、Iwaniec–Kowalski 3 章にあるはずです（所在は中、定理番号は覚えていない）。
- **P2**：a(χ₁χ₂) ≡ a₁ + a₂ (mod 2) からの自明な計算です（高）。
- **P3**：P1 と P2 の積で、標準です（高）。
- **P4**：原始性の保存は標準です（高）。ただし指摘が一つあります。Ξ4 の固有値は非原始な指標も走るので、その場合の因子は χ₁\*(f₂)·χ₂\*(f₁)（f は導手）であり、χ₁(N)·χ₂(M) とは一般に異なります。例：M = 3、N = 25、χ₂ が法 5 から誘導されるとき、χ₁(25) = 1 ですが χ₁(5) = −1 です。「同じ式」は原始な組に限るか、導手で書き直す必要があります（高）。
- **P5**：根数が中国剰余分解で乗法的でないという周知の事実です。法 3 の二次指標と法 5 の四次指標で、因子は ±i になります（高）。
- **P6**：平方剰余の相互法則の形です（高）。奇素数 p, q の二次指標に入れると (q/p)(p/q) = (−1)^{(p−1)(q−1)/4} になります。ただし P6 自体は P3 の自明な系です。相互法則の中身は「二次の原始指標で W = 1」というガウスの符号決定で、これは性質の一覧にありません。P6 だけでは相互法則の証明になりません。

## 3. 局所・大域の説明

- χ をイデール類指標 ω = ⊗ω_v と見ると、W(χ) = Π_v ε_v(ω_v, ψ_v, 1/2) です（Tate の学位論文、Langlands–Deligne の局所定数）。
- 「Ξ1 は素点ごとの積に分かれるか」への標準の答えは「分かれる」です（高）。
- 分かれないのは、中国剰余分解 χ = χ₁χ₂ に関する乗法性です。p | M での χ の局所成分は、χ₁ の局所成分に χ₂ の p での不分岐成分を掛けたものだからです。
- 不分岐な η に対して ε(ωη, ψ) = η(ϖ)^{a(ω)+n(ψ)}·ε(ω, ψ) が成り立ちます。これを p | M で掛け合わせると χ₂(M)、p | N で χ₁(N) が出ます（高。ただし逆元か否かは規約に依存し、そこは中）。
- Θ1 は無限素点での ε_∞(ω₁ω₂)/(ε_∞(ω₁)·ε_∞(ω₂)) です（高）。
- 二次指標では、全体がヒルベルト記号の積公式 Π_v (a, b)_v = 1 と同値です（高）。

## 4. F_q(t) では何が変わるか

- **無限素点が非アルキメデスになる**：偶奇は「χ が F_q^× 上で自明か」に置き換わります。ε は ±1, −i ではなく、χ を F_q^× に制限した指標の有限体ガウス和を正規化したものになります（高）。
- **Θ1 は正規化ヤコビ和型の因子になる**：一般には ±1 ではありません（中）。
- **標準加法指標が一意でない**：標準因子の次数が −2 なので、ψ をどこでも不分岐にはできず、∞ で導手のずれが出ます（高）。
- **P6 の類似は d 乗剰余の相互法則**：d | q−1 について (P/Q)_d·(Q/P)_d^{−1} = (−1)^{((q−1)/d)·deg P·deg Q} です。Rosen『Number Theory in Function Fields』3 章にあります（内容は高、所在は中）。証明は終結式で済み、ガウス和の符号決定は要りません。
- **根数が代数的になる**：L は多項式で、根数はフロベニウスの行列式として読めます。局所分解は Deligne と Laumon の積公式です（中）。

## 5. 標準の事実を超える内容

ない、と判断します（確信度：高〜中）。P1〜P6 は教科書の範囲です。Ξ4 という作用素への束ね方は言い換えで、新しい定理ではありません。

- 価値がありうるのは形式化としての新規性だけですが、既存の形式化ライブラリとの重複は未確認です（低）。
- 非自明な方向に進めるなら、候補は三つです：Ξ4 の核の明示（Kloosterman 型か）、非原始指標を含めた正確な合成則、導手が互いに素でない場合（ヤコビ和）。
