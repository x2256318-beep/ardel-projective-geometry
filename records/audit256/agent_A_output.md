# 査読結果：S1〜S22 の翻訳・判定と全体所見

結論を先に言うと、22 文はすべて正しく読めますが、内容は教科書的な「互いに素な法でのガウス和の捻れ乗法性」と、その根数（root number）版の形式化にとどまります。作用素 Ξ4 についての等式や相互法則そのものは示されていません。検算はすべて手計算です。

## 1・2. 翻訳と判定

記号は e(t)=e^{2πit}、τ(χ)=Σχ(a)e(a/n)、Φ=Φ1(χ₁,χ₂)、c=χ₁(N mod M)·χ₂(M mod N) とします。

Ξ2 は偶で 1、奇で −i で、つまり 1/ε(ε は偶で 1、奇で i）です。Ξ1=τ(χ)/(ε√n) は原始指標では根数 W(χ) です。Θ1=(−1)^{a₁a₂}（a_i は偶奇を 0/1 で表したもの）です。

確信度は、個別に断らないかぎり翻訳・判定とも「高」です。

## 3. 全体所見

**言えていること。** 互いに素な法で、積指標のガウス和は c 倍で分解し（S6）、根数は Θ1·c 倍で分解します（S12）。単純な乗法性は法 3 と 5 の例で破れます（S18）。

**言えていないこと。** Ξ4 の作用素としての分解、非原始指標での Ξ3 の公式、相互法則そのもの、Θ1 単独の不可欠性の 4 点です。

### (a) S6・S12 の「互いに素」の仮定

- **仮定は真であるためには不要です**（確信度：高）。gcd=g>1 なら M,N>1 で、N は mod M で非単数なので χ₁(N)=0 となり、右辺は 0 です。
- 左辺も 0 です。S5 により Φ(a) は a mod lcm(M,N) だけで決まり、Σ_{k mod g} e(k/g)=0 なので τ(Φ)=0 です。
- したがって仮定を外しても偽にはならず、非互いに素の場合は 0=0 という自明な等式になります。仮定は証明（S3 経由）の都合であり、文としては強められます。S12 も同じです。
- **原始性を仮定していないこと**：恒等式としてはより一般です。ただし非原始な χ では Ξ1 は根数ではありません（|Ξ1|≠1 で、0 にもなります）。
- S12 が「根数の法則」として意味を持つのは原始の場合だけです。非原始では「法 n で正規化したガウス和の恒等式」にすぎません。

### (b) S14・S15 と作用素 Ξ4

- Ξ4 は指標基底で対角な作用素で、χ 上の固有値は Ξ3(χ)（χ を誘導する原始指標の根数）です。これは R3 ですでに示されています。
- S15 が加えるのは、原始 χ₁,χ₂ に対する積指標 Φ 上の固有値の値だけです。その値は Θ1·c×(各法での固有値の積) です。
- 作用素の等式にはなっていません。足りないものは次のとおりです。
  1. 非原始指標の場合。gcd=1 なら法 MN の全指標は Φ の形なので、全固有値を得るにはこれが必要です。
  2. S14 の式は非原始にはそのまま延びません。因子は導手 f₁,f₂ を使った χ₁*(f₂)χ₂*(f₁) に変わるはずです（確信度：中）。
  3. 関数空間の同一視 (Z/MN)ˣ≅(Z/M)ˣ×(Z/N)ˣ の下での「Ξ4_{MN}=捻れ・(Ξ4_M⊗Ξ4_N)」という定式化がありません。S22 はその素材にすぎません。
- 補足：c は「χ₁ だけの因子×χ₂ だけの因子」なので各側に吸収できます。一方 Θ1=(−1)^{a₁a₂} は分離できません（行列 [[1,1],[1,−1]] の階数は 2）。
- よって両側に偶奇の両方がある限り、Ξ4_{MN} はどんな A⊗B にもならないはずです。ただしこれは文としては述べられていません（確信度：中）。

### (c) S16 が近い定理と不足

- 近いのは**平方剰余の相互法則のガウス和による証明**の最終段です。
- 二次指標 χ_p,χ_q では c=(q/p)(p/q) で、Θ1=−1 は p≡q≡3 (mod 4) と同値です。よって Θ1·c=1 は相互法則そのものです。
- 不足しているものは次のとおりです。
  1. 仮定 w1・w2・w12、つまり二次ガウス和の符号決定（Gauss の定理、W=1）。ここが深い部分で、未証明です。
  2. 二次指標や Legendre 記号・Jacobi 記号への特殊化。
  3. 仮定が非自明に満たされる例。
- 仮定 h は冗長です。gcd>1 なら Ξ1(Φ)=0≠1 となるからです（確信度：高）。
- 現状は「S12 に 1 を代入した代数」です。

### (d) S18・S19 の例

- 奇の原始指標どうし（法 3 の二次指標と、法 5 の χ(2)=±i）を取ると Θ1=−1 です。
- さらに χ₁(5 mod 3)=χ₁(2)=−1、χ₂(3)=∓i なので、Θ1·c=∓i≠1 です。R2 より根数は 0 でないので、不等式が出ます（手計算、確信度：高）。
- **示していること**：W が単純には乗法的でないこと。
- **示していないこと**：
  - Θ1 単独の必要性。この例のずれは c の寄与（∓i）と混ざっています。
  - ずれの値そのもの。
  - 普遍性。存在例は 1 組だけです。
  - 作用素として Ξ4_{15}≠Ξ4_3⊗Ξ4_5 であること。
- 法 5 の偶の二次指標を選ぶと Θ1·c=1 となり、等号が成立します。例は選び方に依存します。
- S19 は S18 と同内容です。

### (e) 標準を超える内容

- **ありません**（確信度：高）。S6 は Iwaniec–Kowalski などにある標準補題で、S12 は根数の捻れ乗法性です。
- 価値は形式化そのものにあります。Mathlib に同じ補題がまだ無い可能性はあります（確信度：低、確認していません）。
- 22 文のうち実質的なのは S3・S6・S12・S13 の 4 つです。残りは補助、言い換え、具体例です。

## 4. 定義の気になる点と規約依存

- **Ψ1**：val（自然数への持ち上げ）を経由する証明用の装置で、中国剰余定理の逆写像ではありません。逆写像を使っても因子 c は同じなので、結論は Ψ1 の選び方に依存しません。
- **加法指標の規約**：stdAddChar は e(+a/n) です（Mathlib の規約、確信度：中〜高）。e(−a/n) にすると τ は χ(−1) 倍になりますが、S6・S12 の形は不変です。ただし Ξ1 の値自体は変わるので、S16 の仮定「=1」と S18 の具体値は規約に依存します。
- **Ξ1 の正規化**：
  - √n は導手ではなく法を使っています。そのため非原始では根数になりません。
  - `if χ.Even then 1 else I` は「偶でなければ i」です。
  - ℂ 値では χ(−1)²=1 なので、偶か奇のちょうど一方が必ず成り立ちます。n=1,2 では −1=1 なので偶です。
  - したがって「偶でも奇でもない」場合はありません（確信度：高）。ただしこの二分法の補題は一覧に明示されていません。
- **Θ1**：Classical な if による定義です。(1+χ₁(−1)+χ₂(−1)−χ₁(−1)χ₂(−1))/2 のような閉じた式でも書けます。対称で、問題はありません。
- **Ξ3・Ξ4**：
  - Ξ3 は法が導手に変わる依存型です。そのため S14 を非原始に延ばすには水準の付け替えが必要になります。
  - Ξ4 の固有値に非原始指標の「原始化した根数」を使うのは一つの選択です。
  - ip は第 1 変数が共役線形という規約です。
- **S20** だけ NeZero がなく、n=0 も含みます（ℤ の単数は ±1 なので真です）。
- **冗長な仮定**：S6・S12・S16 の h は不要です。S21 の h は必要です。
